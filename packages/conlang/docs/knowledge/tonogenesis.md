# 声调发生学（Tonogenesis）

声调不是语言的天赋属性，而是**历史产物**：无声调语言可以通过可描述的
音变链条变成声调语言。这条链条方向明确、机制清楚，是少数可以写成
引擎规则的历时语言演化过程之一。

> 调研来源：2026-08-15 interlude 调研（见主仓 `private/research/2026-08-15-linguistics-architecture.md`）。
> 奠基文献：Haudricourt (1954)；命名与推广：Matisoff (1973)。

---

## 一、经典模型：Haudricourt 的越南语案例

André-Georges Haudricourt（1954，《越南语声调的起源》，*Journal Asiatique*）
通过比较越芒语支内部的语言，重建了完整的声调诞生过程：

### 阶段 0：无声调，但有丰富的韵尾辅音与声母清浊对立

古越南语（越芒语支祖先）无声调。音节携带 *-s、*-h、*-ʔ、塞音韵尾等
韵尾辅音，声母分清浊。

### 阶段 1：韵尾影响音高/发声态

- 韵尾 *-s / *-h → 擦化、喉化 → 音节带上降调或升调的音高倾向
  （或嘎裂声等发声态差异）；
- 塞音韵尾（*-p *-t *-k）→ 音节短促，归入"促声"类。

### 阶段 2：韵尾脱落，音高音位化

韵尾辅音消失后，原本由韵尾承载的对立**转移到音高上**——音高差异
成为区别词义的手段，声调诞生。这是"补偿性转移"的一种：
丢失的辅音对立被音高对立接替。

### 阶段 3：按声母清浊分裂（register split）

声母的清浊影响基线音高（浊声母音节基频偏低）。当清浊对立本身
弱化或消失时，每个调类**分裂为阴/阳两组**：

```
中古汉语：平、上、去、入 四调
    × 声母清/浊
    ──────────────────────
粤语：   九声六调（平分阴阳、上分阴阳、去分阴阳、入分阴阳，部分合并）
官话：   四声（清浊对立消失，部分调类合并）
越南语： 六调（ngang/huyền/sắc/hỏi/ngã/nặng）
```

这就是汉语"四声各分阴阳"的来源，也解释了越南语六调系统。

## 二、实时观察到的连续统

该过程不是推测——**藏语内部就有活的连续统**：

- **拉萨藏语**：已完成声调化（约 4 个调 + 声母清浊的历史遗迹）；
- **安多方言**：仍无声调，保留复杂的声母系统；
- 白语、部分羌语支语言处于中间状态。

声调化与辅音简化互为因果：声母/韵尾越简化，音高承载的负担越重。

## 三、类型学分布与声调类型

- **音高调（register）**：若干平调（高/中/低），非洲多数声调语属此类；
- **曲拱调（contour）**：升、降、曲折调，汉语、东南亚大陆语言典型。
- 复杂度的常见演化方向：简单 register → 分裂增多 → 部分合并简化
  （如官话从八调系统简化为四调）。

## 四、对本包（conlang）的工程含义：可编程的声调化规则包

声调发生学链条可以直接写成 SCA 规则语义的扩展。建议的规则形式
（依赖 `docs/design/feature-rules.md` 的特征系统，声调作为音段/音节特征）：

```
# 阶段 1+2：韵尾脱落 → 声调诞生
s > ∅ / _#   [+tone:fall]      # 词尾 -s 脱落，音节获得降调
h > ∅ / _#   [+tone:rise]      # 词尾 -h 脱落，音节获得升调
# 塞音韵尾 → 促声调类
[p t k] > ∅ / _#  [+tone:checked]

# 阶段 3：清浊分裂（每个调类 × 声母清浊 → 两个调）
[+tone:X] > [+tone:Xa] / 声母[+voice] _
[+tone:X] > [+tone:Xb] / 声母[-voice] _
```

**设计提示**：架空语言若设定"辅音韵尾大量脱落"，声调化是物理上
自然的后果——创作者不需要"发明"声调，只需运行规则链。反向同样成立：
一个有声调的语言如果历史上发生过音节复杂化（如借入大量带辅音丛的
借词），可以设计声调负担减轻、调类合并的逆过程。
