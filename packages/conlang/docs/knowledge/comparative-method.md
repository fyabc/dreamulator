# 历史比较法与祖语构拟（Comparative Method）

本文介绍历史比较语言学的核心方法——如何从若干亲属语言反推它们的共同祖先
（祖语/原始语），以及这套方法对架空语系设计的意义。喉音理论案例作为"预测→验证"
的方法论样板单列一节。

> 调研来源：2026-08-15 interlude 调研（见主仓 `private/research/2026-08-15-linguistics-architecture.md`）。
> 主要依据：Campbell (2021) *Historical Linguistics*（第 4 版）、Trask (1996) *Historical Linguistics*。

---

## 一、比较法的标准步骤

1. **选取候选同源词表**。优先使用基本词汇：身体部位、数词、亲属称谓、
   自然元素（即 Swadesh 表、Dolgopolsky 表覆盖的领域）。这些词被借用的
   概率最低，最可能保留谱系信号。
2. **确立系统的语音对应关系（correspondence sets）**。判据不是"个别词长得像"，
   而是**成批的、有规律的对应**。例如日耳曼语的 /f/ 系统性地对应拉丁语的 /p/
   （father/pater, fish/piscis, foot/pes）——这种成批对应无法用巧合或借用解释。
3. **构拟原始音位**。对每组对应关系构拟一个原始音段。选择标准：
   - 语音合理性（构拟出的音变在类型学上常见）；
   - 互补分布（两个构拟音不应出现在无法区分的环境）；
   - 经济性（构拟尽量少的原始音位解释尽量多的对应）。
4. **构拟原始词形与原始形态**。在音位构拟基础上重建词形，并处理形态交替
   （屈折范式中的不规则往往保留了更古老的音变层次）。
5. **用音变规律检验**。每个例外都必须有解释，通常归于三类：
   - 更精细的条件音变（如维尔纳定律之于格林定律的"例外"）；
   - **类推（analogy）**：说话人把不规则形式按规则形式改造；
   - **借用（borrowing）**：借词绕过本语音变规律。

**新语法学派信条（1876，Leskien）**："音变规律没有例外"
（die Ausnahmslosigkeit der Lautgesetze）。一切表面例外要么来自更精细的
条件音变，要么来自类推与借用。这条信条是整门学科的方法论基石——没有它，
构拟就退化为猜测。

## 二、方法的有效边界

- **时间深度上限约 8000–10000 年**。更久远时，音变噪音会淹没语音对应关系，
  同源判定不再可靠。这是"诺斯特拉语系""人类单一起源语"等超深时构拟
  争议巨大、不被主流接受的根本原因。
- **必须排除的干扰项**：拟声词（布谷鸟全世界的名字都像）、幼儿词
  （mama/papa 的全球相似是发音生理而非同源）、偶然相似、借词。
- **语料保存率是硬约束**。原始印欧语之所以能精细构拟，是因为有赫梯语、
  梵语、古希腊语等早期书面语料锚定；原始汉藏语因缺乏早期语料，构拟困难得多
  （B 站评论区即有此讨论）。**对架空世界的启示**：一门祖语能否被世界内学者
  重建，取决于你是否为它设计了存世语料（泥板、碑铭、抄本）——语料保存是
  可以设计的认识论变量。

## 三、树模型与波浪模型

- **树模型（Stammbaum，Schleicher 1853）**：语系是干净的分叉树。
  优点：与比较法天然契合——**共享创新 = 分支证据**（两个语言共享的
  独有创新证明它们构成一个支系）。
- **波浪模型（Wellentheorie，Johannes Schmidt 1872）**：创新像涟漪一样
  从中心向外扩散，相邻语言不论谱系如何都会互相波及。解释同语线交错、
  方言连续体等树模型处理不了的现象。
- **现代共识：两者互补**。树捕捉垂直谱系继承，波浪捕捉水平接触扩散。
  工程上对应：语族树（tree）+ 借用边（borrowing edges）= 语言 DAG。

**语言联盟（Sprachbund）**：无谱系关系的语言因长期接触而结构趋同。
经典案例：巴尔干语言联盟（后置定冠词、不定式萎缩、分析式将来时）、
东南亚大陆语言区域（声调、孤立倾向、量词、SVO 的区域特征包）。

**借词层次**：长时段接触在词汇中留下分层沉积。英语 = 日耳曼底层 +
古诺尔斯语层（sky, they）+ 诺曼法语层（court, justice）+ 拉丁/希腊学术层。
日语 = 上古汉语层 + 中古汉语层（音读各系统）+ 近代西方语层。
**语言史应当"分层可读"：词汇的音韵轮廓可以暗示其借入年代与来源。**

## 四、喉音理论案例：预测→验证的范式

这是历史语言学史上最著名的假说-演绎全程，对架空语系设计有直接的方法论价值。

### 4.1 时间线

| 年代 | 事件 |
|---|---|
| 1822 | 格林定律：PIE 塞音在日耳曼语整体移位（*p→f, *t→θ, *k→h 等） |
| 1875 | 维尔纳定律：格林定律的"例外"被证明服从重音条件 |
| 1876 | 新语法学派"音变无例外"纲领 |
| 1879 | **索绪尔（21 岁）《论印欧语言中元音的原始系统》**：为解释元音交替的不对称，构拟两个音值未知的"响音系数"（coefficients sonantiques），一个具 a 着色功能、一个具 o 着色功能——纯代数推断，无任何直接证据 |
| 1906 起 | 哈图沙（赫梯首都）出土上万块楔形文字泥板 |
| 1915 | Hrozný 破译赫梯语（突破口："你们要吃面包，然后喝水"——用苏美尔表意符号 NINDA"面包"做语义锚点，将 ezzatteni 联系到拉丁语 edere/英语 eat），确认赫梯语是极古老的印欧语 |
| 1927 | **Kuryłowicz 发现赫梯语辅音 ḫ 恰好出现在索绪尔预言的系数位置**（ḫant- 对应 \*h₂ent-/拉丁 ante；ḫasterza 对应 \*h₂ster-/英语 star）——预言兑现 |
| 1942 | Sturtevant《印欧-赫梯喉音》：安纳托利亚语族最早分化，故独存喉音本体 |
| 20 世纪后半叶 | 三喉音构拟 *h₁*h₂*h₃ 成为印欧音系学标准成分 |

### 4.2 三喉音及其效应

按**元音着色效应**区分：

| 喉音 | 着色 | 常见发音猜测（仍有争议） |
|---|---|---|
| *h₁ | 不着色（保持 e） | 声门塞音/擦音 [ʔ]/[h] |
| *h₂ | a 着色（e→a） | 咽擦音 [ħ]/小舌音 |
| *h₃ | o 着色（e→o） | 圆唇咽音 [ʕʷ] |

三大结构效应：
1. **着色**：相邻 *e 变 a/o；
2. **延长补偿**：*eHC → ēC（喉音消失后前面元音变长）；
3. **音节支撑**：零音节中喉音自成音节（在希腊语产生 a/e/o）。

各后代语的痕迹：安纳托利亚语直接保留 ḫ；希腊语痕迹最丰富（词首补元音、
着色、辅音间变 e/a/o、延长）；拉丁语保留着色与延长（octō < \*h₃ekʷtṓ）；
亚美尼亚语几乎无痕（"消亡谱系"极端案例）。综合案例："父亲"一词
PIE \*ph₂tḗr → 希腊语 patḗr / 拉丁语 pater / 梵语 pitā́ / 日耳曼语 \*fadēr
→ 英语 father——**一个音段同时解释元音颜色与辅音浊化两类现象**。

### 4.3 方法论意义（对架空语系设计）

喉音理论走通了完整的假说-演绎法：理论预测（1879）→ 独立的经验发现
（1906–1915，与预测无关的考古事件）→ 确证（1927）。常与勒维耶预测海王星、
门捷列夫预言镓/锗类比。

**核心设计启示——"幽灵音段"模式**：一个内部自洽的系统，其缺口和不对称
会留下可检测的痕迹。设计祖语时**刻意植入未来会消失的音段**，让它们在
后代语中变成元音着色、长度补偿、形态交替等"疤痕"——世界内学者可以从
疤痕反推祖语，架空语系因此获得纵深感。

### 4.4 争议标注

- 喉音的确切音值（声门/咽/小舌）至今无定论；Szemerényi 等曾质疑喉音数量；
  但"存在若干在安纳托利亚之外消失的喉部音段"是主流共识。
- 安纳托利亚语是"最早分化的女儿"还是"PIE 的姊妹分支"（Indo-Hittite 假说）
  仍是活跃的争论。
- **这是"共识与争议分层"的范例**：结构结论（喉音存在）是共识，
  音值细节是开放问题。架空世界设计两者都可利用。

## 五、对本包（conlang）的工程含义

1. **一致性校验回路**：比较法的正向版本是"女儿语 → 同源判定 → 祖语重构"。
   本包是反向问题（祖语 + 音变规则 → 女儿语）。两者可互检：生成女儿语后，
   用同源词检测（参考 LingPy 的 LexStat）验证能否恢复祖语词形——
   与 dreamulator 天文引擎"正向计算 vs 手动覆盖值比对"的范式同构。
   相关模型：`lexicon/entry.py` 的 `CognateSet`。
2. **例外系统化**：SCA 生成的女儿语必须能经受"世界内比较法"的审视，
   因此例外不能随机——应由显式的类推（analogy）与借用（borrowing）
   机制产生（见 `docs/design/feature-rules.md` 的 Phase 2 规划）。
3. **时间深度语义**：祖语与女儿语的分化时长应影响音变数量与幅度；
   超过约 1 万年的分化在现实中已不可构拟——架空语系若设定更深的
   分化，应在世界内学术叙事中体现为"构拟不能"。
