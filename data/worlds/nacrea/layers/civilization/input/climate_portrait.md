# 气候画像与文明启示

> **2026-09-29**：E3 纪元落地重建产品（有效倾角 14.9°、Aegis 年 99.7 d、温室 62.0 K、
> 新一代气候引擎 = 守恒账本收口后版本）。对照实际地球（观测值）。

## 一、核心指标对比

| 指标 | Nacrea | 实际地球 |
|---|---|---|
| 全球均温 | 15.9°C | ~14.5°C |
| 陆地均温 | **12.3°C** | ~8.5°C |
| 海洋均温 | 17.4°C | ~17°C |
| 陆地降水 | **970 mm** | ~800 mm |

**Nacrea 是「暖湿海洋性」世界**：陆地均温 +3.8°C、陆地降水 1.2× 地球。

## 二、Köppen 分布（占陆地百分比）

| 群 | Nacrea | 解读 |
|---|---|---|
| A 热带 | 24.3% | 多于地球（~17%） |
| B 干旱 | 28.3% | 与地球（~33%）同量级 |
| C 温带 | 21.0% | 显著多于地球（~9%）——海洋性 Cfb/Csb/Cwb 主导 |
| D 大陆性 | **0%** | 完全没有（见五.2） |
| E 极地 | 26.4% | ET 苔原 16.0% + EF 冰盖 10.4% |

## 三、宜居性评估

- **宜居陆地（t_hot > 10°C，即 A+B+C）占 73.6%**——支撑文明绰绰有余。
- **凉湿海洋性 ET**（年均温>0 且降水>1000mm）约 790 cell（北方沿岸 + 亚南极群岛），
  对人类定居宜居、只是无乔木/农业弱（法罗/因纽特型）。

## 四、优势

1. **暖 + 湿**：陆地 12.3°C、970mm → 生物量潜力大、水资源充足；
2. **温带海洋性 C 群占 21%**：西欧式「温和多雨无严冬」气候多，适合定居；
3. **无严冬带广**：全球陆地温程中位仅 1.8 K，农业无越冬压力区占绝对主体。

## 五、劣势 / 风险

1. **极地 E 群占 26.4%**（苔原 16% + 冰盖 10%）：高纬大片 t_hot<10，不产粮、只能放牧/渔猎；
2. **无 D 大陆性（0%）**：没有「冷冬暖夏」的大陆性谷物带
   ——14.9° 倾角 + 99.8 d 短年 + 72% 海洋的强热惯性使夏季均温够不到 10°C 门槛；
   北方深内陆（50–75°N、离岸 >1500 km）为 6–8 K 温程的「近 D 边缘」微区
   （≥6 K 共 ~2300 cell = 1.9% 陆地；中纬最大 7.7 K；极缘 49 cell 达 8.6 K）。
   **这不等于没有农业**，C/A 群仍支撑大型农业（见下）；
3. **中度弱季节**：四季不分明但非无感——全球陆地温程中位 <2 K，北方内陆
   6–8 K（「北方有冬」）；农业主体是「低纬全年型」或「中纬温和型」，
   北方内陆有可用的「夏收」节律（最热旬在夏至后 ~1/4 年，热滞后所致）。

## 六、独特特征（地球没有）

1. **慢自转（3.138d）**：科氏力弱 → Hadley 胞宽达 55° → 副热带干燥带在高纬（33–73°）；
2. **潮汐锁定卫星**：次 Aegis 半球永久 +1°C 暖化，固定经向温度梯度驱动风/洋流；
3. **K 型橙矮星 0.66× 光照**：偏橙光为主，靠 62K 温室补温——高纬苔原、低纬雨林，中间过渡带窄；
4. **锥摆倾角**：有效倾角绕 14.9° 均值做 ~10 yr ±3° 呼吸（拉普拉斯面锥摆，
   见 long_term_cycles.md §2）——季节强度以十年为节拍轻微起伏，代际可感。

## 七、文明启示

**Nacrea 是「暖湿世界」，能支撑多种大型农业文明，而非只有海洋文明。**

- **大型农业国家（大陆内部）**：世界岛等大陆上有大片连续的 **Cfb（温带海洋）、
  Csb（地中海）、Af/Aw（热带）**——分别对应罗马/希腊（Csb 地中海农业）、西欧
  （Cfb 温和农业）、印度/东南亚/中美洲（Af/Aw 热带农业）。这些同样能孕育大型农耕
  帝国，只是**没有「冷冬暖夏」的大陆性谷物带**（D 型）；
- **海洋文明 + 沿海城邦**：暖湿 + 温带海洋性海岸（C 群 21%）+ 亚南极凉湿群岛，
  为海洋贸易/沿海城邦提供了大量定居点；
- **极地苔原（ET 16%）** → 高纬是「渔猎/放牧」边缘地带，不是农业腹地；
- 所以文明形态是**「大陆农业帝国 + 海洋贸易城邦」并存**，区别在于农业类型是
  地中海/温带/热带型（而非大陆性谷物型）。这与「北方内海 + 亚南极群岛」的设定自洽，
  详见 [civilization_divergence.md](civilization_divergence.md) 的向星区/背星区/边缘区大分流。
