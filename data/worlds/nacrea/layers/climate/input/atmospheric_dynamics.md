# 科里奥利力与流体动力学

> 基于引擎实际推演参数。引擎实现三圈环流（Hadley 0–55° / Ferrel 55–75° / Polar 75–90°），
> 其中 Hadley 胞因慢自转（Ω = 0.31 Ω⊕）扩展为主导环流，Ferrel 较窄，Polar 局限于极区。

### 因变量

| 参数 | Nacrea | 地球 | 比例 |
|------|--------|------|------|
| 自转角速度 Ω | 2.238×10⁻⁵ rad/s | 7.292×10⁻⁵ rad/s | 30.68% |
| 科里奥利参数 f（中纬度 45°） | 3.16×10⁻⁵ s⁻¹ | 1.03×10⁻⁴ s⁻¹ | 30.68% |
| 哈德里环流边界 | **55°**（引擎配置） | ~30° | 1.83 倍 |
| 极锋位置 | 75°（引擎配置） | ~60° | 1.25 倍 |

### 大气环流结果（引擎产出）

- **三圈环流**：Hadley(0–55°) → Ferrel(55–75°) → Polar(75–90°)，Hadley 因慢自转大幅扩展，是实际上的主环流
- **纬向温差**：赤道-极地温差约 22°C（vs 地球 ~40°C），引擎通过 `auto_lat_gradient` + 图扩散建模
- **哈德里下沉支**位于 30°–55° 带——对应引擎产出中的 BSk/BWk 分布带

### 未建模现象（保留为世界设定参考）

- **无台风带**：纬度 <15° 科氏力不足以形成闭合气旋（EBM 不建模气旋）
- **行星尺度飑线**：纬度 ~20° 可形成绵延上万公里的超级飑线
