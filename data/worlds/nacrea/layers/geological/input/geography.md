# 海陆分布（文明时代）

> 潮汐物理使向星点（0°）与背星点（180°）成为深海（大地水准面向星点隆起，
> 海洋响应强于固体地球），侧点与极点偏陆——机制详见 tidal_effects.md。
> 机器可读锚定规格见同目录 `geography.yaml`；本文数值为 cvt_mesh（seed=42,
> 200k）实测结果。

## 潮汐海陆骨架（自变量）

| 位置 | 角色 | 机制 |
|------|------|------|
| 向星点（0° 赤道） | 深海吸引子 | 潮汐伸展应力 → 岩石圈减薄 + 大地水准面隆起 → 全球最深海洋 |
| 背星点（180° 赤道） | 深海吸引子 | 同机制，潮汐应力与向星点几乎相同（只弱约百分之一） |
| 前导点（~90°E）/ 后随点（~90°W） | 陆地吸引子 | 压缩应力 → 地壳增厚隆起 |
| 北极 / 南极 | 陆地吸引子（北强南弱） | 强压缩应力 → 高原/山脉 |

| **曙光大陆** | 约 45°E 为中心 | **16.9 M km²**（占陆地 10.3%），纬度跨 −17°…+48°；内部有一个海湾 |

| **夜幕大陆** | 约 171°W，46°N…63°N，横跨日界线 | **5.2 M km²**（占陆地 3.2%），平均海拔 2224 m 的高原大陆，有全球最高峰（约 8000 m）；位于终年不见 Aegis 的背星半球，与北极大陆之间只隔两条窄水道 |
| 北方内海 | 北极大陆环内（约 90°W…45°E，55°N…83°N） | 约 9.9 M km² 的陆间海，经北极周缘裂谷的几处窄口与外洋**连通** |
| Aegis 深渊洋 | 向星点为中心 | 核心 30° 盘陆地占比 **0.1%**，平均水深约 −2830 m；中央有永耀岛（向星点火山省上最高的火山，此处热流与火山活动格外强烈；约 5 万 km²，峰高约 2200 m） |
| 虚空洋 | 背星点为中心 | 核心 30° 盘陆地占比 **2.4%**；该半球天空终年不见 Aegis |
| 环南洋 | 南纬 45° 以南的环绕洋带 | −60°…−30° 带陆地占比 7.3% |
