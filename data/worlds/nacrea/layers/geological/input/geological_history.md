# 地质历史简史

## 自变量

| 参数 | 值 | 备注 |
|------|-----|------|
| 总时间跨度 | 60 亿年 | |
| 轨道外迁 | 形成以来 +10%（至 723,300 km） | 潮汐角动量传递 |
| 早期偏心率 | ~0.015 | 冥古宙自由偏心率潮汐衰减；晚期散射期（~0.5 Gyr）双珠捕获后转为受迫带（历元 0.00171 = 冷谷快照，见 satellite_architecture.md） |
| 恒星前主序阶段 | 诞生后前 5 亿年，光度为当前 3–5 倍 | |

## 因变量 — 地质分期

| 时代 | 时间 | 热流 (W/m²) | 核心事件 |
|------|------|---------|---------|
| **冥古宙** | 0–5 亿年 | 26.6（形成余热 + 潮汐） | 全球岩浆海；原生水全部蒸发+光致解离+氢逃逸；巨行星磁层保护大气底座 |
| **太古宙** | 5–25 亿年 | ~1.3 W/m²（捕获期带均值） | 韵珠、守珠在**晚期散射期（~0.5 Gyr）**先后被逆行捕获——本系统的「晚期重轰炸期」，同一事件雕塑了墟带、供给散射盘与奥尔特云、捕获逆石星。受迫偏心率带自此接管自由偏心率（双源泵浦 = 恒星四极矩本底 + 双珠长期摄动；当代段摆动带 rms 0.0036 / max 0.0098，数值审计见 design-notes/0009）。次生海洋凝结（散射期彗星/小行星供水）；板块速度 30–40 cm/yr；约 30 次超大陆旋回（周期 ~7000 万年）；生命在 1 亿年内起源 |
| **元古宙** | 25–50 亿年 | ~1.05 W/m² | 大氧化事件；「泥泞雪球」危机（橙矮星偏橙光下冰雪反照率偏低，冰封不完全）；真核生物与多细胞化 |
| **显生宙** | 50–60 亿年 | ~0.8 W/m² | 第 51 次超大陆旋回裂解中期；板块速度 15–25 cm/yr；文明诞生 |

> 注：冥古宙（双珠捕获前）为**总热流**——e~0.015 时潮汐仅 ~6 W/m²（k₂/Q=1×10⁻³），
> 其余为吸积/放射性/核幔分异余热。太古宙及以后以**潮汐热流为主**（∝ e²，见
> tidal_effects.md）；带均值随轨道外迁按 a⁻⁶ 缓降（捕获期 658k km → 现 723.3k km，
> 累计 +10% → 热流 ×0.56），叠加 ~20 kyr「万年火山脉冲」调制。

（与地球的驱动热源/旋回节奏对比见 design-notes/0011。）
