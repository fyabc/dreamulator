## 3. Nacrea 潮汐加热预算（宜居性硬约束）

Nacrea 的偏心率不是自由衰减的残余，而是由两个泵浦源持续维持的**受迫偏心率**：

- **恒星四极矩本底**：Nacrea 处在 0.365 AU 的强恒星场中、又位于 1.45 r_L 处，
  恒星四极矩给它一个 ~0.004–0.006 的偏心率本底。这是测试粒子效应，与双珠
  质量无关；β+ 安静链态下四极矩的调制浅而慢。
- **双珠长期摄动**：线性标定系数 coef = Σ mᵢ(a_N/aᵢ)³ = 0.006×0.222 +
  3.05×10⁻⁴×0.073 = **1.35×10⁻³**，其中韵珠贡献 98.3%。这一项约为四极矩
  本底的一半。两源矢量叠加、再经拍频调制，构成认证带。

**加热换算**：潮汐热流 F = 2.6×10⁴·e² W/m²（Peale-Cassen 公式，对应
k₂/Q = 1.0×10⁻³，即 k₂=0.3、Q=300）。

**认证数字（draw-0 认证实现，当代段 0–12 kyr = 正典窗口）**：e_N rms 0.0036 /
p50 0.0030 / p95 0.0066 / max 0.0098 → **F 均值 0.34 W/m²（0.15×Io，3.9× 地球
内热）、p95 1.14、瞬时极值 2.50（0.89×Io，百年级短暂）**；500-yr 平滑持续脉冲
占空 **0%**（平滑 p95 仅 0.77 W/m²，无体制迁移风险）。历元值 e=0.00242 →
0.152 W/m²（89 TW ≈ 1.9× 地球总热流，带下缘冷谷快照）。长窗结构：e_N 在死前
~6 kyr 单调增温（0.004 → 0.3+）——**加热爬升 = 失稳前兆**诊断律继续有效；
主调制 ~20 kyr =「万年火山脉冲」（长期摄动拍频）。

**叙事定位**：「增强板块构造→正典带」成立（均值 ~4× 地球内热流，落在环境体制
带的正典段 0.3–1.2 W/m²）；瞬时尖峰 ~0.9×Io 为百年级火山脉冲事件，非持续状态
——**达成重构立项的原始严格热流目标（极值 ≤0.5–0.9×Io）**。约束红线（当代段
口径）：任何使 500-yr 平滑 F > 2.24 W/m²（1×Io）持续占空 > 10% 的外卫构型被
否决——draw-0 占空 0% 通过。

## 4. 自转态（两珠均已锁定，解析判定）

锁定（同步化）时标 t_lock = ω₀a⁶I(Q/k₂)/(3G m_p²R⁵)（月球锚验证）。小天体 k₂
被刚度压制（k₂ = 1.5/(1+19μ/2ρgR)）：韵珠 t_lock ~1–3 Myr、守珠 ~28–86 Myr，
可用时间 5.4 Gyr ≫ 全部参数带 → P(锁定) ≈ 100%。

- 韵珠：e 带 0.009–0.072，自转取同步值 6.54 d（Hut 伪同步修正 ≤3%）。
  内部加热随 e² 呼吸，整体温和——「Europa 个头、Europa 成分」的深部水层
  设定因此更稳（冰下海洋长期存在）。
- 守珠：e 带 0.099–0.228（当代段），自转为 Hut 伪同步，周期在 **9.0–11.1 d
  之间呼吸**（中值 10.2）。从珠母星测它的光变曲线可以看到周期漂移，是
  文明级可测现象。

## 5. 起源叙事

两颗珠均为 **晚期散射期（~0.5 Gyr，本系统的「晚期重轰炸」）的逆行捕获**——
与 Glacis 的逆石星 Rogue 同机制同世代。该事件同时供给：双珠与 Rogue 的捕获、
墟带内缘侵蚀、外散射盘与奥尔特云（见 0010 墟带笔记）。捕获后轨道被 Aegis
弱潮汐（P-B 包）冻结在**各自的逆行拉普拉斯面近旁**（不是赤道面——r_L 外侧
平衡面即拉普拉斯面；「捕获面 = 进动面」），5.4 Gyr 迁移 μm/yr 级。
**无瞬态、无序列捕获、无近期捕获**——连珠节律是自系统定型以来恒常的天象。

Nacrea 的 ε=18° 锥摆构型（出路 b）：形成于 Aegis 子盘（贴赤道面），早期巨
撞击设定 Aegis 倾角 18°；Nacrea 在 1.45 r_L 处不受赤道面约束，轨道面绕拉普
拉斯面 ~10 yr 锥摆（i_eq 0.6–31°），**长期均值 i_ecl ≈ 14.9° = 气候层季节倾角**
（10 yr ≪ 气候响应时间，季节学等效于均值倾角 + ±3° 十年呼吸）。倾角阻尼
时标 ~150–300 Gyr（P-B 弱耗散）→ 巨撞击化石，无需维持机制。

  ~4.1 年一遇（15′ 级 ~2.1 年）、5′ 级 ~6.4 年一遇（1500 地球年 N 体 MC 判决，
  `private/research/2026-09-28-sky-recalc.md` §3②）；
- **双掩**（双珠同瞬全掩入巨盘盘后，不入影）：~2.7 次/年，成季聚簇（间隔中位
  43 d = 互倾角慢拍在天空的投影，与食季同构）；
- **双掩大连珠**（四体共线，双珠相继掩入巨盘并双双没入本影）：**~1500 地球年
  一遇**（Poisson 带 ~450–7500 yr），「一文明一次」的历法与神话核心节律；
  相位 = **新巨行星相**（暗盘冲日、向星区子夜），非食夜——食季时影锥指向
  Nacrea 自身、双珠不可能入影。严格四体共线且入影（ψ≲12′）1500 yr 样本内未见。

**墟带与远期天象**：黄道面上 16° 宽的**墟带光**幽带（f_dust=3×10⁻⁸ 基线，
μ_V≈23.8——背星区极暗夜肉眼边缘可辨；碰撞「觉醒事件」可达 μ_V 22.4 肉眼清晰带）；
食季食夜（烬星+Aegis 双灭）是向星区唯一能见墟带与完整星空的窗口；1.57 d 节拍的
双节点流星增强（墟带尘 P-R 内迁）。「韵珠远行」：draw-0 实现 ~22.3 kyr 内韵珠
被弹射出系（e_C 无界增长；死前 ~6 kyr 珠母星潮汐增温与韵珠自身亮化可察前兆）
——先知级可预报末世天象；守珠轨道距离在整个认证窗口内有界（叙事豁免：双珠
与文明长期相伴）。

## 7. 工程红线

- **stellar.yaml 中 Aegis 系全部轨道根数（含链行星、平近点角与守珠重采样
  三角）是认证实现的一部分**：修改任何字段前必须重跑 REBOUND 认证——
  `uv run python scripts/astro/rebound_nbody.py --j2 0.008 --tides --t-end 3e4`
  直读 yaml（预期：~22.3 kyr 韵珠弹射；当代段 e_N rms ~0.0036）。
  认证 harness 必须使用**向量式 J2 算子（节点 + 近点角）**才是完整的拉普拉斯
  面物理；缺少节点项的算子会冻结轨道面、把卫星热预算低估约 7 倍，其认证
  结果不可用。
- **ϖ₀ 扇区红线**：Aegis ϖ 初值只许落在安静扇区（0°/180° 邻域）；90°/270°
  狂野扇区 = 链 8–15 kyr 死 + 卫星热流 ×2.5。近日点-至点对齐只能作为纪元
  平移产物（φ=82.7° 历元），**不得以改 ϖ₀ 初值实现**。
- **禁止在 0.3–0.5 r_H 带引入任何共动第二伴星**（继承旧红线）；守珠内迁
  1800k（0.37 r_H）是 93 票矩阵的存活+热流双优解，进一步内迁（≤1450k）
  已证更早死。
- **紧凑构型禁令**：a_C ≤ 1050k 落入 Nacrea 3:2/5:3 一阶共振影响圈且热流
  反升（标定失效区），已证伪。
- a 值以 1 AU = 1.496×10⁸ km 换算，保留 8 位有效数字保证复现。
- 混沌系统教训：认证对象 = 精确实现（含全部根数与质量）；窗口长度决定 e 带
  （25 kyr 签不得直接当正典带引用）；死点时刻对 k₂/Q 等微扰有 kyr 级漂移，
  重认证后以实测为准。
