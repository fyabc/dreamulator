# 海陆分布（文明时代）

> 潮汐物理使向星点（0°）与背星点（180°）成为深海（大地水准面向星点隆起，
> 海洋响应强于固体地球），侧点与极点偏陆——机制详见 tidal_effects.md。
> 机器可读锚定规格见同目录 `geography.yaml`；本文数值为 cvt_mesh（seed=42,
> 200k）实测结果。

## 潮汐海陆骨架（自变量）

| 位置 | 角色 | 机制 |
|------|------|------|
| 向星点（0° 赤道） | 深海吸引子 | 潮汐伸展应力 → 岩石圈减薄 + 大地水准面隆起 → 全球最深海洋 |
| 背星点（180° 赤道） | 深海吸引子 | 同机制，幅度略弱 |
| 前导点（~90°E）/ 后随点（~90°W） | 陆地吸引子 | 压缩应力 → 地壳增厚隆起 |
| 北极 / 南极 | 陆地吸引子（北强南弱） | 强压缩应力 → 高原/山脉 |

## 海陆配置（当前设定）

| 地貌 | 位置/范围 | 实测 |
|------|----------|------|
| **世界岛—北极超级大陆** | 后随点 ~90°W 为中心，经陆桥连北极 | 连通陆块 **117.2 M km²**（占陆地 70%）；其中 lat<45° 的世界岛本体 **72.3 M km²**；纬度跨 −32°…+90° |
| 大裂谷海 | 世界岛中部纵贯（~−90°W，−30°…+25°） | 错列裂谷型**海峡式内海**，水体 100% 与外洋连通；西支分叉 |
| 第二大陆（前导点褶皱山系） | ~114°E 为中心 | **28.4 M km²**（占陆地 17%），纬度跨 −5°…+46°；褶皱山系横贯其南缘 |
| 南方大陆 | ~133°E，−26°S | **7.8 M km²**（澳洲类比，低海拔） |
| 北极大陆 | 北极点为中心 | 与世界岛经 45°N 陆桥广泛相连（同一连通陆块）；内含北方内海 |
| 北方内海 | ~（−90°…+45°E，60°…80°N） | 北极大陆内的陆间海，经北极周缘裂谷与外洋**连通** |
| Aegis 深渊洋 | 向星点为中心 ±45° | 陆地占比 **0.7%**（全球最深海洋）；中央有永耀岛（潮汐固定热点火山岛） |
| 虚空洋 | 背星点为中心 | 陆地占比 **0.1%**；该半球天空终年不见 Aegis |
| 南极岛弧浅海 | 南纬 60°…76° 环带 | 无连续大陆，呈**岛弧 + 浅海**（数个 0.5–1.2 M km² 岛屿） |
| 南大洋 | 南纬 30°…60° 纬向洋带 | 陆地占比 <4%（−60°…−30° 带仅 3.9%） |

## 全局指标（实测）

| 指标 | 值 |
|------|-----|
| 陆地占比 | **28.7%**（57,394 / 200,000 cell；目标 28%） |
| 陆地总面积 | 167.6 M km² |
| 北半球陆地占比 | **71.2%**（陆地偏聚北半球；lat 60°–90° 带陆地占 62.9%） |
| 连通陆块数 | 187（主大陆 4 + 岛屿群） |
| 海洋连通性 | **全球连通**（与向星点连通的开放洋占 71.0%；仅有 3 处 <0.2 M km² 的封闭小湖） |

## 因变量

| 参数 | 值 | 推导依据 |
|------|-----|---------|
| 赤道张裂带 | Aegis 深渊洋洋中脊 | 潮汐伸展应力在向星/背星点最大 |
| 侧点压缩造山带 | 世界岛周缘环状山脉 + 西缘海岸山脉 | 压缩隆起 + 俯冲作用 |
| 潮汐平原 | 宽 ~25 km | ~44 m 潮差 / tan(0.1°) |
| 大裂谷海超级季风 | 裂谷海季节性热低压 | 狭长内海 → 海陆热力差放大（气候层建模） |
