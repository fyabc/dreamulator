# 海陆分布（文明时代）

> **2026-08 翻案说明**：潮汐物理要求大潮点（向星/背星点）为深海、侧点与极点偏陆
> （大地水准面向星点隆起 +2688 m；海洋响应 1+k₂=1.3 > 固体地球 h₂=0.6，
> 大潮点海洋相对加深 +1447 m——详见 tidal_effects.md 与
> `private/chats/chat-潮汐锁定下的海洋分布.txt`）。
> 旧方案（Aegis 大陆@次行星点、Anti-Aegis 大陆@反点）被推翻，陆块整体迁移至侧点；
> 原重复文档 land_sea.md 已并入本文件。本方案为不对称混合案（保持 72% 海洋）。

## 自变量 — 潮汐海陆骨架

| 位置 | 角色 | 机制 |
|------|------|------|
| 向星点（0° 经线赤道） | **深海吸引子** | 潮汐伸展应力 → 岩石圈减薄 + 大地水准面隆起 → 全球最深海洋 |
| 背星点（180° 经线赤道） | **深海吸引子** | 同机制，幅度略弱 |
| 前导点（~90°E 赤道）/ 后随点（~90°W 赤道） | **陆地吸引子** | 压缩应力 → 地壳增厚隆起 |
| 北极 / 南极 | **陆地吸引子** | 强压缩应力 → 高原/山脉 |

## 自变量 — 不对称海陆配置（文明时代）

| 参数 | 值 | 备注 |
|------|-----|------|
| Aegis 深渊洋 | 向星点为中心，跨经度 ±45° | 平均深度 ~5.8 km（全球最深）；潮汐张裂洋中脊纵贯南北 |
| 虚空洋 | 背星点为中心 | 平均深度 ~4.6 km；该半球天空终年不见 Aegis |
| 世界岛 | 后随点 ~90°W 为中心 | 约 0.9×10⁸ km²（欧亚大陆 1.9 倍）；第 51 次超大陆旋回裂解中期 |
| 大裂谷海 | 世界岛中部纵贯 | 宽 600 km、长 8000 km 的狭长内海（裂谷活跃拉张段） |
| 破碎群岛带 | 前导点 ~90°E 为中心 | 压缩隆起被远古巨型撞击击碎 → 微陆块 + 岛弧 + 浅海潟湖，无大洲（与世界岛构成不对称对比） |
| 北极孤立大陆 | 北极点为中心 | 平均海拔 1000–2000 m 高原；极地环极洋流 ACC 动力学孤立 |
| 南极浅海 | 南极点为中心 | 平均深度 <200 m 陆缘浅海 + 巨型潮间带；打破南北对称（潮汐压缩陆地偏聚北半球） |
| 陆半球偏置 | 北半球陆地占全球陆地 62% | 真极wander 残余 + 撞击不对称 |
| 北纬 45° 地峡 | 世界岛西北陆桥连接北极大陆 | 宽 300 km，部分阻断中高纬度经向洋流 |
| 超级火山热点 | 全球 5 个地幔柱热点 | 其一偏置于破碎群岛带（热点火山是前导点"碎而不沉"的修补机制） |

## 因变量

| 参数 | 值 | 推导依据 |
|------|-----|---------|
| 海洋覆盖率 | 72%（陆地 28%） | 与 physical_params.md 海陆比一致；潮汐大地水准面骨架 + 随机板块配置 |
| 赤道张裂带 | Aegis 深渊洋洋中脊，扩张 ~20 cm/year | 潮汐伸展应力在向星/背星点最大 |
| 侧点压缩造山带 | 世界岛周缘环状山脉 + 西缘海岸山脉 | 压缩隆起 + 俯冲作用（岛弧在外侧） |
| 中高纬度连续洋 | 占表面积 65% | 弱科氏力 → 超级环流；极地海冰分布见气候层 |
| 潮汐平原 | 宽 ~45 km | 78 m 潮差 / tan(0.1°) |

## 与旧设定的兼容性说明

- 旧"Aegis 大陆 / Anti-Aegis 大陆" → 陆块迁移至侧点，更名"世界岛 / 破碎群岛带"；
  气候与奇观文档中的引用已同步替换。
- 保留的故事种子：大裂谷海（超级季风引擎）、北纬 45° 地峡、北极孤立大陆 + ACC、
  5 个超级火山、45 km 潮汐平原。
- 新增叙事素材：向星/背星双深渊洋、"永不见巨行星"的虚空洋、南北不对称
  （北极高原大陆 vs 南极浅海）、破碎群岛带的撞击起源。
