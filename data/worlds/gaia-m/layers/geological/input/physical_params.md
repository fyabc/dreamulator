# 卫星 Gaia-M — 物理参数

### 自变量

| 参数 | 值 | 备注 |
|------|-----|------|
| 质量 | 1.20 M⊕ | |
| 半径 | 1.07 R⊕（6817 km） | |
| 潮汐状态 | 被巨行星 Aegis 潮汐锁定 | 公转周期 = 自转周期 |
| 绕巨行星公转周期 | 78 小时 | |
| 海洋平均深度 | 4000 m | |
| 海洋覆盖率 | 72%（陆地 28%） | |
| 洛夫数 h₂ | 0.6 | 固体形变 |
| 洛夫数 k₂ | 0.3 | 引力势形变 |

### 因变量

| 参数 | 值 | 推导依据 |
