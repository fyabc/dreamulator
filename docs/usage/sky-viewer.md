# 天球视图（星空观察者视角）

前端的「站在世界某天体表面看天空」查看器（Stellarium 式全屏形态）：
给定观测天体、观测点 `(lat, lon)` 与时刻，渲染沉浸环视天空——恒星、
行星、卫星的位置、视直径、相位、星等与升落，全部来自 `sky_ephemeris`
引擎查询（两体开普勒传播 + 观测者 ENU 框架），前端不做任何轨道计算。
天空占满整个视口，所有 UI 是浮动件：指针活动时出现、静置约 2.5 秒后淡出。

> 引擎设计（参考系、自转轴阶梯、升落语义）见
> [knowledge/astrophysics/observer_sky_frames.md](../knowledge/astrophysics/observer_sky_frames.md)
> 与 [design/proposals/sky-ephemeris.md](../design/proposals/sky-ephemeris.md)；
> CLI 侧命令（`dreamulator sky`）见 [cli.md](cli.md) 的 sky 一节。

## 功能概览

- **环视（默认）**：沉浸透视图占满视口——朝一个方向看天空，**拖动环视、
  滚轮/双指缩放竖直视场（15°–120°）**。环视是纯前端投影，不发任何请求：
  所有天体的高度/方位已在结果里，拖动即时生效；只有改时刻才走毫秒级快路径
  取数。圆盘大小与真实视径成比例（巨行星近地时可以是占半屏的大圆盘）；打开
  页面时默认视向自动对准当时天上最亮、且离地平线足够远（≥10°）的天体；
  地面是地平曲线下方的填充区域，方位刻度与八方标沿地平线展开。
- **全天（切换模式）**：方位等距半球星图——半径线性正比于天顶距，30°/60°
  高度环在固定半径、方位角处处等角；天顶在圆心、地平圈为外缘，环视的当前
  视向以金色十字标出。一眼看全所有天体与升落结构。
- **坐标网格（按需开启）**：显示设置里可叠加**地平网格**（高度/方位，白色）、
  **赤道网格**（赤经/赤纬，蓝色，天赤道更亮）与**黄道线**（琥珀色）；后两者
  由结果里每个天体的双坐标反解旋转得到，数据退化时自动跳过。
- **相位月牙**：每个天体标记的亮缘指向星图上恒星标记的方向（真实相位几何，
  非装饰）。
- **星等**：视星等 ≥6（肉眼极限）的天体半透明显示，星图即「裸眼可见性」。
- **时间控件**：底部居中悬浮条——**天数输入框**是唯一时刻设定方式（任意值，
  回车确认，不再受滑条范围限制）；时间显示单位可在**太阳日（观测者本地日，
  默认）/地球日**间切换，表盘随单位走；播放速度是对数滑条（0.01–10
  太阳日/秒，即表盘自身单位，速度与表盘肉眼可对账）；播放为连续动画
  （毫秒级快路径逐帧取数），暂停才提交全量升落数据。
- **选中详情**：单击天体（或升落表行）在**右上**弹出半透明信息面板（不遮死
  天空）——相位角、照亮比、视星等、照度、距离（km/AU 自适应）、视径
  （°/′/″ 分档）、高度变化率、星距/母星距角、赤经赤纬（观测者自转轴的赤道系）、
  黄经黄纬；点天空空白处或面板 ✕ 取消选择。
- **信息面板按需弹出**：升落年历与地平线下列表（下次升起倒计时）默认隐藏，
  在显示设置里点按钮二选一弹出（右上半透明窗口，✕ 关闭）。
- **URL 状态同步**：观测者/观测点/时刻/视向/网格/面板/分支全部在查询参数里，
  链接可分享。

## 访问方式

侧栏「✨ 天球视图」入口或直接访问 `/worlds/:worldName/sky`
（路径段 `/sky/:bodyId` 选中天体）。查询参数：

| 参数 | 含义 | 缺省 |
|------|------|------|
| `from` | 观测天体 id（须有可解的自转轴） | 世界的 `target_body_id` |
| `lat` / `lon` | 观测点纬度/经度（度） | 0 / 0 |
| `at` | 时刻 = 历元 + N 天（松手/暂停时写回 URL） | 0 |
| `mode` | `pan`（环视）/ `disc`（全天） | `pan` |
| `look` | 环视视向 `az,alt`（拖动/缩放结束时写回） | 自动对准最亮天体 |
| `fov` | 环视竖直视场（度，15–120） | 90 |
| `grids` | 网格 CSV：`alt`（地平）`eq`（赤道）`ecl`（黄道线） | 无 |
| `panels` | 右侧弹出面板（单选）：`below`（地平下列表）`almanac`（升落年历） | 无 |
| `branch` | 分支 | 基础世界 |

## 图面约定

**环视**是自然透视：面向北时东在右手边、天顶在上方，与站立观天的直觉一致；
地平线是一条曲线，地面在其下方，方位刻度沿地平线展开。

**全天圆盘**采用**仰视惯例**（planetarium convention）：**北在上、东在左**、
南在下、西在右。这与俯视地图的「东在右」相反——因为你是躺着抬头看天：面向
北时，东在你的左手边。方位角从北起顺时针（N 0° → E 90° → S 180° → W 270°），
天体沿此投影到圆盘上。

时间读数「自历元 N 天 + 0.42 太阳日」与表盘 HH:MM 是**历元相对日钟**：
0.0 = 历元时刻（非本地子夜）。本地时区的正午/子夜口径需要时角数学，
属后续改进；太阳日长度显示在左栏（自转轴来源旁）。

## 操作指南

| 操作 | 方式 |
|------|------|
| 唤出/隐藏 UI | 移动鼠标（静置 ~2.5 s 后 UI 淡出，只剩天空） |
| 环视（转头） | 在天空上**拖动**（抓取天空：拖右天空右移；移动端单指拖动） |
| 缩放视场 | 滚轮；移动端双指捏合（竖直视场 15°–120°） |
| 选择天体 | 单击天体 — 左上弹出信息面板；单击空白天空取消 |
| 悬停预览 | 鼠标悬停标记 — 高亮 + 名称标签 |
| 观测设置 | 左侧工具条 📍 — 观测天体 / 纬度经度 / 分支 |
| 显示设置 | 左侧工具条 🧭 — 环视/全天切换、坐标网格、信息面板、图例 |
| 换时刻 | 底部悬浮条天数输入框直接键入（回车确认），或播放 |
| 播放速度 | ▶ 旁的对数滑条（0.01–10 太阳日/秒，随时可调） |
| 切换时间单位 | 表盘旁「太阳日/地球日」小按钮 |
| 帮助 | 左侧工具条 ？（新窗口打开帮助页天球节） |

## 静态模式限制

天球视图是**参数化引擎查询**（时刻 × 观测点 × 观测者的任意组合都要现算），
静态导出（GitHub Pages）不提供：页面显示提示面板。本地运行
`dreamulator serve` 后访问即可。

## 数据端点

`GET /api/worlds/{world}/sky`（参数同上表 + `targets` CSV 过滤 +
`include_events=false` 快路径——拖动/播放时前端用它，升落字段返回 null）。
错误口径：404 = 世界或观测者不存在；422 = 参数越界或该天体自转轴
不可解（错误信息带引擎原文）。参数细节见 serve 后的 OpenAPI 文档
（`http://localhost:8000/docs`）。
