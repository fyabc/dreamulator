# 3D 恒星系可视化器

前端内置的交互式 3D 恒星系查看器，基于 Three.js（通过 `@react-three/fiber` +
`@react-three/drei`），以**真实天文比例**渲染恒星、行星、轨道和宜居带。

> 架构与设计说明（文件结构、真实比例设计、标签去重叠算法）见
> [design/frontend-3d-viewer.md](../design/frontend-3d-viewer.md)。

## 功能概览

- **真实比例渲染**：所有距离以 AU 为单位，天体半径按真实物理尺寸
- **Leader line 标注系统**：十字准星 + 引线 + 文字标签，亚像素级天体可定位
- **动态缩放极限**：从 200 AU 系统全景到聚焦天体半径的 1.5 倍（自适应）
- **宜居带可视化**：半透明绿色环 + 凝结线标记
- **天体信息面板**：单击天体查看分组详情（轨道 / 物理 / 自转与季节 /
  大气与水文 / 辐照与温度 / 岩石圈 / 地形摘要）；有地图数据的行星
  可从面板直接进入 **3D 球面查看器**或 2D 地图（球面视图支持昼夜光照、月度模式、
  风/洋流箭头——操作见 [map-workflow.md](map-workflow.md) 第 4 节）
- **URL 状态同步**：选中的天体写入 `?focus=` 参数，刷新或分享链接可回到
  同一聚焦视野
- **分支感知**：自动加载分支世界的恒星/行星数据
- **静态模式兼容**：GitHub Pages 上完全可用（无需后端）

## 访问方式

侧栏「🔭 3D 视图」入口或直接访问 `/worlds/:worldName/viewer3d`
（`?branch=` 选择分支，`?focus=<body_id>` 定位天体）；
3D 球面视图缩小到尽头也会过渡到恒星系视图（反之可从信息面板进入球面）。

## 操作指南

| 操作 | 方式 |
|------|------|
| 旋转视角 | 鼠标左键拖拽 |
| 缩放 | 鼠标滚轮 |
| 平移 | 鼠标右键拖拽 |
| 查看天体信息 | 单击标签或天体 — 弹出信息面板，镜头飞向并居中该天体 |
| 立即居中天体 | **双击**标签或天体（不改变缩放距离） |
| 聚焦并拉近 | 信息面板「🎯 聚焦并拉近」按钮 — 居中并拉到 ~4 倍天体半径 |
| 快速选择天体 | 页首天体下拉（恒星 + 天体分组）— 所有条目统一为聚焦并拉近；🌐 仅标记有地图数据（进入球面/地图用信息面板按钮） |
| 取消选中 | 点击空白区域 |
| 进入行星球面/地图 | 信息面板中的链接（仅有地图数据的行星） |

## 数据端点

恒星系（`/stellar`）、行星（`/planets`）、宜居带（`/habitable-zones`）三个端点，
均支持 `?branch=`；参数细节见 serve 后的 OpenAPI 文档（`http://localhost:8000/docs`）。
静态模式下由预导出 JSON 提供（`scripts/release/export_static.py`）。
