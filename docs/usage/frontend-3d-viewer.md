# 3D 恒星系可视化器

前端内置的交互式 3D 恒星系查看器，基于 Three.js（通过 `@react-three/fiber` +
`@react-three/drei`），以**真实天文比例**渲染恒星、行星、轨道和宜居带。

> 架构与设计说明（文件结构、真实比例设计、标签去重叠算法）见
> [design/frontend-3d-viewer.md](../design/frontend-3d-viewer.md)。

## 功能概览

- **真实比例渲染**：场景以天文单位（AU）计量，天体半径使用真实尺寸。画布下方显示比例和当前视距。
- **Leader line 标注系统**：十字准星 + 引线 + 文字标签，亚像素级天体可定位
- **天体名称**：场景标签、聚焦菜单和详情使用与[天球视图](sky-viewer.md)相同的译名。没有译名的天体保留目录原名。
- **动态缩放极限**：从 200 AU 系统全景到聚焦天体半径的 1.5 倍（自适应）
- **宜居带可视化**：半透明绿色环 + 凝结线标记
- **天体信息面板**：点击场景里的天体或标签会打开详情，可查看轨道、物理参数、季节、气候和地形等分组。
  选中的天体有地图数据时，页首才会显示「前往平面地图」和「前往球面地图」。地图操作见[地图工作流](map-workflow.md)第 4 节。
- **URL 状态同步**：选中的天体写入 `?focus=` 参数。刷新或分享链接后，镜头仍对准该天体，但不恢复自定义缩放。
- **分支感知**：自动加载分支世界的恒星/行星数据
- **静态模式兼容**：GitHub Pages 上完全可用（无需后端）

## 访问方式

侧栏「🔭 3D 视图」入口或直接访问 `/worlds/:worldName/viewer3d`
（`?branch=` 选择分支，`?focus=<body_id>` 定位天体）；
3D 球面视图缩小到尽头也会过渡到恒星系视图。可以从恒星系页首返回该天体的球面图。

## 操作指南

| 操作 | 方式 |
|------|------|
| 旋转视角 | 用鼠标左键或单指拖拽。 |
| 缩放 | 用鼠标滚轮或双指捏合。 |
| 平移 | 用鼠标右键拖拽。 |
| 选中并居中 | 点击天体或标签，或者从页首下拉菜单选中天体。镜头会居中，不会自动拉近。 |
| 查看轨道 | 对有轨道数据的天体点击「查看轨道」，画面会收起详情，并同时显示母天体与整条轨道。高亮轨道上的准星指向选中天体的位置。 |
| 近看天体 | 对有半径数据的天体点击「近看天体」，镜头会按本体大小取景。此时不保证整条轨道可见。 |
| 查看天体详情 | 点击场景中的天体或标签会打开详情。若从下拉菜单选中天体，可以点击「天体详情」。关闭详情不会清除选中的天体。 |
| 取消选中 | 点击空白处，或在下拉菜单中选择「未选中天体」。 |
| 进入球面或平面地图 | 选中有地图数据的天体后，点击页首对应的地图链接。两个链接都保留当前世界分支。 |

## 数据端点

恒星系（`/stellar`）、行星（`/planets`）、宜居带（`/habitable-zones`）三个端点，
均支持 `?branch=`；参数细节见 serve 后的 OpenAPI 文档（`http://localhost:8000/docs`）。
静态模式下由预导出 JSON 提供（`scripts/release/export_static.py`）。
