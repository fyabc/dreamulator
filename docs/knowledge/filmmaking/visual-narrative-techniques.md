# 影视视觉叙事手法（本库视频链适用的技法目录）

> 本目录收录与本项目视频链（世界伪纪录片、开发实录、数据可视化）相关的影视
> 手法：术语、代表作出处、以及在本项目中的适用性。手法描述为通用知识；「适用」
> 一栏绑定本项目的资产（渲染链、FUI 管线、双声部旁白、博物馆叙事框架）。所引
> 的视频计划为私有文档，不入公开库。

## 1. FUI（Fantasy/Fictional User Interface）

界面化的科幻显示手法，影视工业通称 **FUI**，也叫 Screen Graphics / HUD
Overlay：把「未来系统的界面」作为画面元素直接参与叙事。

| 元素 | 专业叫法 | 代表作 |
|------|----------|--------|
| 十字聚焦框 | Targeting Reticle / Lock-on Brackets | 《钢铁侠》HUD、《流浪地球》 |
| 透明数据窗 | Holographic Callout / Data Readout Panel | 《普罗米修斯》《苍穹浩瀚》 |
| 逐字打出 | Teletype / Typewriter Decode Effect | 《火星救援》《星际穿越》 |

制作要点：等宽字体（JetBrains Mono / Share Tech Mono / IBM Plex Mono）；
音效三件套 = 伺服锁定声（servo lock）+ 面板弹出 blip + 打字 tick；搜索关键词
`Sci-fi HUD After Effects template`、`FUI design`、`target lock HUD overlay`。

**本项目适用**：系列一里 FUI 是界内机构（未来勘测探针存档终端）的观测者界面，
不是开发者界面——这保住「引擎不存在」的纪录片铁律。数据卡由 JSON 管线从
yaml/derived 自动生成（杜绝手敲幻觉），详见视频计划 §1.6 的巡天异常结构与
§四-C 镜头 #12。

## 2. 匹配剪辑（Match Cut / Graphic Match）

用图形、动作或色彩的相似性把两个时空直接缝合的转场，最著名的范式是
《2001 太空漫游》骨头→轨道站（图形 + 语义双匹配）。变体：图形匹配叠化
（match dissolve）、动作匹配（action match cut）。要点是**让相似元素在剪辑点
前后占同一画面位置、同一运动方向**，观众的眼睛"没有断"。

**本项目适用**：贝壳三珠→三星连珠（色彩金琥珀/红褐/灰白 + 张壳弧线双匹配）；
潮坪水洼→轨道视角等一切「微观即宏观」的尺度跳跃。

## 3. 天体运动转场（本系列的原生手法）

- **食既黑场（eclipse cut）**：全食把昼半球推入黑暗——巨神星盘面扫过恒星本身
  就是一次**遮挡擦除（object wipe）**，食甚 = 天然黑场，可以无痕切到任何场景；
  配合心跳骤停的听觉签名，是本系列自有的万能转场。
- **锁定框转场（reticle wipe）**：FUI 十字框从上一场景目标"滑"到下一场景目标
  并落锁——界面语言兼任转场语言。
- **盈亏擦除（phase wipe）**：巨神星相位从满到新的动画遮罩，适合时间跨度大的
  章节切换（潮汐锁定下相位即钟表）。

## 4. 声音主导的衔接（J-cut / L-cut 与声桥）

下一场景的声音先于画面进入（J-cut）或上一场景的声音延续过切点（L-cut），
统称 split edit；纯声音过渡即**声桥（sound bridge）**。旁白密度本身作转场语言
（档案员 110–130 词/min → 宇宙声部 50–70 词/min 的滑落）与声桥叠加，可以做到
"台词没说完，世界已经换了"。

## 5. 尺度穿行（Powers of Ten / 无缝变焦）

从微观到宏观（或反向）的连续变焦，范式是 1977 年《Powers of Ten》短片与
《宇宙时空之旅》的 ship-of-the-imagination 变焦。要点：每级尺度给一个可辨识的
锚（水洼→海岸线→行星→系统），变焦速度本身表达情绪（快=惊奇，慢=庄重）。

## 6. 档案质感分层（archive degradation）

把「不同年代的素材」做出不同的技术质感：早期勘测 footage 用低分辨率、扫描线、
胶片颗粒与丢帧；当代档案用干净渲染。两种质感并置，博物馆的时间纵深就有了
画面证据——观众不需要台词就知道「这份档案更老」。可叠加 datamosh 等数字
故障风格，但克制使用。

## 7. 图层揭片（progressive layer disclosure）

地图/星球像「揭片」一样逐层叠加或剥离（地形→气候→生态→文明），每层一次
信息增量。与媒介语体切换（同一颗星球在不同图层呈现为不同质感）天然配合；
Tufte 的 small-multiples（同构小多图）用于跨世界/跨纪元对比。

## 8. 数据自证动画（data-driven counters）

数字与图形直接由数据文件驱动逐帧变化（计数器滚动、等值线生长、粒子流平流），
而非后期手摆。这是本项目相对常规视频的最大优势：每个动态数字都可溯源到引擎
输出（粒子流、云流平流、板块回溯三条链已入库）。

## 9. 静帧长拍（slow-burn static frame）

数秒不动的静止构图配环境声，用于「静息期」段落与闭馆前的留白；与快速剪辑
段落形成呼吸对比。Tarkovsky 式长拍的克制版本。

## 10. 转场之外：叙事容器手法

- **分屏对照（splitscreen）**：因果并置（左潮汐加热右板块运动）；科普片常用，
  但博物馆语体下优先单帧图层而非分屏。
- **片头字卡统一制式**：每集标题卡 = 展厅展签，制式统一形成系列识别。
- **重复母题（motif）**：心跳、闭馆语、三珠、π 彩蛋——母题在系列内的每次
  变奏都是给老观众的暗号。
