## 1. 冰盖高程的计算阶段

冰盖高程同时受长期冰量历史、积累、消融与冰流影响。地质层提供基岩与初始冰量，
气候计算采用明确的地表边界，现今冰面则按同一来源的物质平衡与动力学更新。

- 地球南极没有冰盖的话，裸岩平均高程在海平面附近（Bedmap2 基岩面大部分低于
  0 m）；实测冰面均值 ~2048 m、平均冰厚 ~2.1 km——**冰盖贡献了南极大陆几乎
  全部的高程**（Fretwell et al. 2013）。
- 地质层的含冰 `elevation` 是气候模式的参考边界，温度递减率和反照率计算消费这一地表。
  固定气候之后的冰面更新属于下游地表产品，保存基岩、冰厚与冰面三个状态量。
  气候与冰盖的长期反馈由明确的联合求解阶段承担，构建图中的层间依赖保持单向。
- 现有地质冰量追加在地形合成之后，冰量只放在来源陆地上，海平面校准保持原值。
  受载基岩由 `elevation − ice_thickness_m` 恢复。气候约束的试点使用固定受载基岩，
  地质网格与大气模式边界继续保存其参考版本。

### 1.1 冰载荷均衡

冰载荷按局地 Airy 均衡压低基岩：冰厚 H 使基岩下沉 H·ρ_i/ρ_m ≈ 0.28·H（ρ_i = 917、ρ_m = 3300 kg/m³），
冰面只比无冰基岩高 0.72·H。冰盖宽数千公里，远大于岩石圈约 100–150 km 的挠曲波长，局地补偿在冰缘以外成立；
地幔回弹的时间尺度约 1 万年，长期存在的冰盖处于完全补偿。地球上南极与格陵兰的大片基岩因此低于海平面
（Bedmap2）。冰面仍高于无冰基岩，所以没有陆地格因此变成海洋；重跑时先把下沉量补回再重算，保持幂等。
认识论类别：守恒定律加观测约束的密度。

### 1.2 冰面与冰下基岩的高程语义

冰面高程 s、受载基岩高程 b 与冰厚 H 满足 s = b + H。按上述局地完全补偿近似，
无冰卸载基岩高程为 s − (1 − ρ_i/ρ_m)H；它与当前受载基岩 s − H 是不同的情景。
地形对照需要选择相同的表面：Copernicus 数字表面模型记录地表，冰盖处对应冰面；
Bedmap2 则分别提供南极冰面、冰厚和冰下基岩（Fretwell 等 2013）。

冰面局地起伏由冰流、物质平衡和基底条件共同决定。基底起伏向冰面的传递取决于起伏波长相对冰厚的比例
和底部滑动条件（Gudmundsson 2003），厚冰内部与冰缘、出口冰川及裸岩露头需要分别验收。
高程生成方法即使使用含冰的粗尺度输入，也需要验证最终冰面的坡度与分尺度起伏；
高清基岩的恢复还需要同尺度冰厚或独立基岩来源。以地形数据训练的生成模型若以含冰地表为条件，
会把冰盖当作岩石高台生成，冰退去后留下冰盖轮廓的痕迹；生成岩石时应以基岩高程为条件，冰另行叠加。

浅冰近似的等温、无滑动形式为 q = −2A/(n+2) (ρ_i g)ⁿ H^(n+2) |∇s|^(n−1)∇s，
并用 ∂H/∂t = a − ∇·q 计算冰厚，a 是积累减去消融的净物质平衡。Glen 指数 n 常取 3，
温冰参考速率因子 A 为 2.4×10⁻²⁴ Pa⁻³ s⁻¹；极地冰内温度与底部滑动需要另外解释。
冰面坡度控制驱动应力，冰厚则以 H⁵ 进入变形通量。因而基岩与冰面上的同一处起伏，
对薄冰和厚冰会产生不同的动力响应（Cuffey & Paterson 2010；PISM）。

地质亚格子起伏可作为基岩的统计先验，生成纹理与独立观测有不同的认识论地位。
浅冰近似的有效尺度还受基底起伏波长约束，粗糙基底的高阶应力可用 Schoof（2003）的参数化处理。
实现的局部冰量重分配原型为 `src/dreamulator/map/canvas_ice_surface.py`，采用成对有限体积交换，
封闭边界和零净物质平衡，用于固定现有冰量的形态试点。

### 1.3 气候物质平衡与正度日近似

正度日方法把消融量近似为高于融点的温度积算量乘以度日因子。月均温 T 与显式给定的
温度标准差 σ 对应高斯温度分布时，正温度期望为
`σ φ(T/σ) + T Φ(T/σ)`；φ 和 Φ 分别是标准正态分布的密度与累积概率。
这一表达式保留月均温低于融点时的暖天气消融（Calov 与 Greve 2005；PISM）。

画布试点从已定版高频 GCM 的近地面气温计算相位分箱内的方差。降雪比例用低于 0 °C 的概率近似，
降水在该温度分布内均匀取样是本试点的相态假设，原生 GCM 降雪作为独立的模式过程核对。
雪和裸冰的度日因子分别采用 3 和 8 mm 水当量/(K·日)，来源为 PISM 的 EISMINT 观测参考。
该拟合的标定域是地球冰盖，其在不同恒星光谱、自转与地表能量条件下的适用性需要另行验证。

每个月先积累降雪，再消融季节雪，剩余正积温用于消融已有冰。消融量受现有储量限制，
年末保留的雪以冰当量储量记录，融水直接计入径流。粒雪密度、再冻结和冰内热状态属于后续热力学任务。
十二个相位月的积算使用既有的 365.25 日参考年口径；轨道年决定季节相位，模型时间以物理秒和年记录。
实现为 `src/dreamulator/map/ice_mass_balance.py`，方法与参数来源见
[PISM 地表物质平衡文档](https://www.pism.io/docs/climate_forcing/surface.html)。

### 1.4 积累柱的基底热状态

Robin（1955）的稳态冰柱以固定冰厚 H、正积累率 a 和地表温度 T_s 近似冰分水岭。
以基底为 z = 0、冰面为 z = H，垂向速度为 w = −az/H，
导热与平流满足 κT″ − wT′ = 0。κ = k/(ρ_i c_i) 是冰的热扩散率，
底部向上的热通量 q 对应 T′(0) = −q/k。
在常数材料性质下，基底温升为 qL/k，其中
`L = H ∫₀¹ exp(−Pe u²/2) du`，`Pe = aH/κ`，a 使用 m/s。
积累为零时 L = H，恢复线性导热；积累增加时，向下输送的冷冰降低基底温升。

基底压力融点相对于地表零压参照为 T_m = −βρ_i gH。
参考常数为 k = 2.1 W/(m·K)、c_i = 2009 J/(kg·K)、β = 7.9×10⁻⁸ K/Pa，
融化潜热 L_f = 3.34×10⁵ J/kg，取自 PISM 的冰材料参数。
保持基底在压力融点所需的冷柱导热为 `q_c = max(k(T_m − T_s)/L, 0)`。
超过 q_c 的热量可用 `max(q − q_c, 0)/(ρ_i L_f)` 表达融化潜力，并与实际冰量变化分开保存。

这一诊断忽略水平平流、应变与摩擦加热，以及基底融化造成的垂向速度变化。
它适用于缓坡积累区的热状态敏感性，完整温底柱、出口冰川和历史瞬态需要相应热力学求解。
厚冰的导热时间约为 H²/κ，可用来判断某段历史是否适合稳态近似。
全球内部热释放与局部基底导热各有预算，火山带出的热量需要热传播依据才能作为冰床强迫。
实现为 `src/dreamulator/map/ice_thermal_column.py`，计算阶段见画布管线第2.5.7节。

### 1.5 全球冰量的约化估算

月气候的净物质平衡可以提供积累区，积累、几何尺度和冰流共同决定平衡冰厚。
在平底、一维对称冰盖、均匀积累 a 与 Glen 指数 n = 3 的浅冰近似下，
距分水岭 x 的通量为 ax，令 `C_sia = 2A(ρ_i g)³/5`，稳态 Vialov 剖面满足
`H^(8/3) = 2(a/C_sia)^(1/3)[L^(4/3) − x^(4/3)]`。
L 为半宽，a 使用 m/s，A 为 Glen 速率因子。该剖面同时包含积累、流变、重力与几何尺度，
完美塑性剖面则由固定驱动应力定义，两者采用各自的物理假设（Cuffey 与 Paterson 2010；Mikkelsen 等 2018）。

全球粗估可将连通净积累区作为等效冰盖，以到边缘的距离定义剖面尺度，并按实际格面积积分体积。
净积累的总输入记为 A₊，等效平衡体积记为 V_eq。
在固定水平几何与流变条件下，浅冰变形通量对冰厚为八次方标度，
可用 `dV/dt = A₊[1 − (V/V_eq)^8]` 表达储量与集中输出的响应。
该式将消融边缘、流动与海洋出口合并为输出项，平衡点为 V_eq；源、输出与体积变化共用一本账。
参考态附近的局部恢复时间为 V_eq/(8A₊)，从很小冰量开始的积累时间则约为 V_eq/A₊。

这种闭合用于全球体积量级与历史时序检查。平底等效几何、固定气候参考面和温冰流变均属于明确近似；
现今空间冰厚、陡峭出口、漂浮冰架、山岳冰川和冰面气候反馈采用相应求解。
冰的体积与覆盖面积分别记录，海冰、陆地冰和漂浮冰架按各自口径比较。
地球观测气候和冰体积提供独立量级检查，时间步长与体积预算提供数值检查。

### 1.6 冰川侵蚀的时间尺度

冰体对气候的响应与基岩地貌的调整具有不同时间尺度。
Herman 等（2018）的理论与数值模型得到约 10 年至 1 万年的冰体响应，
地貌侵蚀的调整时间约为 1 万年至 1000 万年，受积累率、抬升与地形控制。
具体侵蚀深度还需累计有效温底滑动时间，并考虑岩性与沉积输送。

Hallet 等（1996）的野外资料显示，流域平均侵蚀率跨多个数量级。
极地冰川与晶质基岩上的薄冰平台可约 0.01 mm/yr，坚硬基岩上的温冰谷地可约 0.1 mm/yr，
大型快速温冰川可达 10–100 mm/yr。下表按 `时间 = 切深/速率` 给出量级，
速率在整个时段保持不变是表格的换算假设，流域沉积产率与局地谷底切深采用各自口径。

| 代表侵蚀率 | 切深 100 m 的累计时间 | 切深 500 m 的累计时间 |
|---|---|---|
| 0.01 mm/yr。 | 约 1000 万年。 | 约 5000 万年。 |
| 0.1 mm/yr。 | 约 100 万年。 | 约 500 万年。 |
| 1 mm/yr。 | 约 10 万年。 | 约 50 万年。 |
| 10 mm/yr。 | 约 1 万年。 | 约 5 万年。 |

Kessler 等（2008）的二维模型在约 100 万年内形成峡湾，机制是原有谷地引导集中冰流并加强侵蚀。
Koppes 等（2015）表明温度和融水通过滑动条件影响侵蚀率。
冷底覆冰可以长时间保留基岩，温底出口则更容易集中改造谷地。
冰量历史用于约束冰的存在，侵蚀历史还需温底、滑动速度、岩性与有效持续时间。

### 1.7 共享求解域与固定海岸输出

浅冰近似的体积通量为 `q = −2A(ρ_i g)³H⁵|∇s|²∇s/5`，
连续方程按每个格子的实际面积积分。球面 Voronoi 格子的格心连线垂直于公共大圆边，
公共边长度乘法向通量给出交换体积率；相邻格的体积交换相消。
法向高差与切平面最小二乘梯度共同估计完整冰面梯度，供冰侧厚度用于保持干格边缘非负。
这一有限体积试点沿用浅冰守恒方程，数值方法与 Bueler（2016）的有限体积单元法分别解释。

固定海岸可以采用吸收边界，冰体进入参考海洋时从陆地储量中移除，并计入固态海洋输出。
PISM 的固定范围崩解选项提供这一简化边界的参照。
海洋格本身保持无冰，地表融水与固态输出采用不同的预算项。
这一边界用于陆地冰储量与封闭海岸对照；漂浮冰架、前缘应力和真实崩解速率采用相应动力学。
跨画布计算共用全球公共边，截图与地形分块仅决定输出取样范围。
实现及来源版本语义见画布管线第2.5.8节。

### 1.8 亚格子冰面与固定气候响应

细尺度积累与消融需要使用同一参考高程。父格的平均高程会遗漏山顶冷区，
地表订温按实际高差应用已采用的温度递减率，降雪与正度日继续按第1.3节计算。
固定月气候下，令G为年末保留雪，D为先融雪之后的裸冰消融潜力，两者以冰当量米表示。
年度递推为`H_next = max(H − D, 0) + G`。
重复N年的全年最小裸冰储量为`max(max(H_initial − D, 0) + (N − 1)(G − D), 0)`，
最后一年的新雪G与这一最小储量分别保存。闭式解减少重复计算，固定高程和月气候是其成立条件。

细尺度延拓既要保持冰量，也要表达薄冰与厚冰的不同响应。
等面积基岩样本b与格内平均冰厚H给出几何条件`mean(max(s − b, 0)) = H`。
解得的水平面s是体积对应的几何闭合；动力学决定冰量及实际响应程度。
薄冰的变形缓慢，来源积累分布可在短时响应内保留；厚冰的浅冰通量对H为五次方依赖。

对一维浅冰方程，令地表起伏为`a cos(kx)`，固定局地冰厚H，
并将非线性项投影到该基频，可得`da/dt = −3 C H⁵ k⁴ a³/4`，
其中`C = 2 A (ρ_i g)³/5`。初始方差为σ²、即`a_initial² = 2σ²`时，
保留的振幅比为`[1 + 3 C H⁵ k⁴ σ² t]^(−1/2)`。
未解析起伏的最长波长取求解网格的奈奎斯特波长2Δ，因而`k = π/Δ`。
这一单模式浅冰闭合使用已有的流变、冰厚、起伏、格距与模型时间，
用于连接来源地表与已求解冰面。高阶应力、滑动及多模式耦合属于相应动力学的适用范围。
原生延拓的非负冰厚与每个连通冰体的体积仍独立核对。

实现为`canvas_ice_surface.py`的`subgrid_ice_surface_level`与`subgrid_ice_relaxation_fraction`，
固定气候储量接口位于`ice_mass_balance.py`。生产范围、短时响应与来源语义见画布管线第2.5.9节。

### 1.9 冰盖的海洋边界：连通外海与静水接地

冰盖腹地的基岩低洼处冰最厚。冰沿冰面坡度流向低处，先填满谷地，因此低于海面的
冰下基岩在现实中很常见：南极西部的大片冰床位于海面以下，最深处在海面以下两千多米，
这些地方都被连续冰盖覆盖（Fretwell 等 2013）。海面以下的高程本身不会让冰消失，
冰只会在海水足以把它浮起时离开床面。

海水只存在于与外海连通的位置。内陆低于海面的洼地如果没有水路通向海洋，就没有可以
浮起冰的海水；它在冰下属于普通的接地冰床，冰外则是陆上洼地或湖盆。连通外海的位置，
冰按静水平衡判断是否接地：当冰厚H满足`H ≥ (ρ_w/ρ_i) d`时冰压在床面上，d为水深。
取海水密度ρ_w = 1028 kg/m³与冰密度ρ_i = 917 kg/m³，接地所需的冰厚约为水深的1.12倍，
相当于冰面至少高出海面`0.121 d`。不满足这一条件的冰会漂浮；冰架需要单独的应力平衡，
这里将其作为入海输出记账。PISM 用同一浮力判据区分接地冰与漂浮冰，海水密度参数默认取
1028 kg/m³（PISM 基底强度文档）。
这一判据是守恒定律层面的闭合，标定量只有两种密度。

细尺度画布上，连通外海的水域常以窄水道的形式伸入冰盖，宽度远小于冰流求解网格。
窄水道两侧是厚冰，冰面落差接近整个冰厚，侧向蠕变很快把它填满。沿用第1.8节的单模式
浅冰闭合，把宽度为w的水道看作半个波长，取`k = π/w`；水道底相对冰面的亏缺量为d时，
余弦振幅为d/2，方差为`d²/8`。保留的亏缺比例为`[1 + 3 C H⁵ k⁴ d² t/8]^(−1/2)`，
H取求解格的冰厚。水道宽度用形态学局地厚度测量，即覆盖该像素的最大内切圆直径
（Hildebrand & Rüegsegger 1997）。宽度达到求解格距的水域属于已解析的开阔海域，
由求解网格的封闭海洋面处理。由于响应随`k⁴`变化，几公里宽、两侧冰厚数百米以上的水道
在十年内即可填满，而开阔海岸外的海面不受影响。填入的冰再按上式检查接地。
这一闭合描述冰体内部的水道。海岸处冰前缘的位置取决于崩解、前缘应力与冰缘剖面，
单模式闭合不能预测，因此靠近开阔海面的水道仍按开阔水面处理（PISM 崩解文档）。

海陆的划分因此由连通性和浮力共同决定，不再取决于高程的正负号。只按高程正负号划分海陆时，
冰盖内部被河谷刻到海面以下的像素会被当作海洋，形成冰盖中的无冰裂缝，这在物理上不成立。

实现为`canvas_marine.py`：`connect_sea`按存储分块做四连通的外存连通性判定，
`water_width_px`计算水道局地宽度，`channel_fill_fraction`给出水道填充比例，
`grounded_ice`给出静水接地判据。生产接入见画布管线第2.5.10节。

## 2. 日照门（热限，无量纲）

冰盖能在某个纬度存活，经典控制是**入射日照**（米兰科维奇理论的核心机制：
夏季日照不足 → 冰不消融 → 冰盖生长）。实现取年平均大气顶（TOA）日照作为判据：

```
逐日平均日照（Hartmann 2016 式 3.7）：
Q_day = (S₀/π)·[H₀·sinφ·sinδ + cosφ·cosδ·sinH₀],  H₀ = arccos(−tanφ·tanδ)

年平均：δ = ε·sin L，L 在一个轨道周期上均匀取样平均（圆轨道；
偏心率对年平均的影响是二阶小量，~e²/2，地球 e=0.017 → +0.014%）。

太阳常数（世界相关）：S₀ = 1361 W/m² · L_star/L_sun / d²_AU
```

判据用**无量纲比值** `q̄(lat)/q̄(equator) < f`（默认 f = 0.50），而不是绝对
W/m²。原因（已否证方向的教训）：nacrea 的 S₀ ≈ 830 W/m²（L = 0.076 L_sun，
d = 0.353 AU），绝对阈值 240 W/m² 相当于其 S₀ 的 29%（地球只有 17.6%）——门
被推到 ±45°，全球过冰（雪球）。无量纲阈值随恒星自动标定：

| 世界 | ε | S₀ (W/m²) | f = 0.50 的穿越纬度 |
|------|---|-----------|---------------------|
| 地球 | 23.44° | 1361 | ~67°（南极洲在门内，北极圈沿岸在外） |
| nacrea | 14.9° | ~830 | ~62°（小倾角使极区相对更暗，门更宽） |

年平均日照的纬向分布只依赖 ε 与 S₀，不依赖世界其他参数——这是一个**近似推导**
类闭合（Milankovitch 控制的粗粒化）。

## 3. 海陆分域：南北不对称的来源

地球两极的冰盖形态截然不同：北极圈陆地是苔原/局部冰帽（斯瓦尔巴、加拿大北极
群岛），南极是连续大陆穹丘。差异**不是天文的**（两极日照对称），而是**地理的**：
北冰洋是一个海洋热源，持续加热沿岸陆地；南极大陆的中心离海超过一千公里。

实现用「到最近海洋的测地距离」作为海洋热源的代理（多源 Dijkstra）：

- 距海 > `ice_maritime_distance_km`（700 km）→ 大陆内部，建完整穹丘；
- 门内但近海 → 只在雪线以上长局部冰帽（数百米厚，斯瓦尔巴式）。

地球锚点：加拿大北极/西伯利亚苔原海岸距海 < ~500 km；南极 Dome A 距海
~1200 km（接近南极难抵极）。700 km 落在两者之间，是**观测拟合**类参数。

### 3.1 球面距离与数值坐标

图的邻接边长由两端的球面方向计算。对有限、非零的笛卡尔向量 a 和 b，中心角为
`θ = atan2(|a×b|, a·b)`，物理边长为行星半径乘 θ。
两个向量的正径向缩放同时乘到叉积长度和点积上，角距因此保持不变。
这一表达在较小角距下也具有稳定的数值条件；方向的有限精度与向量长度的截断分别解释。
实现使用 `ice_sheets._edge_angles`，距离语义在原精度输入和导出输入之间保持一致。
推导及参考实现见 [Vector-based spherical geodesy](https://www.movable-type.co.uk/scripts/latlong-vectors.html)。

由此，世界的南北不对称从海陆分布中**涌现**，而非硬编码半球：nacrea 北极是
大陆核心（距海远 → 穹丘），南半球暮光大陆是被海道切开的群岛型大陆（全境近海 →
只有冰帽）——同一套物理在两个半球给出不同形态，正如地球。

## 4. 完美塑性穹丘剖面

### 4.1 推导

完美塑性近似（perfect-plastic approximation）：冰的变形在底部剪应力达到屈服
值 τ_d 时发生，且到处都达到（冰盖内部应力近似塑性极限）。对厚度 h(x)、
x 为到冰缘距离的一维柱体，driving stress 与底部阻力平衡：

```
ρ_i·g·h·(dh/dx) = τ_d   →   h·dh = (τ_d/ρ_i·g)·dx   →   h² = 2·τ_d·x/(ρ_i·g)

h(x) = √(2·τ_d·x / (ρ_i·g))        （固定驱动应力的完美塑性剖面）
```

剖面的几何特征是抛物线形穹丘：边缘薄、向中心按 √x 增厚，与实测冰盖剖面一致
（Cuffey & Paterson 2010 ch. 8）。**世界重力直接进入分母**——重力更大的世界，
同样的驱动应力下冰更薄（h ∝ 1/√g）。

### 4.2 参数与数值例

| 参数 | 地球值 | 来源 |
|------|--------|------|
| 冰密度 ρ_i | 917 kg/m³ | Cuffey & Paterson 2010 |
| 驱动应力 τ_d | 50–100 kPa（观测冰盖范围） | Cuffey & Paterson 2010 ch. 8 |
| 实现默认 | 40 kPa（低端柔和剖面，nacrea 标定） | 观测拟合 |

数值例（地球）：τ_d = 50 kPa、半宽 x = 1800 km →
h = √(2·5×10⁴·1.8×10⁶ / (917·9.81)) ≈ **4.4 km**——与 Dome A 实测冰面
4093 m 同量级（Fretwell et al. 2013）。

nacrea 实测（g = 10.28 m/s²）：北极核心（≥77°N）冰面均值 ~2320 m（对标
Bedmap2 南极均值 2048 m）、峰值 ~4856 m；穹丘边界取「穹丘子图内到非穹丘 cell
的测地距离」，子图隔离保证冰只在陆上传播、绝不穿过海洋。

### 4.3 冰帽（近海边缘）

门内近海陆地的局地冰帽取线性雪线超额的减半并封顶：

```
h_cap = min((bed − snowline)·0.5, cap_max)    （snowline = 1200 m, cap_max = 500 m）
```

纯**观测拟合**（斯瓦尔巴/北极群岛冰帽厚度为数百米量级），无第一性推导。

## 5. 已知近似与已否证方向

**近似（当前接受）**：

- 积累假定充足：寒冷极区在 Myr 尺度即使低降水也持续积累（参照南极内部干燥但
  冰盖存在）。门只看热量。
- 海洋热量输送只通过「距海」代理进入；极向热输送极端强的世界可能过冰。
  **交叉校验**：气候层中冰 cell 的年均温应 < 0 °C。
- 冰载荷均衡只取局地 Airy 完全补偿：冰缘约一个挠曲波长内的挠曲隆起与冰后回弹的
  瞬态不计。

**已否证方向**（失败根因，勿重试）：

- 绝对 W/m² 日照门 → 雪球（见 §2；必须无量纲）。
- 海洋份额的邻接扩散作为 maritime 代理 → 失败：0.5 自锚把陆地 cell 钉在 0，
  随机游走扩散只能走 √hops·cell 距离；必须用图上测地距离（Dijkstra）。
