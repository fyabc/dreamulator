## 1. 冰盖高程为什么在地质层做

冰盖是**地质时间尺度的地形**（大陆冰盖以数十 Myr 计），不是年际波动的气候态。
它改变的是行星的固体表面形态：

- 地球南极没有冰盖的话，裸岩平均高程在海平面附近（Bedmap2 基岩面大部分低于
  0 m）；实测冰面均值 ~2048 m、平均冰厚 ~2.1 km——**冰盖贡献了南极大陆几乎
  全部的高程**（Fretwell et al. 2013）。
- 高程是地质层的核心产品（板块 → 构造 → 地形 → 水系）；气候层是高程的消费者
  （温度递减率、冰面反照率）。冰盖高程放地质层，气候层直接读到含冰面的
  `elevation`，反馈链自然闭合（冰面更高 → 递减率更冷 → 冰更稳定）。
- 实现约束：追加在海平面校准 / 钉扎 / 均衡 / 平滑 / 河流**之后**，冰只堆叠在
  陆地 cell 上、海平面不动——**海岸线格局不受影响**；基岩可由
  `elevation − ice_thickness_m` 重建，重跑幂等。

## 2. 日照门（热限，无量纲）

冰盖能在某个纬度存活，经典控制是**入射日照**（米兰科维奇理论的核心机制：
夏季日照不足 → 冰不消融 → 冰盖生长）。实现取年平均大气顶（TOA）日照作为判据：

```
逐日平均日照（Hartmann 2016 式 3.7）：
Q_day = (S₀/π)·[H₀·sinφ·sinδ + cosφ·cosδ·sinH₀],  H₀ = arccos(−tanφ·tanδ)

年平均：δ = ε·sin L，L 在一个轨道周期上均匀取样平均（圆轨道；
偏心率对年平均的影响是二阶小量，~e²/2，地球 e=0.017 → +0.014%）。

太阳常数（世界相关）：S₀ = 1361 W/m² · L_star/L_sun / d²_AU
```

判据用**无量纲比值** `q̄(lat)/q̄(equator) < f`（默认 f = 0.50），而不是绝对
W/m²。原因（已否证方向的教训）：nacrea 的 S₀ ≈ 830 W/m²（L = 0.076 L_sun，
d = 0.353 AU），绝对阈值 240 W/m² 相当于其 S₀ 的 29%（地球只有 17.6%）——门
被推到 ±45°，全球过冰（雪球）。无量纲阈值随恒星自动标定：

| 世界 | ε | S₀ (W/m²) | f = 0.50 的穿越纬度 |
|------|---|-----------|---------------------|
| 地球 | 23.44° | 1361 | ~67°（南极洲在门内，北极圈沿岸在外） |
| nacrea | 14.9° | ~830 | ~62°（小倾角使极区相对更暗，门更宽） |

年平均日照的纬向分布只依赖 ε 与 S₀，不依赖世界其他参数——这是一个**近似推导**
类闭合（Milankovitch 控制的粗粒化）。

## 3. 海陆分域：南北不对称的来源

地球两极的冰盖形态截然不同：北极圈陆地是苔原/局部冰帽（斯瓦尔巴、加拿大北极
群岛），南极是连续大陆穹丘。差异**不是天文的**（两极日照对称），而是**地理的**：
北冰洋是一个海洋热源，持续加热沿岸陆地；南极大陆的中心离海超过一千公里。

实现用「到最近海洋的测地距离」作为海洋热源的代理（多源 Dijkstra）：

- 距海 > `ice_maritime_distance_km`（700 km）→ 大陆内部，建完整穹丘；
- 门内但近海 → 只在雪线以上长局部冰帽（数百米厚，斯瓦尔巴式）。

地球锚点：加拿大北极/西伯利亚苔原海岸距海 < ~500 km；南极 Dome A 距海
~1200 km（接近南极难抵极）。700 km 落在两者之间，是**观测拟合**类参数。

由此，世界的南北不对称从海陆分布中**涌现**，而非硬编码半球：nacrea 北极是
大陆核心（距海远 → 穹丘），南半球暮光大陆是被海道切开的群岛型大陆（全境近海 →
只有冰帽）——同一套物理在两个半球给出不同形态，正如地球。

## 4. 完美塑性穹丘剖面

### 4.1 推导

完美塑性近似（perfect-plastic approximation）：冰的变形在底部剪应力达到屈服
值 τ_d 时发生，且到处都达到（冰盖内部应力近似塑性极限）。对厚度 h(x)、
x 为到冰缘距离的一维柱体，driving stress 与底部阻力平衡：

```
ρ_i·g·h·(dh/dx) = τ_d   →   h·dh = (τ_d/ρ_i·g)·dx   →   h² = 2·τ_d·x/(ρ_i·g)

h(x) = √(2·τ_d·x / (ρ_i·g))        （文献常称 Vialov 剖面）
```

剖面的几何特征是抛物线形穹丘：边缘薄、向中心按 √x 增厚，与实测冰盖剖面一致
（Cuffey & Paterson 2010 ch. 8）。**世界重力直接进入分母**——重力更大的世界，
同样的驱动应力下冰更薄（h ∝ 1/√g）。

### 4.2 参数与数值例

| 参数 | 地球值 | 来源 |
|------|--------|------|
| 冰密度 ρ_i | 917 kg/m³ | Cuffey & Paterson 2010 |
| 驱动应力 τ_d | 50–100 kPa（观测冰盖范围） | Cuffey & Paterson 2010 ch. 8 |
| 实现默认 | 40 kPa（低端柔和剖面，nacrea 标定） | 观测拟合 |

数值例（地球）：τ_d = 50 kPa、半宽 x = 1800 km →
h = √(2·5×10⁴·1.8×10⁶ / (917·9.81)) ≈ **4.4 km**——与 Dome A 实测冰面
4093 m 同量级（Fretwell et al. 2013）。

nacrea 实测（g = 10.28 m/s²）：北极核心（≥77°N）冰面均值 ~2320 m（对标
Bedmap2 南极均值 2048 m）、峰值 ~4856 m；穹丘边界取「穹丘子图内到非穹丘 cell
的测地距离」，子图隔离保证冰只在陆上传播、绝不穿过海洋。

### 4.3 冰帽（近海边缘）

门内近海陆地的局地冰帽取线性雪线超额的减半并封顶：

```
h_cap = min((bed − snowline)·0.5, cap_max)    （snowline = 1200 m, cap_max = 500 m）
```

纯**观测拟合**（斯瓦尔巴/北极群岛冰帽厚度为数百米量级），无第一性推导。

## 5. 已知近似与已否证方向

**近似（当前接受）**：

- 积累假定充足：寒冷极区在 Myr 尺度即使低降水也持续积累（参照南极内部干燥但
  冰盖存在）。门只看热量。
- 海洋热量输送只通过「距海」代理进入；极向热输送极端强的世界可能过冰。
  **交叉校验**：气候层中冰 cell 的年均温应 < 0 °C。
- 无冰均衡（glacial isostatic adjustment）：冰载荷不压低基岩（地球南极基岩因
  冰载荷均衡下沉）。bed 保持构造值，冰厚纯叠加——高阶效应，留给未来。

**已否证方向**（失败根因，勿重试）：

- 绝对 W/m² 日照门 → 雪球（见 §2；必须无量纲）。
- 海洋份额的邻接扩散作为 maritime 代理 → 失败：0.5 自锚把陆地 cell 钉在 0，
  随机游走扩散只能走 √hops·cell 距离；必须用图上测地距离（Dijkstra）。
