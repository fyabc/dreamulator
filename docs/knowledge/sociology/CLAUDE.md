# 社会学知识库

目录于 2026-08 docs 重组时建立。civilization 层当前为半结构化 input +
`narrate`；Phase 3C（事件溯源 + 状态机）设计见
`../../design/civilization-layer.md`。本目录收录文明动力学的科学底座。

## 规划中的文档

- `civilization_dynamics.md` — HANDY / SDT 模型（资源-精英-人口的微分动力学，
  复杂性边际收益递减 = Tainter 命题的可计算版本）；3C 的策略模式建模直接消费
- `political_morphology.md` — 政体形态类型学：曼荼罗体系、朝贡网络、
  酋邦→王朝→分散主权→联合政体的分期（视频赏析 EP2 的方法论来源）
- `geographic_determinism.md` — 地理决定论的适用域与反例（大河河谷 vs
  破碎群岛；年鉴学派的长时段视角作为世界史叙事方法）
- `anthill_model.md` — 蚁穴模型：文明规模指数（面积+人口+土地）随气候
  振荡的扩张-收缩-迁徙时空结构（乐意 Ajax《季风世界》EP2 提出；3C 文明实体
  状态量的设计参考——引擎输出的文明曲线天然是一张蚁穴剖面图）

## 与其他学科的关联

- 气候强迫 → 文明周期：`../climatology/` 的年际-年代际变率是兴衰模型的输入
- 地形 → 聚落：`../worldbuilding/map_design_guide.md` 的城市选址节
