# 社会学知识库

目录于 2026-08 docs 重组时建立。civilization 层当前为半结构化 input +
`narrate`；Phase 3C（事件溯源 + 状态机）设计见
`../../design/civilization-layer.md`。本目录收录文明动力学的科学底座。

## 已有文档

- `myth-phylogenetics.md` — 神话层累与系统发生学：PCM 方法论与可信度梯度、
  层累机制库（历史化/etiology 反转/宗教叠写/碎片杂交）、昴星团-射日-野人
  三案例速查、物理锚定接口。全文带"现实可信度"标注（共识/弱校准/大胆假说）
- `human_settlement.md` — 人类宜居性与农业适宜性：宜居三因子（人类气候生态位
  Xu 2020 / 降水干旱栅 / 海岸距离衰减 Small & Nicholls 2003）+ 农业三因子
  （生长度日 McMaster 1997 / 林线 Köppen/Körner / 土壤肥力）；文明层
  「宜居等级/农业等级」derived 图层的科学底座，含 0–100 公式映射
