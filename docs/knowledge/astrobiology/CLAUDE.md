# 天体生物学知识库

本目录存放天体生物学（astrobiology）参考文档，涵盖替代溶剂、极端环境生命化学、系外行星宜居性等内容，
为架空世界的非水基生命设计提供科学依据。

## 已有文档

- `alternative-solvents.md` — 替代生命载体溶剂（液氨、液态碳氢化合物、浓硫酸、超临界 CO₂、离子液体）
  及行星环境设计约束（相图、大气保留、无氧产能路径）

## 规划中的文档

- `habitable_zone.md` — 宜居带理论与扩展（传统水宜居带、碳氢宜居带、潮汐加热宜居带）
- `extremophile_biochemistry.md` — 嗜极生命化学（高温/低温/高压/高盐环境下的生化策略）
- `prebiotic_chemistry.md` — 前生命化学（非生物有机合成路径：Miller-Urey、热液、光化学、星际冰）
