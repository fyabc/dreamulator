# 架空世界创建指南

本目录存放架空世界设定的方法论和设计思路，指导如何从零开始构建一个自洽的架空世界。

## 已有文档

- `design_patterns.md` — 架空世界数据编码模式（特洛伊天体与拉格朗日点等）
- `map_design_guide.md` — 地图设计指导（CVT 时代版：地理锚定工作流、气候/生态/文明预期、命名与呈现）
- `narrative-craft.md` — 世界史讲述方法论（叙事公式、双线史纲、多声部呈现、比喻与诚信制度）

### drafts/ — 不成熟世界草案

存放 AI 讨论中产生的创意世界构想。这些草案尚未经过充分验证和细化，
**不作为正式世界线**，仅供未来参考和迭代。

- `drafts/conlang-world-drafts.md` — 架空语言文字草案（6 个草案：OSV 认知文明、多轨和声语法、能量梯度语序、宿命论语序、硅基纯表意文字、种族语音对立）
- `drafts/alternative-solvent-world-drafts.md` — 替代溶剂世界草案（9 个草案：氨海超级地球、乙烷湖行星、温水双洋、冷海双洋、硫火世界、冰-油-卤水三层世界、CO₂ 干冰穿梭、富氯行星、富碳辛烷油海）

## 规划中的文档

- `workflow.md` — 完整的自底向上世界构建流程（恒星 → 行星 → 地质 → 气候 → 生态 → 文明）
- `consistency.md` — 如何确保各层面设定的自洽性
- `creative_choices.md` — 在科学约束内做出有趣的创意决策
- `pitfalls.md` — 常见的世界设定陷阱和反模式
