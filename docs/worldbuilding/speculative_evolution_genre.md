# 推测进化（Speculative Evolution）流派简史与方法论

> 来源：Curious Archive《The Evolution of Speculative Evolution》
> （[YouTube](https://www.youtube.com/watch?v=NifBVOeVdO0)，2022-06-23；B 站熟肉 BV1YE421A7rW）。
> 转写存档：`private/external-resources/bv_EVOL/NifBVOeVdO0_en_transcript.txt`（原片英文音轨，本地 ASR）。

## 定义

推测进化 / 推测生物学（speculative evolution / speculative biology）是专注于**生命演化的假想场景**
的创作流派：不是把怪物当作背景道具，而是认真推演「这些生物从何演化、占据什么生态位、
构成什么生态系统」。判定标准是**演化与生态是否处于叙事前台**。

## 历史里程碑

| 年代 | 作品 / 事件 | 意义 |
|------|------------|------|
| 1895 | H.G. Wells《时间机器》 | 流派起点：远未来章节（红日下的濒死地球、蟹状生物、触手巨物）首次推演百万年尺度的演化后果；Morlocks/Eloi 是人类分化为捕食/被捕食两支的早期推演 |
| 1896–98 | Percival Lowell 火星运河 → Wells《世界大战》 | Wells 先写多篇「火星生命会是什么样」的推演文章，设定几乎原样进入小说——「先建世界、再写故事」的最早范例；普及了外星入侵题材 |
| 1930 | Olaf Stapledon《Last and First Men》 | 20 亿年、18 个人类物种的推演未来；预见了基因工程 |
| 20 世纪中叶 | 好莱坞入侵外星人潮 | 反面教材：外星人沦为「幻想怪物」，生物学是事后补的（afterthought）；1950s 麦卡锡主义隐喻 |
| 1957 | Disney《Mars and Beyond》（Ward Kimball，天文学家 E.C. Slipher 顾问） | 硅基生命、毒气捕食者、超声波 stun 等「真正异质」的生命推演，时代 ahead-of-time |
| 1957/61 | Gerolf Steiner《鼻行兽》（Rhinogradentia，笔名 Harold Stumpke） | 学术恶作剧格式的推测进化：完整分类树 + 生态位设计，干涩学术腔以假乱真；2015 年苏拉威西发现大鼻啮齿类时被戏名「Sulawesi snouter」致敬 |
| 1981 | Dougal Dixon《After Man》 | **第一个大规模推测进化项目**（整颗世界 + 海量物种，大灭绝后 5000 万年）；首次使用 speculative evolution/biology 两词；Rabbix（兔→食草鹿位）、Vortex（企鹅→滤食鲸位）、Night Stalker（蝙蝠→陆生梦魇）。直接受《时间机器》终章启发 |
| 1988 | Dixon《The New Dinosaurs》 |  alternate-timeline 子流派开端：K-PG 灭绝未发生，恐龙演化至今 |
| 1990 | Dixon《Man After Man》 | 未来人类演化；因出版方干预、科学细节缺失而成为反面案例 |
| 1990 | Wayne Barlowe《Expedition》 | 「真正 alien」的标杆：达尔文 IV 星生态系统，无眼/无毛/无外耳，智慧种 Eosapien 非人形且漂浮；以科考报告体裁呈现 |
| 2002 | 《The Future is Wild》 | 自然纪录片格式的推测进化；Dixon 参与设计；规模与野心至今无匹敌 |
| 2005 | 《Alien Planet》（Discovery，Barlowe 任设计顾问/执行制片） | CGI 电视特辑成为推测作品的载体 |
| 2000s | 主流反哺 | 《金刚》←《The New Dinosaurs》；《Avatar》← Barlowe 概念艺术 |
| 2006 | C.M. Köseman《All Tomorrows》 | 网络时代开端：人类被外星「Qu」基因改造为无数形态的十亿年编年史； nihilistic-yet-hopeful 基调 |
| ~2006–12 | Köseman《Snaiad》 | 受《Expedition》影响的异星世界构建，生物多样性极高的虚构世界之一 |
| 2012 | Köseman + John Conway + Darren Naish《All Yesterdays》 | 反向推测：恐龙可能的形态与行为；启发了《Prehistoric Planet》；附「All Todays」（外星人仅凭化石重建现代动物） |
| 2010s | Alex Ries「Birrin」 | 六足智慧外星种族的深度文化+生物学构建，在线协作时代的代表 |
| 2010s 末–今 | 复兴：Dylan Bajda《Serina》 | **seed world 子流派**普及化：空行星放入少数物种（鸟类），追踪其演化；Christian 等自出版；Amphitera 等 alternate-timeline 新作 |

## 方法论要点（对本项目有用的部分）

这一节把流派史里反复验证过的做法提炼出来，逐条对应到本项目的现有机制。

1. **生态位填充法**（《After Man》的核心手法）：先列出大灭绝后空出的生态位，再让现存
   类群辐射去填——兔子填鹿的食草位、企鹅填鲸的滤食位。这正是生态层演化模块要做的事：
   「形态型 ↔ 生态位」的映射模板。
2. **Alternate timeline**（《The New Dinosaurs》开创的子流派）：只改一个历史节点
   （比如 K-PG 灭绝没有发生），然后认真推演「替代的现在」。这与本项目的分支系统同构——
   分支就是在某个 DAG 层改一个输入、看下游如何不同。
3. **Seed world**（《Serina》普及的子流派）：往一个空世界放少数几个种子物种，然后追踪
   几千万年的演化路径。对应本项目的层级 DAG：从生态到文明逐步推演，而不是直接编写结果。
4. **真正 alien 的设计**（《Expedition》的标杆意义）：对「外星人=演员额头贴东西」套路的
   反叛。达尔文 IV 的生物无眼、无毛、无外耳，智慧种非人形且漂浮——它们读起来像是从另一条
   演化线自然长出来的。本项目「从物理定律出发推演世界」的第一性原则与这个追求同源。
5. **科考报告 / 学术腔体裁**（《Expedition》的考察报告格式、鼻行兽的干涩学术恶作剧）：
   用世界内科学家的口吻呈现设定，可信度远高于作者旁白。这与 `narrative-craft.md` 的
   「多声部呈现」互补。
6. **反面教材同样有教益**：《Man After Man》因出版方干预牺牲科学细节，成为 Dixon 自己
   都不愿承认的作品；好莱坞怪物把生物学当事后补充（afterthought），就失去了「推测」二字
   的价值。本项目「LLM 只改 input、引擎算 derived」的输入/衍生分离，正是把
   「生物学不许当 afterthought」制度化。
