# 世界史讲述方法论

如何把一个推演出来的世界**讲成好故事**。本文沉淀自乐意 Ajax《季风世界》
系列的帧级赏析，以及对我方视频计划的映射分析。

## 1. 叙事总纲：世界是主角，工具退幕后

- 用地理/历史纪录片口吻讲述虚构行星，**叙事吸引力优先**；
  管线与引擎介绍放副轨特典或片尾"幕后"，覆盖不丢失。
- 层级链同构：天文 → 地质 → 大气 → 海洋 → 生态 → 文明的展开顺序，
  既是 dreamulator 的 DAG，也是观众能自然跟随的因果链。

## 2. 单期结构公式

```
hook（悬念标题 / 媒介质感对撞 / 灾变画面）
→ 硬科学展开（每个数字可溯源到引擎输出）
→ 高潮（灾变 / 揭示 / "叹为观止"的渲染）
→ 修辞闭环收尾（把本期科学钩向文明剧情）+ 留白预告
```

- **反常识开场**优于设定罗列（"遗传学革命推翻了起源地共识"式）。
- 结尾金句把地理片钩向主线（"更大的船，更宏伟的海峡"）。

## 3. 双线史纲：气候周期 × 王朝周期

- 用气候振荡解释文明兴衰（暖期扩张/冷期凋亡），地理决定论作为方法论显式使用；
- 蚁穴模型式状态量：文明"规模指数"随气候的扩张-收缩-迁徙，
  引擎文明曲线画出来即是可视化（`../knowledge/sociology/CLAUDE.md`）。

## 4. 多声部呈现：同一数据，多种媒介质感

一部片内频繁切换"真实世界文档类型"：市政交通地图、博物馆展墙、
黑白学术图版（ka.BP 纪年、拉丁学名）、公式信息图、伪官方档案封面、
体素文明拼图、数据雕塑。地图表达细则
（色彩聚光灯、洋流双语言、竖排注记+王朝时间带、负空间失落文明）参考乐意 Ajax《季风世界》EP1 的实证画法。

dreamulator 的优势：**这些质感可由引擎输出 + 导出模板自动生成**，
而非手绘（前端"附件框"导出模板 = 伪官方档案质感的工业化）。

## 5. 比喻系统

抽象机制必须具象化：蚁穴（文明时空结构）、孢子（技术扩散）、
心律失常的病人（气候紊乱）、巨神吐息（呼吸潮）。每个核心机制配一个比喻，
比喻应从设定内部生长（该世界早期文明真住地下洞穴，蚁穴才成立）。

## 6. 诚信制度与留白

- "引擎推导"与"创意设定"两色标注——比人工创作者更强的诚信手段；
- 杜撰内容打星号、免责声明"迭代中，各期内容可能稍有出入"给修订留余地；
- 诚实留白（承认某机制"暂时只是个标识"）反而圈粉；
- 评论区 = 设定集延伸：逐条回复观众推理，登记为"以后一一陈述"的兑现清单。

## 7. 节奏

- 低频高质可行（9 个月一更被容忍），条件是单次高完成度 + 拖更时坦诚说明；
- 主线之间穿插 1–2 分钟爆款短内容导流；教程类内容建立专业信用。
