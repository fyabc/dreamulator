# "赤渊"倒流河奇观

## 原设（2026-07，已搁置）

原选址 nacrea 世界岛北纬 40° 大裂谷海裂谷段，副热带超级荒漠核心区。
因当时地形不支持封闭裂谷盆地而移出，计划待后续异星世界复用。

## 新址评估（2026-08-10）

### 背景

nacrea v0.24+ 气候引擎经 subtropical suppression 参数化（Hadley 边界 55° +
罗斯贝变形半径标度）后，北方（48°N 附近）形成了大片温带荒漠，为倒流河奇观
提供了新的候选场景。

同时，mesh 数据中确认北方内海存在一个向南延伸的狭窄水域——cell #12554
(−72.30°, 48.19°)，海拔 −62 m，是陆壳上的裂谷海向南的最远端。它构成了
"北方内海 → 沙漠内陆"的天然缺口。

### 尺度计算

| 参数 | 100k nodes（~71 km/cell） | 200k nodes（~51 km/cell） |
|------|--------------------------|--------------------------|
| 200 km 河流 | 1.8° 纬度 / ~3 cell | ~4 cell |
| 350 km 河流 | 3.1° 纬度 / ~5 cell | ~7 cell |
| 550 km 河流（原设） | 4.9° 纬度 / ~8 cell | ~11 cell |

建议新址河流长度 **350 km**（~3° 纬度），从 48.2°N 延伸至 ~45°N，
在约 5 cell（100k）内形成完整河流-盐湖系统。

### 实施路径

1. **geography.yaml 新增裂谷特征**（短期）：
   - 类型：`rift_valley`，起点 (−72.3°, 48.2°)，走向 SSW（~200°），长度 350 km
   - 谷底海拔：0 → −200 m（从海平面逐渐加深至封闭盆地）
   - 两侧隆起肩部：+200~400 m（形成天然屏障防止外溢）
   - 终点盐湖盆地：−50 ~ −200 m，面积 ~5,000–10,000 km²

2. **流水侵蚀（3B）**（中期）：
   - 侵蚀引擎落地后，裂谷内自然形成河道下切 + 沉积物搬运
   - 缺口处潮汐冲刷自动维持峡谷形态
   - 200k vs 100k 的差异（北方内海在 200k 下封闭）说明 sub-cell 尺度的
     海陆判定对裂谷缺口敏感——侵蚀可自动"打通"因网格离散化而错误闭合的缺口

3. **精细化地形后处理**（远期）：
   - 倒流河全程仅 ~5–10 cell（100k），属 **sub-grid 精细化地形** 范畴
   - dreamulator 的地形引擎适合宏观格局（大陆、山脉、海盆），
     裂谷峡谷/盐湖盆地/潮汐缺口等 < 50 km 特征需要外部工具（如 Gaea、
     World Machine、Houdini HeightField）做局部高分辨率渲染
   - 工作流设想：dreamulator 输出宏观 mesh → Gaea 局部雕刻（缺口峡谷 +
     盐湖盆地）→ 高分辨率 DEM 贴回到 dreamulator 地图图层
   - 前端可叠加"精细化高程图块"覆盖默认 mesh 渲染

### 地质自洽性

- ✅ **裂谷向南传播**：东非大裂谷南支、红海→亚丁湾均为裂谷传播实例。
  北方内海已是裂谷成因（`crust_type: continental`），向南延伸形成小型地堑
  完全自洽
- ✅ **陆壳裂谷**：cell #12554 已确认为 continental crust，裂谷在陆壳内
  延伸（而非洋壳），形成"大陆裂谷→海水灌入→内陆盐湖"的经典演化序列
- ✅ **潮汐驱动**：nacrea 的 ~44 m 潮汐（巨行星 Aegis + 卫星共振）为倒流河
  提供强大的涌潮驱动力，与裂谷形态无关
- ✅ **极端干旱**：39.6 mm/yr 降水 → 蒸发 >> 降水，盐湖可持续堆积

### 命名

原设"赤渊"（红色盐湖，由嗜盐古菌/藻类色素沉积形成彩色条带）在新址仍然适用。
中纬度冷荒漠的低蒸发使盐湖颜色可能更偏**蓝绿→乳白渐变**（低温嗜极藻类），
而非副热带的铁锈红。
