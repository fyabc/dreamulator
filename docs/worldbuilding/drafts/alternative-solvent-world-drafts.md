# 替代溶剂世界草案

> **状态：不成熟草案** — 以下架空行星世界概念来自 AI 讨论中基于天体物理学和天体生物学知识
> 推演产生的创意构想，尚未经过充分验证和细化，不作为正式世界线。记录于此供未来参考和迭代。

## 草案一：氨海超级地球

**溶剂**：液氨（极性，可形成氢键）

**核心参数**：

| 参数 | 推荐值 |
|------|--------|
| 表面温度 | 278 K（~5 °C） |
| 表面总气压 | 15 bar |
| 氨分压 | 5–6 bar |
| 背景大气 | N₂ 为主，含少量 CH₄、Ar、H₂、HCN |
| 行星质量 | 2.8 M⊕ |
| 行星半径 | 1.35 R⊕ |
| 表面重力 | ~1.5 g |
| 逃逸速度 | ~15 km/s |
| 磁场 | 2–4 倍地球磁矩 |
| 恒星 | 安静 K 型矮星，年龄 4–6 Gyr |
| 入射辐射 | 0.6–0.8 S⊕ |

**地表特征**：氨海洋、氨雨、铵盐沉积、富氮有机霾、热液喷口。

**优点**：液氨化学活性较高，温度接近地球常温，生命起源反应速率不至于太慢。
超级地球质量和磁场有助于长期保留大气。

**风险**：NH₃ 紫外光解 → N₂ + H₂、H 逃逸、若无冷阱或大气屏蔽氨会被破坏。

**生命化学方向**：氨体系酸碱（NH₄⁺/NH₂⁻）、胺/腈化学、金属胺配合物、
溶剂化电子参与的高能还原反应。

## 草案二：乙烷湖类地行星（温暖版）

**溶剂**：液态乙烷（非极性），含少量甲烷、CO₂、N₂ 溶解质

**核心参数**（215 K 基准版）：

| 参数 | 推荐值 |
|------|--------|
| 表面温度 | 215 K（~ −58 °C） |
| 表面总气压 | ~12 bar |
| 分压配置 | C₂H₆ ~4 bar（饱和）；N₂ ~6 bar；CH₄ ~1 bar；CO₂ ~0.8 bar；Ar+H₂ ~0.4 bar |
| 行星质量 | 2–3 M⊕ |
| 行星半径 | 1.25–1.4 R⊕ |
| 表面重力 | ~1.3–1.6 g |
| 磁场 | 1.5–3 倍地球磁矩 |
| 恒星 | 安静 K 型或年老 M 型 |
| 入射辐射 | ~0.15–0.3 S⊕ |
| 基岩 | 水冰（此温度下水冰即"岩石"） |

**液态重叠分析**：在 215 K 下，仅乙烷为本体液体；N₂（临界 126 K）、CH₄（临界 191 K）
均为气体/超临界溶质；CO₂ 仅在高分压下可能为液体但会溶入乙烷海洋。
四者完全互溶，形成**单一混合非极性海洋**。

**奇观**：
- "冒泡湖"效应：升温/降压时溶解的 N₂ 与 CH₄ 出溶冒泡
- 组成随温度分馏：暖区富乙烷，冷区冷凝雨富甲烷/CO₂
- 海洋密度 ~0.5–0.6 g/cm³，浮于水冰基岩（~0.92 g/cm³）之上

**生命化学方向**：非极性膜（azotosome）、H₂ 与不饱和烃的加氢反应、矿物表面催化。
核心产能：C₂H₂ + H₂ → C₂H₆。

## 草案三：水+乙烷「温水双洋」行星

**概念**："地球海洋 + 泰坦烃海"的合体。上层乙烷海、下层水海，两者互不相溶。

**核心参数**：

| 参数 | 推荐值 |
|------|--------|
| 表面温度 | 278–290 K（~5–17 °C） |
| 表面总气压 | 28–38 bar |
| 分层 | 乙烷（ρ≈0.4，上层）/ 水（ρ≈1.0，下层） |
| 大气 | N₂ + 乙烷蒸气（还原性，无游离氧） |
| 行星类型 | 2–4 M⊕ 超级地球 |

**景观**：海面是一层微黄的乙烷，天空是光化学雾霾的橙色。潜入乙烷层数米后
抵达一道银亮的波动界面，其下是真正的深海。潮汐搅动处形成乳白色乳化带。

**有机溶剂来源**：行星整体碳氧比偏高，地幔通过费托型反应与蛇纹石化持续向地表供给碳氢化合物。

**生命起源——界面摇篮**：
1. 两亲分子在液-液界面自发铺展为单分子膜，微滴被膜包裹 = 天然原始细胞
2. 还原性物质（H₂S、Fe²⁺）只溶于水相，光化学氧化剂只存在于乙烷相——跨界面电化学梯度
3. 核苷酸在界面吸附、缩合，矿物颗粒稳定乳化液滴

**选型定位**：最接近地球生化、演化速度最快、相图窗口最宽、设定容错率最高。

## 草案四：液氨+乙烷「冷海双洋」行星

**概念**：极寒环境下的极性/非极性双层海洋。上层乙烷海、下层液氨海。

**核心参数**：

| 参数 | 推荐值 |
|------|--------|
| 表面温度 | 200–235 K（~ −73 °C 至 −38 °C） |
| 表面总气压 | 10–30 bar |
| 分层 | 乙烷（ρ≈0.45–0.54，上层）/ 液氨（ρ≈0.66–0.73，下层） |
| 基岩 | 水冰（此温度下坚硬如岩石） |
| 大气 | N₂ 为主，含 NH₃、CH₄、C₂H₆ 蒸气 |

**奇观**：
- **氨雪下沉**：极地极寒时乙烷表层析出氨霜雪（固态氨 ρ≈0.83，比乙烷重），
  穿透乙烷层沉入液氨海——"下行支"
- **氨泉上涌**：海底热液加热液氨 → 氨蒸气气泡横穿乙烷层喷出海面 →
  冷凝成雨落回——"上行支"
- 同一层乙烷海洋中同时出现"下沉的雪"与"上升的气柱"

**生命化学方向**：
- 氨合成（N₂ + 3H₂ → 2NH₃）是核心产能——利用大气主要成分产能，产物（NH₃）是溶剂本身
- 碱金属溶解于液氨产生溶剂化电子（−2.0 V）——高能量密度代谢
- 跨界面氧化还原：乙烷侧还原剂 + 液氨侧氧化剂，需跨界面电子载体
- 遗传物质可能采用低电荷/中性骨架（PNA 型）以适应液氨的低介电常数

**选型定位**：陌生感强、遗传化学另起炉灶、双溶剂生态位最独特。

## 草案五：水+熔融硫「硫火世界」行星

**概念**：高温高能的绝对不互溶双海洋。上层高压热水海、下层金黄/暗红熔融硫海。

**核心参数**：

| 参数 | 推荐值 |
|------|--------|
| 表面温度 | 120–200 °C |
| 表面气压 | 5–20 bar |
| 分层 | 水（ρ≈0.92，上层）/ 熔融硫（ρ≈1.8，下层） |
| 地质 | 极其活跃的火山活动（木卫一规模） |

**独特性质**：160 °C 以上 S₈ 环开环聚合成链，硫粘度暴增，界面处形成有弹性的
"硫聚合物皮"——天然的 protocell 膜材料。

**生命化学方向**：
- 能量极丰富：H₂（蛇纹石化）+ S → H₂S 放能巨大；硫歧化、多硫化物电对构成完整氧化还原阶梯
- **代谢先行**路径：界面 FeS/NiS 沉淀形成烟囱状矿壁（铁硫世界假说），
  先建立自催化代谢网络，遗传物质后续"接管"
- 或采用耐热遗传类似物：PNA、TNA、含硫骨架聚合物

**选型定位**：能量最充沛、画面冲击力最强、代谢先行的硬核设定。

## 草案六：富碳行星（辛烷油海）

**概念**：最简洁的"油浮于水"方案。使用长链烷烃（辛烷/庚烷/壬烷混合物）作为上层非极性海洋。

**核心参数**：

| 参数 | 推荐值 |
|------|--------|
| 温度 | 60–90 °C |
| 气压 | 1–5 bar |
| 上层 | 辛烷/重烃（ρ≈0.70，ppb 级水溶解度） |
| 下层 | 液态水 |

**优点**：互溶度可以忽略不计（ppb 级别）、界面如镜面清晰、重烃自然界可通过费托合成大量存在。
没有 CO₂ 方案那种"溶于水"的硬伤。

## 草案七：四氢化萘「密度翻转」油海世界（铁呼吸行星）

> 本草案是对「草案八（冰-油-卤水三层世界）」的深度拷问与重构：不再回避四氢化萘
> 与水的密度随温度交叉，反而把这一现象升格为行星级奇观的核心驱动力。

**概念**：以四氢化萘（tetralin，C₁₀H₁₂）为主体的极地油海。四氢化萘的热膨胀系数
远大于水，其密度随降温快速上升，而 0 °C 以下的过冷水密度反而随降温下降，
两条曲线在 **约 −12 °C 交叉**。于是「冰—油—水」层序每年冬夏各发生一次海洋尺度的
**瑞利-泰勒翻转**（大翻转），油层与水层位置互换。

### 核心参数

| 维度 | 参数 |
|------|------|
| 恒星 | 安静 K 型橙矮星 |
| 行星质量 / 表面重力 | ~1.1 M⊕ / 1.05 g |
| 表面气压 | ~1.05 atm |
| 极地油海覆盖 | 全球表面积 ~8% |
| 油层主体 | 四氢化萘（十氢萘、茚满为辅） |
| 极地温度年变幅 | +5 °C ～ −40 °C |
| 中低纬度温度 | 10–30 °C（与地球相当） |

### 关键物质物性（1 atm）

| 物质 | 分子式 | 密度 g/cm³ (20°C) | 熔点 | 沸点 |
|------|--------|------------------|------|------|
| 四氢化萘（tetralin） | C₁₀H₁₂ | 0.970 | −35.8 °C | 207.6 °C |
| 十氢萘（decalin） | C₁₀H₁₈ | 0.890 | −43 °C（顺式）/ −31 °C（反式） | ~190 °C |
| 茚满（indane） | C₉H₁₀ | 0.965 | −51.4 °C | ~178 °C |
| 萘（naphthalene） | C₁₀H₈ | 1.14 | 80 °C | 218 °C |

四氢化萘热膨胀系数 β ≈ 8.8×10⁻⁴ K⁻¹，故其密度随温度变化显著：
`ρ(T) = 0.970 × [1 + 8.8×10⁻⁴ × (20 − T)]`。

### 密度交叉（本草案的物理核心）

| 温度 | 四氢化萘密度 | 水（过冷）密度 | 相对位置 |
|------|-------------|---------------|----------|
| +5 °C | 0.983 | 1.000 | 油 < 水（油浮水上） |
| 0 °C | 0.987 | 1.000 | 油 < 水 |
| −10 °C | 0.996 | 0.998 | 油 < 水（接近反转） |
| **−12 °C** | **0.997** | **0.997** | **交叉点** |
| −20 °C | 1.004 | 0.994 | 油 > 水（水浮油上） |
| −35 °C | 1.017 | ~0.985 | 油 >> 水 |

两种稳态构型：
- **夏季态**（T > −12 °C）：冰 → 四氢化萘 → 淡水 → 卤水
- **冬季态**（T < −12 °C）：冰 → 淡水 → 四氢化萘 → 卤水

### 全年循环推演

| 阶段 | 温度区间 | 关键动态 |
|------|---------|----------|
| 1 夏末稳态 | ~5 °C | 层序「冰—油—水」，油水界面清晰如镜 |
| 2 秋季降温 | 5→0 °C | 表层冷油变重下沉，油层内部剧烈对流 |
| 3 初冬结冰 | 0→−10 °C | 油水界面结冰，冰晶（ρ 0.92）比油轻，自下而上浮穿油层 |
| 4 密度交叉 | −10→−12 °C | **大翻转**：瑞利-泰勒失稳，油柱下沉、水柱上涌 |
| 5 深冬稳态 | −12→−35 °C | 层序反转「冰—水—油」，油层被水层与卤水层夹持 |
| 6 极寒谷底 | −35→−40 °C | 油层接近凝固（距熔点仅 2–4 °C），呈半固态凝胶 |
| 7 春季升温 | −40→−12 °C | **二次翻转**：油重新上浮，层序恢复 |
| 8 晚春融冰 | −12→5 °C | 冰壳融化，融水（ρ 1.00）穿过油层（ρ 0.98）下沉 |

### 四氢化萘循环与水循环

**四氢化萘循环**（地幔 → 海洋 → 大气 → 地幔）：
1. **生成**：蛇纹石化产 H₂ + 费托合成（CO + 2H₂ → −CH₂− + H₂O）在热液喷口合成四氢化萘前体
2. **注入**：高温含油流体喷出，低密度四氢化萘上浮至油层
3. **分布**：季节性密度翻转驱动全年层序循环
4. **损耗 A**：夏季裸露油层受 UV → 光化学聚合成重质焦油沉降
5. **损耗 B**：冬季下沉油接触 >300 °C 热液 → 脱氢生成萘 + H₂
6. **回收**：焦油/萘矿床随板块俯冲进入地幔
7. **再生**：高温高压下裂解 + 地幔 H₂ 加氢 → 再生四氢化萘

**水循环**：水以冰壳、淡水层、卤水层、矿物结合水四种形态存在，春季融水穿油下沉、
冬季翻转水上浮，在油层中双向穿梭。

**关键耦合反应**（蛇纹石化，产 H₂ 并固氧）：

$$\text{3 Fe}_2\text{SiO}_4 \text{（橄榄石）} + 2\text{H}_2\text{O} \rightarrow 2\text{Fe}_3\text{O}_4 \text{（磁铁矿）} + 3\text{SiO}_2 + 2\text{H}_2 \uparrow$$

### 氢循环与三重保护

H₂ 是这颗星球"能量货币"，其大气稳态浓度 0.5–3% 由三重保护机制维持：

| 保护机制 | 效果 |
|---------|------|
| K 型橙矮星低 FUV 通量 | 打断 C–H 键（>5.5 eV）的高能光子少，光解产 H₂ 速率降 1–2 个数量级 |
| 1.05 g 重力势垒 | Jeans 逃逸速率呈指数级下降，H₂ 逃逸约地球的 1/50–1/100 |
| 平流层托林雾霾层 | 吸收 >90% UV，截留有机蒸汽（"冷阱"），保护对流层溶剂 |

综合效果：H₂ 逃逸约地球的 1/1000–1/5000（~10⁴–10⁵ kg/年），而蛇纹石化产 H₂
速率 10⁹–10¹⁰ kg/年，产/耗比达 10⁴–10⁶ 倍 → H₂ 必然在大气中积累为稳定组分。

**十氢萘-四氢化萘-萘氧化还原链**（行星氢"呼吸"）：
- 地幔加氢：萘 + 3H₂ → 十氢萘（`C₁₀H₈ + 3H₂ → C₁₀H₁₈`，储氢载体）
- 夏季光解：十氢萘 −3H₂ → 四氢化萘（`C₁₀H₁₈ → C₁₀H₁₂ + 3H₂↑`）
- 冬季脱氢：四氢化萘 −2H₂ → 萘（`C₁₀H₁₂ → C₁₀H₈ + 2H₂`，沉降回地幔）

### 氧循环（还原态行星版）

行星无游离 O₂（`O₂` 浓度严格为 0）。氧被锁在水（>99.9%）与硅酸盐/氧化物岩石中，
循环本质是「水—岩石—碳」之间的氧原子转移：
- **固氧**：蛇纹石化把 H₂O 拆解，O 锁入磁铁矿，H 成为 H₂
- **释氧**：俯冲带脱水（500–800 °C）释放岩浆水；热液喷口磁铁矿氢还原
  `Fe₃O₄ + 4H₂ → 3Fe + 4H₂O`；微生物异化铁还原 `Fe₂O₃ + H₂ + 4H⁺ → 2Fe²⁺ + 3H₂O`
- 初级生产者代谢废物是纯净的 H₂O（Sabatier：`CO₂ + 4H₂ → CH₄ + 2H₂O`）

### 生命化学

- **反胶束细胞（W/O 微乳液）**：生命不"生活于油中"，而是以纳米级水核为细胞质、
  疏水碳氢链为外膜的反胶束。极性生化反应（磷酸化、离子泵）全部封闭在水核内。
- **遗传物质**：无磷骨架。采用多环芳烃 π-π 堆叠形成的刚性柱状超分子结构
  （PAH 世界假说），比 DNA 更耐极寒断裂。
- **氢键放大**：非极性溶剂中无水分子干扰，氢键作用力放大数十倍，
  少量氢键即可维持刚性折叠。
- **核心代谢——铁呼吸**（有氧呼吸的替代）：

$$ \text{H}_2 + 2\text{Fe}^{3+} \rightarrow 2\text{H}^+ + 2\text{Fe}^{2+} \quad \Delta G° \approx -148\ \text{kJ/mol} $$

  能量效率达有氧呼吸（H₂ + ½O₂ → H₂O，−237 kJ/mol）的 **62%**。Fe³⁺ 以有机配合物形式
  溶解（"铁血液"），Fe³⁺/Fe²⁺ 电对 +0.77 V 仅比 O₂/H₂O（+0.82 V）低 0.05 V。
- **铁-氢芳香循环（FHAC）**：以芳香烃载体（萘-四氢化萘衍生物）为碳骨架、
  H₂ 为电子供体、Fe³⁺ 为电子受体的还原加氢环（克雷布斯循环的反向）。
- **无磷生命**：能量货币改用**硫酯**（硫酯水解自由能与 ATP 相当），
  磷降级为仅酶辅因子级别的微量元素（干重 0.001–0.01%）。

### 能量流动

| 能量来源 | 全球总量 | 特点 |
|---------|---------|------|
| 恒星辐射（地表） | ~10¹⁶ W（~50–80 W/m²） | 夏季主导，冬季极夜归零 |
| 地热通量 | ~50–80 TW | 全年稳定，集中于热液喷口 |
| 蛇纹石化化学能 | ~4–10 GW | 高度集中于热液喷口 |

与地球（恒星/地热比 ~2000:1）不同，本行星夏季约 500:1、冬季极夜 0:1，**季节剧变**。

**"铁呼吸猎豹"可行性**：一只 50 kg 动物以 100 km/h 冲刺 30 s 需 ~300 kJ ≈ 41 g H₂，
以金属氢化物储存仅需 ~540 g 储氢材料（占体重 ~1%）。能量总量足够，真正的瓶颈是
**功率密度**（Fe³⁺ 为固态，不像 O₂ 可快速扩散），需演化出携带 Fe³⁺ 配合物的"铁血液"
循环系统与爆发式储氢器官。最可能的生态位：热液喷口附近的高温高 H₂ 区。

### 元素循环

| 元素 | 角色 | 核心循环特征 |
|------|------|-------------|
| 铁 Fe | 能量载体（电子受体） | 蛇纹石化"充电" ↔ 铁呼吸"放电"，依赖跨界面铁载体 |
| 氮 N | 单向漏斗 + 减压阀 | 闪电固氮（N₂→HCN→NH₃）富集于深海氨库，靠热分解/厌氧氨氧化返回 N₂ |
| 硫 S | 跨界面信使 | H₂S 穿梭油水两相，多硫化物（`H₂ + S₄²⁻ → 4HS⁻`）提供高能代谢 |
| 磷 P | 绝对限制因子 | 极度匮乏，逼出无磷遗传物质，引发"磷掠夺"生态 |
| 氯 Cl | 保守物理循环 | 火山 HCl → 卤水层 Cl⁻ 富集 → 俯冲回收，几乎无生物参与 |

### 地质不稳定性与稳态维持

四氢化萘油海在百万–十亿年尺度面临四类退化风险：**深层热裂解**（>300 °C 脱氢成固态萘）、
**光化学焦油化**（UV 聚合致粘度/密度失控）、**组分漂移**（轻组分挥发 + H₂ 逃逸致不可逆碳化）、
**生物乳化**（两亲分子将油水打成稳定微乳液）。

**稳态条件**：费托合成补给速率 ≥ 光化学 + 热裂解损耗；板块俯冲回收焦油/萘矿床；
雾霾冷阱回收逃逸碳。行星"油海"实为全球性化学流化床反应器，其寿命取决于地幔活动强度。

### 选型定位

将原草案的"静态三层结构"升级为"全年动态演化系统"：物理自洽性最高（不再有低温密度矛盾）、
叙事潜力最大（每年两次海洋尺度翻转构成文明历法节点）、生命起源机制最独特
（翻转-分层循环即天然的浓缩-稀释泵）。

## 草案八：极地「冰-油-卤水」三层世界

**概念**：利用冰（ρ≈0.917）< 油（ρ≈0.97）< 卤水（ρ≈1.1–1.3）的密度阶梯，
在极地区域形成冰浮在油上、油浮在盐水上的三层结构。不需要全球覆盖——类似地球冰盖，
仅在极地区域出现。

**核心参数**：

| 层序 | 物质 | 密度 | 温度 |
|------|------|------|------|
| 冰壳 | 淡水冰 | 0.917 | −30 °C 至 −5 °C |
| 油层 | 部分加氢环烷芳烃混合物（见下） | 0.92–0.99 | 近恒温 |
| 卤水层 | CaCl₂/高氯酸盐浓溶液 | 1.1–1.3 | 地热增温 |
| 基岩 | 硅酸盐 | — | 地热梯度 |

**油层成分（自洽化设定）**：油层主体为**部分加氢的环烷芳烃共熔混合物**，以
茚满（C₉H₁₀，熔点 −51.4 °C）+ 四氢化萘（C₁₀H₁₂，熔点 −35.8 °C）为主体，
复配十氢萘（C₁₀H₁₈，熔点 −43 °C）为抗冻溶剂。三者结构相似，形成低共熔体系，
混合凝固点可压低至 **−60 °C 以下**，并将密度锁定在 0.92（冰）< 油 < 1.00（淡水）
的狭窄窗口内，保证三层结构全年稳定。

> **为什么不能用"多环芳烃"**：萘（熔点 80 °C）、菲（101 °C）、蒽（218 °C）等
> 多环芳烃在 −30 ~ −5 °C 下必为坚硬的晶体，无法维持液态油层。只有饱和环破坏
> 平面性的部分加氢芳烃（如四氢化萘、茚满）或高度烷基化芳烃才能在极地低温下保持液态。

> **密度-温度耦合警示**：四氢化萘热膨胀系数 8.8×10⁻⁴ K⁻¹，从 20 °C 冷却至 −30 °C
> 密度会增至 ~1.01，超过淡水（1.00），此时"融水穿油下沉"失效、融水反而浮于油上。
> 本草案通过共熔混合物把油层密度压入 0.92–0.99 并维持温度于 0 °C 以上来规避；
> 主动利用这一密度交叉的动态版本见「草案七」。

**非生命有机物来源**（五条路径）：
1. **热液合成**：蛇纹石化产 H₂ + 费托型合成（CO + H₂ → 烃链）→ 汇入油层
2. **地热热解**：原始碳质物质埋入深部 → 300–600 °C 热变质 → 生成部分加氢芳烃（油层主体）
3. **大气光化学**：CH₄ + hν → C₂H₂、HCN → 有机气溶胶沉降到极地（冷阱效应）
4. **宇宙输入**：微陨石与星际尘埃持续输运 PAH
5. **冰内辐射化学**：混合冰（H₂O+CO+NH₃+CH₄）受宇宙射线辐照 → 氨基酸、核碱基前体 → 冰融时释放

**季节奇观**：

| 季节 | 关键动态 | 奇观 |
|------|---------|------|
| **春** | 冰壳表面融化，融水（淡水 ρ≈1.0）比油重 | **"水穿油"瀑布**——无数银色水柱在琥珀色油层中垂直下落 |
| 春 | 冰壳变薄、潮汐应力下崩裂 | **油泉喷涌**——黑色油柱从冰缝喷射到冰面形成油湖 |
| **夏** | 油层直接暴露于大气 | **裸露油海**——极其平静的镜面（油粘度高） |
| 夏 | 融水大量沉入卤水，稀释局部浓度 | **化学花园**——界面处 FeS（黑）、FeS₂（金）、CaCO₃（白）树枝状矿物结构 |
| **秋** | 油层中悬浮水滴结冰（冰 ρ 0.917 < 油 ρ 0.97） | **逆雪花玻璃球**——无数冰晶在琥珀色油层中缓慢上浮 |
| 秋 | 冰晶在油层顶部聚集、烧结 | **冰壳自修复**——冰壳从下方增厚 |
| **冬** | 卤水表层开始结冰，排盐 | **卤水瀑布**（brine rejection）——高密度冷卤水沉穿油层 |
| 年际 | 多年冰中油包体逐层积累 | **年轮状含油冰层**——琥珀色/黑色条纹记录每年油层化学 |

**生命起源的"三明治"摇篮**：
- 顶部冰壳：屏蔽紫外线和宇宙射线、维持温度稳定
- 中间油层：提供非极性反应介质、脂质膜材料、有机底物
- 底部盐水：提供液态水、离子梯度、热液喷口能量
- 季节冻融循环 = 天然浓缩-稀释泵（类似实验中的"湿-干循环"，驱动单体聚合）

**选型定位**：最接近地球生物化学、化学多样性最高、物理自洽且视觉和叙事潜力巨大。
静态三层结构是其与「草案七（动态翻转版）」的根本区别。
