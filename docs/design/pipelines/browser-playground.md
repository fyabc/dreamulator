# 浏览器气候实验台

已有世界的气候实验台在本机版运行完整的能量平衡气候管线（EBM），在静态站运行浏览器温度预览。浏览器草稿继续使用保存时的温度预览和输入。
世界「气候」页的「运行气候」按钮会打开当前天体和分支的平面地图，并展开气候实验台。本机版需要现成的天文数据和地质网格；世界只有高程图时，需要先构建。「帮助」页的样例会展开实验台，不会自动计算。地球样例在本机版选择模型分支，静态站从地球参照主干读取浏览器预览的输入。静态世界的当前分支没有全球高程时，「气候」页会把用户引到帮助页的样例入口。

全球高程可用时，平面和球面的工具栏都提供「气候实验台」。面板在当前视图中打开，不会重置视角或选区。试算读取当前天体和分支的全球高程，不以区域选框作为计算范围。平面与球面切换时共用参数、月份、结果和计算线程，试算不改动正式图层及其月份。收起面板不会丢弃结果。更换世界、天体、分支或正式高度图时会结束原实验并重新读取输入。离开地图工作台或刷新时不会保留未保存的实验。
正式前端旅程由[前端入口提案](../proposals/frontend-entry.md)维护，完整浏览器计算候选由
[浏览器计算提案](../proposals/browser-playground.md)维护。

## 本机 EBM

试算通过正式气候引擎解析所选天体的物理输入，并允许临时覆盖倾角、自转周期、邦德反照率和温室增温。它读取已有地质球面网格，清除其中继承的气候和下游字段，然后用正式 EBM 和地图导出器生成独立产物。即使分支固定为 GCM 结果，试算也不读取该结果作为气候初值。真实地球参照主干拒绝本机试算，模型分支可以运行。

本机实验台的「气候模型」选择框默认使用 EBM。EPS 和 EPS++ 列在同一处，但尚不可选。鼠标悬停或键盘聚焦选项时可查看模型说明。

本机服务一次接受一个试算，在独立进程中计算，并将结果保存于临时目录。界面轮询真实阶段和耗时，在纵向步骤列表中标记已完成的阶段，并自动滚动到当前阶段。列表保留阶段用时、累计用时和网格单元数，逐月水汽收支求解时还显示当前轮次和已完成月份。任务完成后，平面和球面使用与正式图层相同的几何、字段和气候文件格式，显示可用的年均和逐月图层；没有瞬时模式。试算不覆盖正式输入、地图或构建产物。离开工作台或刷新后不会自动恢复本次结果，静态导出也不包含这些临时产物。

## 浏览器运行时与数据

完整 EBM 的试算导出器允许浏览器调用方关闭温度和降水诊断 PNG。关闭后，它不做这两张图的等距圆柱投影，也不写对应的栅格量程和分辨率。球面网格、柯本分类、年均和逐月产物仍由同一导出器生成，正式构建和本机试算默认继续输出诊断图。静态站的地图工作台尚未接入完整 EBM。

`frontend/src/playground/temperature.worker.ts` 在首次计算时从站点自身加载 Pyodide 与 NumPy。同一实验会话的后续运行复用已经初始化的运行时，计算不占用界面主线程。
Vite 在开发和构建时准备这批文件。核心文件来自锁定的 `pyodide` npm 包，NumPy 的 WebAssembly 安装包从分发镜像下载，并按 Pyodide 的包清单校验 SHA-256。普通访客不需要连接第三方 CDN，也不会在打开页面时预先下载运行时。生成的运行时资源随站点发布，不入 Git。[Pyodide 上游源码](https://github.com/pyodide/pyodide/tree/314.0.7)对应当前锁定版本。
计算线程把 `engine/climate_physics.py`、`engine/climate_seasonality.py` 和
`frontend/src/playground/temperature_kernel.py` 的源码装入浏览器运行时，计算过程不需要 API 服务。
固定版本升级时须核对分发路径、numpy 包和源码兼容性。

试算使用 180 × 90 的等距圆柱规则网格。它读取当前分支的天体目录、全球高程和高程量程，沿用地图读取接口的分支继承。尚未生成天体目录时，试算读取已有的恒星系和行星输入。卫星的恒星距离与年长取自其宿主世界绕恒星的轨道，地表参数与自转取自卫星本身。简化模型使用自转周期的大小和不超过 90° 的季节倾角。若世界数据仍缺少参数，界面标明采用了地球样例默认值。

样例使用对应世界的全球高程和天体参数。用户若只有一张全球高度图，可以从[已有高度图创建世界](#从已有高度图创建世界)开始，并在保存前试算。

## 温度计算

内核先用辐射平衡和温室增温计算全球温度，再用一维能量平衡模型求纬向温度。
陆地高程通过递减率影响地面温度，季节热容量、月度日射和周期响应给出逐月温度。
它不计算完整气候求解器中的降水、水汽预算、风场、洋流和气候分类，也不会写回正式图层。

页面显示参数、灰度预览、温度图、年均与月份选择、均温、范围及耗时。修改参数后，页面保留并注明上次运行的结果，直到用户重新计算。页面按一月至十二月显示，仍按模型的春分起算索引读取对应结果。切换月份不启动新计算。
全球能量平衡温度与地表网格面积均温分别报告；它们不等同于完整世界的最终气候值。
规则网格与正式球面网格的逐格结果不能直接混作同一口径。

## 地图内的气候试算

顶部工具栏把平面与球面切换、「模式」和「区域选取」放在同一行。「模式」下拉框在「正式」和「试算」之间切换。没有结果时，选择「试算」会自动打开气候实验台；配置面板在宽屏上覆盖右侧检查栏，在窄屏上从底部打开。两种模式共用图层列表、时间控件、单元格检查和统计。切换模式不会重跑试算、改变地图视角或清除单元格选择。窄屏通过「图层」和「单元格与统计」分别打开相同内容。

两种试算都沿用正式地图的配色、叠加渲染和浮动色阶。缺失的图层置灰，检查和统计不会用正式图层的数据填补。本机 EBM 直接使用地质网格的地形和试算气候字段。浏览器预览用重采样后的 180 × 90 高程与海平面绘制地形、海陆与海岸线。检查单元格时，浏览器预览在正式单元中心采样；多选报告采样点的平均值，而不是区域面积均温。没有正式网格时，可在光标处读取试算温度。浏览器预览的世界统计报告按面积加权的均温和温度范围。

宽屏地图在右侧检查栏显示时间控件，窄屏地图将它们放在底部的「单元格与统计」面板中。柱形图在所选图层有逐月数据时显示。浏览器预览只对温度显示图表；完整 EBM 和正式模式共用图表、单元数据与降尺度路径。点击柱形只切换地图上的月份，不重新计算气候，也不改变光照。浏览器预览的降尺度只在其求解网格上对温度插值。

年均和逐月的温度与降水图层显示海洋上的有效数值。柯本图层保留陆地分类，并根据海洋最冷月温度划分热带和非热带海域。阈值为 18 °C，海洋数据不足时只显示未分类海洋。海域单元具备完整逐月温度时，检查栏显示月均温低于 0 °C 的月份数。本机 EBM 没有逐月海冰覆盖率，月份数只描述温度，不表示实际海冰覆盖，也不参与柯本分类。降尺度和色阶的通用规则见[地图技术参考](map-system.md#2d-渲染与昼夜光照)。

地图工具的两个本机导入入口与新建世界不同。本机通用导入页也能为已有世界导入高程，但地图上的「替换当前高度图」会直接选定正在查看的天体和分支。「导入海陆锚定图」只记录下次地形生成所用的海陆倾向，不会替换现有高程。

## 草稿与备份

浏览器温度预览可以显式保存草稿到「世界数据」。草稿保留来源天体、分支、参数和重采样后的输入高程，不保存计算产物。已保存的草稿不依赖原始世界地图重新下载。浏览器数据包在 `experiments/temperature/` 中包含草稿，不包含正式世界的图层与设定。本机 EBM 试算暂不提供持久保存。

草稿从「世界数据」打开时，进入来源天体和分支的全球地图，并自动打开气候实验面板。`/playground` 只用于兼容旧链接：有世界和天体时跳转到对应地图，保留链接中的分支、视图和草稿；没有来源时打开帮助页。两种地图视图之间切换时仍使用草稿保存的高程。若来源地图不可用，工作台提供草稿恢复界面，可用已保存的参数和高程重跑。

## 从已有高度图创建世界

统一创建入口在本机版和静态站共用高程解码和海岸预览。它读取等距经纬投影、北方在上的非交错 8 位或 16 位灰度 PNG，要求长宽比为 2:1。用户为纯黑、纯白和海平面指定以米为单位的高程，像素按线性映射换算。TIFF、实际以米存储的图像和只有陆地信息的阈值映射由本机地图导入工具处理，不由这个创建分支承接。

创建步骤复用气候实验台的 Worker 和气温模型，但不使用样例页面的 Canvas 解码。预览和实验通过像素中心所在的源图像素采样。原始 PNG 及其高程映射进入地质层的正式输入，正式构建直接读取这份原图。与引擎兼容的天体参数写入天文和地质输入；用户在实验里指定的公转周期和递减率不覆盖正式构建的物理输入。

初始世界按完整世界快照格式打包，可用 CLI 恢复。静态站将同一个压缩快照写入浏览器存储；本机站将快照校验后还原到新的世界目录。两种保存操作都不启动构建。受支持的世界备份可在静态站世界列表恢复，不覆盖同名世界。

创建时可同时保存年均和逐月温度。软件记录内核源码的哈希、实际输入的指纹、温度单位、月份顺序和网格口径。温度文件位于 `layers/climate/derived/browser-temperature/`，不写入正式的球面网格。输入一旦变化，旧结果不参与保存。世界数据的二维预览可在关闭或刷新后直接读取保存的结果。

## 从起步模板创建世界

两种站点在同一页面提供基础行星和类地行星。两者使用同一套仓库模板，也使用相同的名称、世界 ID 和随机种子。静态导出将模板的世界配置和正式输入附到站点，浏览器据此生成带 SHA-256 校验的世界快照。本机 API 将同一个模板复制到新的世界目录。不论保存位置，创建过程都不写入高程、地图或任何计算产物，也不会为类地行星自动套用真实地球高程。

静态站可以从世界列表恢复浏览器创作生成的两类快照。起步世界的快照也可以用 `dreamulator snapshot restore` 恢复到本机。若要给起步世界添加全球高程，或由生成器计算地形，可在本机使用地图导入或正式构建。静态站的区域数据工具仍可单独给浏览器世界添加区域数据，但不会用区域数据替代全球高程。

## 正式构建的网格参数

本机与静态站的世界工作台都提供「世界参数」。地形网格单元数是正式构建的输入。完整 EBM 试算使用最近构建的地质网格，浏览器温度预览始终使用规则网格。本机在所属世界或分支写入地质层的正式 YAML 文件。如果地质引擎读取独立的地形配置，就保存到该配置；如果从行星设定初始化地形，就保存到该行星的地形字段。保存不会启动构建，也不会删除地图。如果已有地图仍使用旧设定，构建面板会提示重新构建。

从气候层或其后分叉的分支沿用上游地质网格，不能单独改分辨率。复用已有网格的导入模式和真实地球参照也不开放写入。本机计算占用计算槽时不接收保存请求，表单打开后如果输入已在别处修改，也必须重新读取。浏览器自建世界将参数写入自己的世界快照。下载并在本机恢复后，正式构建读取同一个值；已有的浏览器气候试算和原始高程不受影响。静态发布的世界只允许查看。

## 正式构建的天体参数

「世界参数」还提供主要天体的自转周期和邦德反照率。主要天体对应正式构建读到的 `planets.yaml` 中第一项。自转周期是相对远方恒星自转一周的时间，以地球日计，必须大于零。邦德反照率是反射回太空的入射辐射比例，取值从 0 到 1。保存只写地质层的正式输入，不改写恒星系统中另行记录的设定，也不修改现有地图和气候结果。正式构建读取这些值；如果文件比现有正式气候结果更新，构建面板会提示重新构建。

从气候层或其后分叉的分支只能查看上游的天体设定。可以独立修改地质设定的分支会把改动写到分支本身。浏览器自建世界把修改写入可下载的世界快照，原始高度图、气候实验草稿和已保存的实验结果保持原样。真实地球参照和静态发布世界只能查看。

## 参数页布局

「世界参数」把正式输入归入「天体」和「地形与网格」两组。宽屏把名称、值、单位和可填范围放在同一行，窄屏允许换行。每项参数的帮助图标提供说明和适用的只读原因。只有在已知正式输入文件路径时，分组才显示「详情」，展开后只显示该路径。只读分支沿用相同的行布局，但不显示编辑或保存控件。

## 限制与验收

首跑需要能从当前站点读取运行时资源。可独立打开的离线包与分享能力属于后续设计。
原型验收覆盖运行时加载、选图预览、运行失败、年均与月度切换，以及静态站内的本地计算。
性能样本须分别记录首次加载与内核计算，不能用单次计算耗时代表首屏加载时间。
正式入口验收另见[前端入口提案第八节](../proposals/frontend-entry.md#8-分阶段验收)。
