# 全球画布链：画布生成、外存水文与区域裁窗

> 本文描述已实现的全球高清地形链：S1 把每块大陆整块生成为一张 terrain-diffusion（下称 TD）分块画布，
> S2 在画布上做外存水文，S3 裁出区域数据包交给现有渲染腿，另有一张整画布的超高清总览图。
>
> 源码：S1 在 `src/dreamulator/map/td_canvas.py`（几何、布局、归属、混合与取样）、`td_canvas_build.py`
> （布局配置与每张画布的输入）、`td_canvas_worker.py`（TD 虚拟环境里的生成进程）与 `td_canvas_mosaic.py`
> （总览图）；S2 与 S3 在 `src/dreamulator/media/canvas_hydrology.py`（全局前沿参照实现）、
> `canvas_hydrology_tiled.py`（三段式填平与分块汇流）、`canvas_lakes.py`（洼地层级与湖级联）、
> `canvas_pipeline.py`（磁盘驱动与矢量河段）、`canvas_window.py`（裁窗）与 `lake_masks.py`（湖面足迹）。
> 命令行是 `export canvas` 子命令组（`cli_export_canvas.py`）。湖与河道判定的制图背景见
> [drainage_cartography.md](../../knowledge/cartography/drainage_cartography.md)，TD 模型本身的能力边界见
> [terrain_diffusion.md](../../knowledge/cartography/terrain_diffusion.md)。

## 1. 数据流与命令

```bash
# S1：布局与输入（读世界目录下的 canvas_layout.yaml），然后逐张画布生成分块
dreamulator export canvas plan nacrea                     # 默认写到 <世界>/canvases/<分支>/
dreamulator export canvas generate data/worlds/nacrea/canvases/gcm-t42-712 \
    --td <terrain-diffusion 克隆> --gpus 0-7
dreamulator export canvas status data/worlds/nacrea/canvases/gcm-t42-712 --verify

# S2 与 S3：外存水文，然后裁出区域窗口包（水文没做完时 window 先补跑）
dreamulator export canvas hydrology <canvas_dir>
dreamulator export canvas window <canvas_dir> --lat 15 --lon -100 --span-km 550
dreamulator export render <窗口包> --style all

# 整张画布的超高清总览图（默认每 4 像素取平均，约 360 m 一像素）
dreamulator export canvas mosaic <canvas_dir> --step 2
```

一张画布由 `ncell × ncell` 个粗格组成，粗格边长 23 km，每个粗格含 256 × 256 个像素，像素边长约
89.84 m。画布按 8 × 8 粗格分块，每块 2048 × 2048 像素，存成 int16 米值的 `.npy`，并以 `canvas.json`
记录几何、分块清单、生成参数与气候编码表。海平面固定为 0 m。裁出的窗口包使用与 `export region`
完全相同的 `input/` 与 `refined-out/` 词汇，可以直接交给 `export render` 出图。

## 2. S1：画布生成

### 2.1 投影与坐标

画布是方位等距平面，投影中心取所含陆地的最小覆盖圆心（`minimax_centre`，能盖住全部成员陆地的最小
球冠的中心），球半径取行星真实半径。平面坐标 x 向东、y 向北，单位 km；从中心出发的平面距离等于球面
大圆距离，方位角也保持不变。径向比例尺处处为 1，切向比例尺为 c / sin c（c 为到中心的角距离），两者之比
称为各向异性（`anisotropy`）。经纬度、平面与像素坐标的换算集中在 `CanvasGeometry`，支持数组输入；
所有消费者共用这一份换算，不另写公式。

像素坐标以角点为原点，第 0 行是北边缘，第 0 列是西边缘；像素 (r, c) 的中心为 `x = −half + (c + 0.5) × px`、
`y = half − (r + 0.5) × px`。粗格 (i, j) 覆盖行 `[256i, 256i+256)` 与列 `[256j, 256j+256)`，分块 (ci, cj)
覆盖粗格行 `[8ci, 8ci+8)` 与列 `[8cj, 8cj+8)`。这里采用角点对齐，与上游 `tiff_export` 写出的仿射变换
一致；按格心理解会整体偏移约 11.5 km，是整套坐标里最容易出错的一处。

### 2.2 布局

布局规则在 `td_canvas.py`，作者的选择写在世界目录的 `canvas_layout.yaml`（`CanvasLayoutConfig`）：

1. **陆块**（`land_components`）：CVT 网格上的陆地格按邻接连成陆块。面积不小于一个分块（约 3.39 万 km²）
   的陆块参与分组；更小的陆块只在落入某张画布的生成范围时随之生成。
2. **分组**（`plan_layout`）：陆块按面积从大到小处理。离已有组的陆地不超过两倍缓冲宽度（400 km），
   并且合并后边缘各向异性不超过 1.15，就并入该组，否则自成一组。画布半边长等于最小覆盖圆半径加 200 km
   缓冲，再取整到偶数个分块；陆架延伸（2.3 节）需要更大时随之放大。
3. **切割圆**（`LandCut`）：单个陆块就超过各向异性上限时，作者放一个切割圆，通常在地峡上。圈内陆地格
   暂时从邻接图上去掉，陆块断成几片。普通切割圆的半径不得超过缓冲宽度，圈内陆地不属于任何一片；
   颈部比缓冲带宽时用**归还型**切割圆（`reattach`），切开后把圈内陆地按最近距离还给各片作为成员陆地，
   代价是陆上多一条穿过圆内的归属分界。
4. **固定编号与强制合并**：配置的 `names` 用「一个陆上种子点对应一个编号」给主要画布固定编号，其余画布
   按投影中心自动命名（形如 `land_-31p8_+135p9`，会随地形微调而变）；`joins` 把一个陆块强制并入另一个
   陆块所在的画布，不受合并距离限制。

nacrea 当前是 19 张画布、9259 个分块、约 388 亿像素，int16 存储约 78 GB。世界岛用两个切割圆切成三片：
南北地峡（37.0°N 70.0°W，半径 120 km）切下的东北角并入北极大陆的画布，78°W 10°N 东北侧的宽颈
（12.0°N 74.0°W，半径 250 km，归还型）把其余部分分成 `world-west` 与 `world-southeast`。

### 2.3 生成范围

一个分块入选画布的清单，只要它至少有一个粗格满足下面两条之一（`chunks_near_land`）：

1. 粗格中心离本画布成员陆地不超过 200 km；
2. 粗格中心最近的网格格是本画布的**陆架格**（`shelf_cells`）：海洋格，水深浅于 2500 m，离本画布
   成员陆地不超过 600 km，并且按 2.4 节的规则归本画布所有。

第二条的依据是 TD 会把近海平面的浅陆架抬成陆地：只有缓冲带时，这类陆地在缓冲带外缘被分块边缘截断。
归属条件保证画布不会伸进邻居的地盘。600 km 与 2500 m 是覆盖范围的选择（大陆坡坡脚的典型深度），
不是物理参数。

### 2.4 归属与过渡带

相邻画布的生成范围会重叠。重叠区里同一地点有两份 TD 高程，消费者一律用同一条规则取舍：**一个地点
归属于成员陆地离它最近的那张画布**（`owner_of`，按球面大圆距离）。布局目录附带全部成员陆地点的单位
向量表与所属画布表，求值不依赖 CVT 网格。这条规则让每块陆地都归属于自己的画布，海岸线与流域完整
落在单张画布内，分界线落在海峡或海洋中间；世界岛上的两个切割圆是仅有的陆上分界。

分界线两侧是两次独立生成，消费者用 `blend_overlap` 混合，分块文件保持 TD 原样输出：

1. **默认两频段。** 两张画布各自分成低频骨架（高斯低通，σ = 15 km）与细节；骨架按到两侧成员陆地的
   距离差在 92 km 宽的带内混合，细节在 4 km 宽的带内混合，权重是距离差的平滑阶跃（`blend_weight`，
   3t² − 2t³）。这样分界处没有台阶，带内又保留一侧的完整细节。
2. **海陆不一致处改整体混合。** 两张画布一张高于 0 m、另一张不高于 0 m 的像素，外扩一个粗格后改用
   92 km 宽的整体混合，避免细节层的硬切切出笔直的海岸。

带宽取 92 km 而不更窄，是因为平坦低地上两次生成可以整体相差几十米，窄带会把这段高差压成一条平行于
分界的直线。这组带宽是在世界岛两处陆上分界上目视标定的渲染选择。

### 2.5 条件场与气候通道

每张画布的输入由 `write_canvas_inputs` 写出，全部气候取自布局配置指定的分支（nacrea 为 GCM 固定气候
分支 `gcm-t42-712`）。

- **条件场**（`conditioning/`）是 TD 实际使用的五个输入：引擎高程、订正到海平面的年均气温（递减率随
  降水在 −9.8 到 −4.0 K/km 之间取值，与区域链相同）、月均气温的标准差、年降水与月降水的变异系数。
  气温、降水等四个气候条件在 4 倍细的网格上取最近的 CVT 格，再按 4 × 4 求块平均（`sample_mesh_field`）。
  高程底场改用抗混叠取样（`antialiased_height`）：4 倍细网格上的数值取网格格高程的 Clough–Tocher 插值并截断到
  三角形顶点范围，海陆正负取到网格海岸（高程大于 0 m）的有符号距离、经半个网格间距（格心最近邻距离的中位数）的
  高斯低通后的符号，每个网格格心四分之一格距以内保持该格自己的海陆（单格岛屿不会消失），符号与数值冲突的像素取
  ±1 m，再求块平均。这样可以减少条件场的格子平台与海岸锯齿，但不保证沿岸低地带宽度或山地形状摆脱网格影响；
  海陆标签在外扩三倍标准差的网格上求取，网格不完整时插值凸包之外退回最近格。代价是格子平均高程不再严格不变。
  格心保号描述当前实现，不是所有粗格都应作为地理锚点的物理要求；约束范围与沿岸平原的后续验收见 `proposals/canvas-conditioning-structure.md` 4.2 节。
  海平面气温订正仍参照格子平均高程。条件场逐位相同是两次生成得到同一地形的前提，`canvas.json` 记录每个条件场的
  sha256 与高程底场的取样方法（`height_sampling`）。
- **气候通道**（`climate/`）供水文与渲染使用：年均与月均气温、年降水与月降水、年径流（Turc–Pike，
  n = 2）、Hamon 年潜在蒸散、月径流（土壤水桶加基流给出月形状，乘以年径流）、冰厚、NPP、柯本与群系
  编码。公式派生的量先在 CVT 格上算好再取样，不在粗格上重算非线性量。连续场用 Clough–Tocher 插值
  （`clough_tocher`）并截断到所在三角形的顶点取值范围；月径流与类别编码用 `sample_mesh_field`。海洋
  粗格上的陆地专属量记为 NaN。编码通道取粗格中心的最近格，在海岸会与高程判定的海陆不一致，消费者
  判定海陆一律以高程是否大于 0 m 为准。

地质网格的 `elevation` 已包含冰盖表面，受载基岩高程为 `elevation − ice_thickness_m`。
TD 高程条件使用这一地表高程，`climate/ice.m.npy` 另存粗尺度冰厚，供水文与渲染使用。
高清分块按地表高程解读。登记覆冰区可采用第 2.5.3 节的固定冰量更新，细化冰厚独立保存；
长期物质平衡与历史基岩冰蚀继续按[冰川地貌提案](../proposals/canvas-glacial-landforms.md)验收。
高清冰下基岩按其统计来源解释。

画布计划可通过 `--precipitation-field` 读取 `NativePrecipitationField` 的完整原生高斯降水档案。
档案分别保存大尺度与对流分量的十二个月值，每个父格覆盖全部陆海面积；读取时核对面积水量预算。
此路径的降水条件和气候降水使用 `canvas_precipitation.canvas_precipitation_coverage` 提供的完整粗格球面足迹。
曲边在经度与纬度正弦构成的等面积平面中细分并裁切，面积与交叠权重的相邻细分变化均检验收敛。
相对几何容差为 2e-6；源降水在已有积分单元内保持常量，目标月值为交叠水量除以覆盖面积。
`precipitation/` 保存双精度面积和稀疏交叠权重，`canvas.json` 记录几何、校验和及两分量的十二个月覆盖水量。
原生父格的完整预算与单张画布足迹中的水量分别核验，跨画布所有权积分按其分区另行处理。
径流和潜在蒸散在此路径中由相同的粗格月温度与降水重算，类别编码沿用 CVT 分类取样。
水文计算先按导出格式量化月温度与月降水，再转换为双精度运算；下游直接读取该月度文件可以复现这些派生通道。
缺少有效来源的 NPP 连续场保存为 NaN。

`refresh_canvas_climate` 默认用于独立暂存批次的附带气候更新，保留当前 `conditioning/`、生成参数和高清分块。
`canvas.json` 将新气候来源与地形生成来源分别保存，并注明水文产物需要重算。
调用者可复用同几何的 `CanvasPrecipitationCoverage`；更新入口核对原生分区和目标画布几何。
完整气候底场随批次保存，采用后消费者按同一批版本更新。

GCM 到 CVT 的降水面积输出由 `gcm/cvt_area.py` 提供。接口从有序经纬度重建完整球面 Voronoi 分区，
将大圆边界细分到等面积坐标并与原生积分单元裁切；独立球面面积与两次细分的交叠变化共同检查收敛。
几何检查通过后，权重列归一到各原生积分单元的面积。GCM 字段保存双精度目标积分面积及原始几何面积，
格心指纹绑定取样顺序，缓存读取重新检查源列与目标行的面积预算。降水统计使用对应积分面积；
温度、风场和气压仍按各自既有取样规则输出。跨画布归属分区与完整 CVT 分区分别验收。

气候版本更新有两种消费范围。`refresh_canvas_climate` 默认更新附带的气候与水文输入；
在独立、尚未生成的画布批次中设置 `refresh_conditioning=True`，同时更新海平面年均气温、
月气温标准差、年降水和月降水变异系数，高程条件继续使用已接受来源。
随后用 worker 的 `--prepare-coarse --refresh-climate` 入口准备共享统计场：新模型查询提供
均值与气候编码，均值和低分位之差保留接受参照。全部高清块使用新条件和新共享场重新生成，
原地形块的校验和用于记录上一版本。两档高清导图消费同一批新块。

上述更新完成长期气候的重采样与 TD 消费。迎风和背风降水的亚格子差异、
局地温度变化及对应天气驱动方法继续按提案 4.1 节的候选范围验收。

### 2.5.1 条件场的构造结构与 TD 的细节幅度

布局配置打开 `structure` 后，`write_canvas_inputs` 在高程条件上叠加零均值的构造结构场（`structure_anomaly`，
`td_canvas_structure.py`）：沿等高线方向排列横切谷与山嘴，初始幅度系数为网格亚格子起伏的 0.52 倍（地球 Copernicus 拟合）。
之后的格内均值校正、陆地截断和 23 km 聚合继续改变实际起伏，最终条件场的幅度须按相应尺度统计。
谷间距按 Hovius（1996）的山脉半宽之半，每个网格格内零均值（残差在亚格子起伏的 5% 以内）；叠加后保持底场的海陆
不变，陆地至少 1 m、海洋至多 −1 m。海平面气温订正仍用格子平均高程。配合使用的生成参数是高程通道条件信噪比 0.05（数值越小条件越强），
以及 TD 输出细节系数 `residual_std` 取上游值的 2.0 倍（在地球十个地点上标定与检验，经 `pipeline_kwargs` 传给生成
进程）。设计与验证见 [canvas-conditioning-structure.md](../proposals/canvas-conditioning-structure.md)。

### 2.5.2 连续地形来源

`write_canvas_inputs` 可接收 `height_source`，通过 `terrain_source.sample_canvas` 对各个 23 km 条件格独立积分。
来源实现 `TerrainSource.evaluate`，按经纬度返回高程和海陆指示值；`ProjectedTerrainSource` 将查询转换到固定的来源投影。
`PointTerrainField` 保存支持点与插值面，`RasterTerrainField` 保存固定来源栅格，`PolylineGeometry` 提供地物折线距离。
这些对象的支持范围和参数在取样前确定，裁窗使用相同的来源。

`SphericalSegmentGeometry` 保存球面短大圆弧，查询最近线段、沿段位置、角距离和有向侧别。
曲线以来源坐标系中的单位向量表示，距离计算独立于画布投影；结果可用于将地质参数沿板块界线插值。
有限线段的端点参加距离计算，退化与对跖端点在建立来源时报告错误。

`paleo_orogens.paleo_orogen_field` 将已有古山带剖面开放为任意球面点查询，输入使用网格的单位向量坐标系（y 轴向北）。
作者路径、碰撞年龄及现有衰减和宽度关系共同决定地形贡献；陆壳范围由调用方提供。网格端的 `paleo_orogen_relief`
调用同一函数，并保留陆壳掩膜。条件场可对这一贡献独立积分，替换前后的山带组合仍采用最大值规则，随后按冻结端点传递差值。

`FrozenStageTerrainField` 将一段参考过程的冻结高程变化用于替代输入。三个回调分别查询参考过程前的地形、
参考过程后的地形和替代输入，计算顺序为“参考过程后高程 +（替代输入 − 参考过程前高程）”。各端点先完成重建与限幅，
随后作差；替代输入等于参考输入时，查询结果准确返回参考过程后的高程。回调使用同一来源平面，返回与查询坐标同形状的
高程数组。调用方在来源记录中保存三个端点的哈希。这个接口保留参考过程的高程变化，过程对新输入的实际响应由对应算子另行检验。

积分采用 Gauss–Legendre 求积，并用方位等距投影的球面面积因子修正权重。高程均值与陆地覆盖率分别累计。
源函数覆盖不足时报告错误，由调用者补齐来源范围。求积阶数通过逐级加密比较确定，跨岸格同时检查覆盖率误差。

采用该入口时，`canvas.json` 的 `height_sampling` 为 `continuous-source-v1`，`height_source` 记录来源、求积阶数和
覆盖率文件校验和。`geometry_fields/land_fraction.npy` 保存结构增量叠加前的陆地覆盖率，作为来源几何记录；现有下游
海陆判定继续使用最终高程。气温海平面订正仍参照气候输入对应的网格格高程。结构增量在来源底场上叠加，并单独记账。
当前常规布局沿用抗混叠入口，连续来源由首版局部试验显式传入。

`VolcanicConeField.surface_m` 在球面短弧距离上查询目录锥体，与提供的背景表面取最大值。
`VolcanicCone` 由完整精度的当前峰顶、背景和建成坡度确定基底范围、出水面积及几何体积。
调用方保留 `volcano_cell_mean_m` 作为原贡献，替换、后续阶段响应和重叠体积分别记账。
`FrozenVolcanicReplacement` 冻结接受的最终表面及撤回所选原贡献后实际重算的最终背景，
将当前锥体与后者组合，再减去接受表面的连续重建。全部背景响应随差额传递。
普通高程钉扎在实际地质重放中约束粗格均值，显式海峡与陆桥约束则由调用方核对地物支撑范围。
目录基底相对于同一背景定义；水平基底与倾斜背景的接触连续性及组合体积分别验收。
`FrozenVolcanicDeposit` 将当前剖面作为该背景上的连续厚度，校验中心基底参考，
单体体积按球面面积积分；实际出水轮廓消费组合表面，重叠厚度的包络体积单列。
这一接口供连续地物试点显式使用，生产布局的采用范围另行验收。

`ConservativeArcField` 按弧长测度将弧段预算映射到共享节点，以隐式图扩散完成零端点通量的平滑。
节点测度加权积分在映射和平滑中保持一致，沿轴线性插值与离轴有限弧延拓分别验证。
原数值平滑半径通过核的第二矩对应扩散时间，实际物质输运另由地质过程定义。

`orogen_source.CollisionProfileField` 将保守沿轴量接入现有碰撞剖面，读取同一 Airy 截面积、
地球粗格翼坡标定和力平衡高程上限。有限端部、远离山带时的整段均值及陆壳覆盖按来源分别处理。
`FrozenOrogenReplacement` 在冻结的活动山带与古山带最大值包络中替换所选贡献，
参考格位置、旧贡献及陆壳覆盖在建立对象时冻结。对象返回高程差额；对应下游过程的实际响应另行验收。
来源对象与目标投影分开，查询可复用在条件积分、粗格诊断和相邻裁窗中。

`coastal_source_from_native` 从 `terrain_sources.npz` 的实际陆架输出、岸坡前后高程及
冻结低地目标准备连续岸坡差额。入口核对档案类型、格数、地形指纹和阶段连接。
调用者显式提供宽度、平原高程分界、山岸比例和剖面来源参考；来源元数据保存档案哈希及其适用范围。
`CoastalPlainDifferenceSource.footprint_support` 合并新剖面宽度和旧阶段改变顶点的实际岸距，
并包含源三角形最大边长与目标格半对角线，以覆盖旧端点重建的全部可能差额。
该入口提供冻结数值阶段重建，局部平原的生产依据和与其他来源的共同采用按对应声明核验。

`collision_source_from_contract` 从完整界线、有效接触历史和来源数组准备连续活动剖面，
按原顺序保留正贡献弧，并纳入具有有效历史的零贡献弧。接触格的坐标和板块编号与来源网格共同核对。
`paleo_source_from_history` 使用作者路径和碰撞年龄，沿用现有衰减规律及楔体宽度；
准备时先逐值重放完整古山带参考场。两种来源均要求其参考贡献复现归档包络。

`orogen_source_from_native` 按显式的活动分段编号和古缝合带编号准备组合来源。
古山带的活动峰高参照由原碰撞峰高统计规则推导，所选连续剖面由
`OrogenEnvelopeProfileField` 先取最大值，再与其余冻结贡献共同组成新包络，最后减去旧包络。
这一顺序保留重叠山带的主导关系。未选山带继续按原来源格传递，陆壳覆盖和参考态保持冻结。
准备接口检查来源选择的唯一性，以及所选和其余贡献对完整参考场的重放。
该接口完成原生来源的组合准备；常规布局的来源选择与全量高清采用按其声明范围验收。

`FrozenOrogenReplacement.continuous_reconstruction` 为连续背景组合准备独立的
`ContinuousOrogenReplacement`。所选来源、其余活动山带、古山带和冻结地壳指示量
共用正权球面三角形重建；地壳覆盖作为原指示量的连续数值比例使用。
两份最大值包络在贡献重建后分别求值，再作差，原阶段的包络重建残差保持冻结。
来源记录保存独立重建哈希及覆盖策略；支持范围包含源三角形最大边长。
所选解析剖面的整体几何连续性按完整来源另行核验。
原最近格入口及接受版查询方式按其原声明使用。

活动剖面的 `with_continuous_arc_envelope` 为每条有限弧准备连续方向距离剖面，
使用现有两翼坡度及后侧平台宽度，再取同一山带内的高程最大值。
各弧共用接受缩短量场与到整条来源的距离均值延拓。共享节点和开放端点均参与有限弧计算，
端部策略及连接度随来源元数据记录；原 `with_continuous_endcaps` 供开放端点诊断使用。
几何定义及其数值适用范围见
[造山剖面 4.1](../../knowledge/geology/orogen_topography.md#41-有限山带端部的数值延拓)。
该入口供共同表面的数值候选使用，生产采用分别验收端部体积、岸线收敛和下游阶段响应。

原生来源档案保留地形组合至作者高程约束之间的实际表面。
`cell_area_km2` 保存与 `xyz` 同一来源格的实际球面面积，供体积账本和保守传递使用。
`shelf_continental_crust_mask` 保存陆架入口实际 `crust_type == "continental"` 的指示量，
包括地理准备和地壳重标的结果。`land_crust_mask` 保存造山来源的
`crust_type != "oceanic"` 资格；两项判据及地表海陆分类分别使用。
构造阶段快照的标签按其实际年代读取，陆架重放使用陆架阶段捕获的标签。
`combined_elevation_m` 与 `after_initial_sea_level_m` 标记初次海面校准，
`orogen_cap_m` 保存活动山带实际拥有者的平均高程上限，
`after_orogen_cap_m`、`after_interior_lowlands_m`、`interior_lowland_clamped_mask` 和
`after_deposition_fill_m` 记录高程上限、内部低地及沉积消费。
岸坡之后的 `final_forearc_surface_m` 使用实际初次校准和配置海面基准，
`after_forearc_m`、`after_deep_ocean_clamp_m`、`after_final_sea_level_m` 及
`after_overlay_archipelago_m` 记录前弧、限深、末次海面校准和岛群纹理。
`final_elevation_m` 为作者高程约束后的表面。各字段仍采用原生地质网格精度，
单位和参考基准随档案记录；连续来源按同一阶段顺序消费这些约束。

`canvas_refinement.prepare_refined_canvas` 将已积分的来源差额加到参考 S3 高程条件，
写入独立输入批次，并保留参考结构、生成参数及气候通道。元数据保存来源、参考端点哈希和求积阶数。
高程来源更新时，先核对生成批次与目标地质网格的格心、高程和地形指纹。
生成高程条件、附带月气候和渲染图各自保存来源版本；附带气候刷新与重新渲染分别消费现有地形块。
已有地质增量的传递使用相同的参考重建和覆盖取样，再加到接受的高程条件，保留原结构贡献。
最近源格取样和连续来源积分分别声明其数值口径，来源更新与重建方法变化分别验收。
整批来源更新沿用参考布局和归属表，并在每张画布的来源声明中保存生成参照指纹、
目标地质指纹与差额定义。完整总览在相同地表阶段、坐标范围和色表下比较，
海洋水深与恒定海洋颜色分别用于核对浅海带和实际岸线。
来源更新后的冰面与水文产品使用新生成地形作为参照，资产状态记录各自的生产阶段。
调用方同时提供新高程均值对应的六通道 TD 编码场，以及已接受的统计参照。
`coarse_source` 按 `fixed-coarse-statistics-v1` 保存二者的相对路径、哈希和形状，
统计采用参考的均值减第五百分位之差，四个气候编码通道逐值保留。
字段中的低尾差按现有 TD 编码保留符号，float32 的差额重算误差容限为 8×10⁻⁶ 个编码单位。
`td_canvas_worker.translate_coarse_mean` 按编码均值差同步平移低分位；
均值响应为零的格点逐字节保留全部参考通道，避免低尾差往返计算产生远端舍入变化。
`td_canvas_worker.prepare_coarse_statistics` 在同一固定模型、种子和条件 SNR 下生成候选均值，
读取参考批次的冻结共享场，或从所声明的原 S3 条件生成参照。已包含来源细化的参考批次
使用其配套 `coarse_source`。准备时核对两批的几何、生成配置、结构声明和五个条件文件的哈希，
四个气候条件输入逐字节相同。每次安装条件后重建 tile 缓存，查询完整含边界的六通道编码场；
候选场只采用新均值，低分位差和四个气候输出由参考场传递。
这项固定气候政策用于地质来源实验；明确刷新气候的批次按 2.5 节更新四个气候输入及共享场的气候编码。
worker 的 `--prepare-coarse` 模式将候选场、参照及校验回执写入独立目录，供细化输入安装时复用。
常规 `export canvas refine` 通过 `canvas_orogen_refinement.refine_canvas_layout` 完成来源选择、
条件积分和共享统计场的整批准备。`CanvasRefinementConfig` 按画布声明唯一的活动分段和古缝合带编号；
`load_native_inputs` 按分支解析作者配置、来源档案和造山契约，核对物理半径并记录输入哈希。
原生替换入口使用原始 S3 参考，已接受细化批次沿用其配套来源和统计参照。
`FrozenOrogenReplacement.footprint_support` 将有限宽度的新剖面与旧正贡献格的可能最近邻覆盖合并。
支持范围使用目标 footprint 的球面位移上界，适用于稀疏和不均匀来源网格。
`integrate_source_correction` 使用球面面积 Jacobian 和 Gauss–Legendre 求积，常规选择依次检查
8、16、32、64、128 阶；相邻阶差的第 95 百分位须小于等于 2 m、最大须小于等于 10 m。
来源通过 `FootprintTerrainSource` 提供匹配目标形状的布尔支持范围。
原山带接口 `integrate_orogen_correction` 是这一共享函数的别名，岸坡使用同一积分规则。
数值门槛通过后调用 GPU worker 准备统计场。整批在临时目录准备并核对条件和统计回执，
完成后安装新目录；布局与归属表保持，未选输入按原值复制，原高清块保留在原批次。
每张所选画布的 `preparation/statistics.json` 保存准备时间和文件哈希，
根 `layout.json.height_refinement` 保存选择、来源指纹及积分收敛记录。

所选来源可通过 `statistics_reference` 指定已接受的统计参照画布目录。
该目录保存完整条件与自含的 `coarse_source`；其画布编号、几何、模型、结构声明和四个气候
条件须与本次 S3 参考一致。高程参考继续来自原始 S3，统计参照按其接受版本单独记录。
准备入口先核对参照，再在临时目录复制所需输入，按参照均值减第五百分位之差生成候选。
条件高程与已接受参照逐字节相同时，直接复用该参照的六通道场。
统计参照的路径、画布哈希和共享场哈希保存在来源及整批回执中，其查询前缀传入高清阶段。
参照路径按选择文件所在目录解析；省略该字段时使用原始 S3 的统计政策。
历史接受产物可在独立目录封装完整条件、原统计场和实际查询顺序，原存档保持。

岸坡及陆架来源可显式调用 `terrain_curves` 导出其冻结参考场的海岸曲线，坡度按缺值记录。
`ShelfEnvelopeDifferenceSource` 的剖面在固定背景与岸距上求值，下沉板块保护域仍用最近源格标签。
域内返回原陆架端点，域外使用新剖面包络；这一切换的源点重放与边界极限分别核验。
完整共同阶段接入还须验收对应作用域及两份表面的连接。
显式 `protection_policy="source-weight"` 将原生资格放入同一来源三角网，按其正权重组合
原阶段端点与新陆架包络。全保护区返回参考端点，混合三角形表达粗格证据的数值比例。
`shelf_source_from_native` 使用这一策略准备来源，核对档案指纹、实际地壳掩膜、下沉板块标签、
陆架输出与岸坡输入；坡折、陆坡及剖面依据由调用方显式提供。直接构造的默认策略保持最近格路径。
该导出入口按需运行，曲线档案供来源诊断使用，默认阶段查询沿用原输出。
点值重建按原输入精度解释；源积分的收敛和旧格均值的约束分别记录。
`CoastalPlainDifferenceSource` 对冻结岸带阶段求差，将新岸距下的固定剖面减去独立重建的参考阶段。
`apply_profile` 对显式传入的表面、目标与岸距应用同一固定剖面。
`ShelfCoastalDifferenceSource` 先消费陆架替代表面，再以其已核验岸线计算岸距和岸坡；
差额相对原生岸坡端点，已包含前置陆架变化。构造时核对半径、基准、源点及实际阶段连接。
下游试点以同一来源权重组合各顶点的上界削减与下界抬升响应，无限非激活边界的响应为零。
实际粗格重放重新计算海陆邻接和最终海面，叠置地形及作者约束按原顺序执行。
研究调用方将该差额加到已有底场，并保持 S3 统计幅度及气候条件。
这些模块目前用于显式来源实验，生产中的地物存在范围、宽度和岸边高程依其来源验收。
沿轴保守传递、西岸连续岸坡与暮光实际阶段响应已获局部效果接受，固定 S3 统计幅度及方向。
常规非对称地质合成已将已有挠曲作用域传入陆架阶段，后续阶段消费实际地表；
暮光固定窗口的条件逐值复现已接受的实际响应版。连续岸坡与沿轴来源的常规画布接入分别推进。
板块对的明确极性与年代来源由地质契约保存，海沟、岛弧和陆架作用域使用地壳准备完成后的共同快照。
接口时点、默认近似和缓存恢复见 [地质管线 6.1](geological-pipeline.md#61-历史契约汇聚边界段orogen_contractpy)。

### 2.5.3 固定冰量的冰面更新

`canvas_ice_surface.source_ice_bed` 用含冰高程条件减去现存冰厚提供受载基岩均值，
并按地质层的 `relief_std_m` 设置基岩纹理幅度。TD 残差的均值与方差在实际地质格距上测量，
覆冰指示量的连续插值用于来源连接。分块批处理共用同一统计场与纹理均值，基岩按统计先验记录。

`redistribute_ice` 在固定基岩上求解等温浅冰方程。相邻格成对交换冰量，自适应时间步保证非负与体积预算。
当前数值更新采用 5750 m 格距、100 年模型时间、重力 10.28 m/s²，以及温冰参考速率因子
2.4 × 10⁻²⁴ Pa⁻³ s⁻¹。原生纹理统计在 1437.5 m 汇总格上计算，求解场回到原生像素后按冰体积校正。
固定窗口的 5750 m 与 1437.5 m 对照中，厚冰的 10 km 起伏指标相差约 0.2%，薄冰约 2%。
物质平衡取零，继承覆冰范围的边界封闭。冰体按连通域求解，
跨越地形分块的冰体共用同一个求解域。这一更新描述固定冰量的表面响应，长期气候平衡与冰床侵蚀另行计算。

回到原生像素时，用共享冰面和来源冰量的边缘支撑恢复非负冰厚，并对每个连通冰体求一个
保持原始冰体积的高程偏移。原海洋及来源冰量为零的像素沿用原高程，受载基岩的局部露出按实际海平面判断。
`chunks` 保存量化后的现今地表高程，`surface/ice_chunks` 保存浮点冰厚；二者相减提供同一统计先验的受载基岩。
原生像素冰厚是受来源约束的延拓，冰流的解析尺度由求解网格决定。
温度、降水与原 TD 生成条件分别保留其既有来源，水文从更新后的地表重新计算。

### 2.5.4 气候物质平衡试点

`ice_mass_balance.monthly_snow_and_pdd` 消费十二个月的科学气温、降水和显式温度标准差，
给出降雪水当量与正积温。`annual_ice_balance` 按季节雪、裸冰的顺序消融，
并输出保留冰当量、两种消融量与逐格水量残差。雪与裸冰的度日因子采用 PISM 的地球观测参考，
分别为 3 和 8 mm 水当量/(K·日)。近似与标定域见
[冰盖物质平衡](../../knowledge/geology/ice_sheets.md#13-气候物质平衡与正度日近似)。

当前配对试点消费来源同步后的 TD 地形与定版 T42 月气候，温度波动来自同批高频近地面气温。
固定受载基岩，按现今冰面与气候参考面之差应用 0.0065 K/m 的递减率，每年执行一次物质平衡与浅冰流动。
求解网格采用 5750 m 格距和 100 年模型时间，冰可进入来源无冰的陆地，海洋及窗口外边界封闭。
原生延拓使用求解冰厚的支撑范围，并保留求解域的最终冰体积；180 m 与359 m图使用同一地表。

这一试点位于气候之后的画布地表阶段，地质网格、GCM 边界、冻结月字段和正式画布保留参考版本。
200k 数值输出目前记录物质平衡与冰当量储量，高清窗口输出相应地表和独立冰厚。
年度保留雪、长期厚冰和现今冰面分别验收；长期热状态、海洋出口与完整跨画布求解按冰川提案继续处理。

### 2.5.5 基底热状态诊断

`ice_thermal_column.steady_ice_column` 以地表温度、冰厚、正积累率和显式基底热通量
计算稳态冰分水岭柱的热状态。Robin 积累柱保留向下输送冷冰的平流与垂向导热，
材料性质采用 PISM 的冰参考常数。输出包括受压力融点约束的基底温度、冷柱导热通量、
过剩热量对应的融化潜力，以及 H²/κ 的导热响应时间。公式与适用域见
[积累柱热状态](../../knowledge/geology/ice_sheets.md#14-积累柱的基底热状态)。

该接口供独立热状态诊断使用，当前物质平衡与冰面配对试点仍采用共同的温冰参考流动率。
融化潜力暂与冰量账本分开保存；基底滑动、水平平流、应变与摩擦加热，以及融化引起的垂向速度变化
由后续求解处理。调用方显式提供冰床热通量，全球潮汐或火山热释放按其物理路径另行解释。
历史强迫准备与全面覆冰方案见[冰川提案第 4.0.3 节](../proposals/canvas-glacial-landforms.md#403-历史强迫与覆冰进退)。

### 2.5.6 共享球面冰量与海洋出口试点

`spherical_ice_flow.spherical_ice_mesh` 从同一全球 Voronoi 分区准备陆地求解域，
保留格子编号、实际面积、公共边长度和格心球面距离。画布边界作为下游取样边界，
冰量交换按全球公共边计算。采用导出几何时，短边长度需要保留足够精度；
从经纬度重建的几何与原面积分别核对，气候和地质字段继续按同一格子编号读取。

`flow_spherical_ice` 使用等温浅冰流动、格面法向高差和切平面的最小二乘梯度。
供冰侧厚度确定非线性扩散率，相邻格交换相等体积；自适应时间步保证非负冰厚。
海岸位于陆海格心之间，首版以零米海面作为吸收边界，跨岸流出的固态冰进入海洋输出项。
关闭海洋面得到同几何对照，湖泊面在这一试点中封闭。

`evolve_spherical_ice` 每年计算季节降雪、雪融和裸冰消融，再更新共享冰流。
月降雪和正积温快照在年度中点按时间混合，年末保留雪按冰当量进入储量。
初始冰量、最终储量、降雪输入、地表径流和海洋输出共用体积账本。
一年与两年的流动更新间隔用于检查物质平衡和流动的分步误差。

当前范围是固定受载基岩与参考气候面的空间响应试点。全球格子保存基岩、冰厚和相应冰面，
高清窗口读取共同状态作形态检查。海岸吸收边界表示固定范围的陆地冰输出，
漂浮冰架、出口前缘应力、基底热传播与冰面气候反馈按提案分别验收。
候选空间结果与现今平衡冰面分别解释，全面地表更新仍按同一来源版本集中安排。

初版画布地表消费这一共享来源，并保持已接受的 S3 统计幅度和来源同步地形。
一个完整季节循环内始终保留裸冰储量的格子提供全年覆冰来源，夏季完全融化的季节雪另行记录。
全球冰厚、受载基岩和地质起伏统计使用 `SphericalPointTerrainField` 的共同球面权重，
在1437.5 m支架上取样，再恢复原生像素。冰下基岩的纹理由同一画布的共享残差统计归一化，
其幅度使用地质层的起伏标准差。共同球面状态提供细尺度响应的基岩与冰量种子。
与外海连通的海洋像素保持来源同步后的高程；不连通外海的海面以下像素按陆地处理（第2.5.8节）。原生冰厚另存于 `surface/ice_chunks`，
`climate/ice.m.npy` 保存23 km格内均值，全球独立字段保存在画布根的 `surface_ice_source.npz`。
球面求解冰量与单张投影画布的像素冰量按各自面积口径保存，画布重叠区单独解释。

`render_mosaic` 的 `ice_overlay=True` 从原生冰厚块读取超过1 m的覆冰像素，
并按输出像素内的覆盖率混合浅蓝白色。阴影仍读取相应冰面高程，颜色表达覆冰范围。
该选项保持地表数据和海洋深度，180 m和359 m图消费同一批原生块。
初版采用固定气候参考面和受载基岩，长期冰面反馈、冰床滑动与热状态继续按提案验收。

### 2.5.7 亚格子覆冰与冰面延拓

画布的月气候在其参考高程上保存。细尺度物质平衡按更新前地表与参考条件面的高差，
应用0.0065 K/m的递减率，同批高频GCM提供月内温度波动。降雪、季节雪融与裸冰消融
继续使用第2.5.4节的预算。50 km父格平均高程下无冰的山地，其高清峰顶可形成净积累区；
EF分类与永久覆冰仍分别判断。

`annual_snow_storage_and_ice_melt` 给出年末保留雪G与裸冰消融潜力D，均以冰当量米表示。
固定气候下的年度储量递推为`H_next = max(H − D, 0) + G`。
`fixed_climate_ice_minimum` 用该式的闭式解计算100年响应，年末新雪与全年最小裸冰储量分开保存。
调用方以50 m高差步长准备物质平衡查表，再按参考气候位置与实际高差取样。
这一步保持冻结月气候，运行中的地表反馈由后续联合求解承担。

细尺度冰面以5750 m格距计算10年的固定冰量浅冰响应，海洋面与画布外框封闭。
`redistribute_ice`的`support_fraction`按部分格（cut cell）处理含海面的求解格：
冰量按格平均体积记账，铺在能承载冰的面积比例f上，基岩取这部分的平均高程，
每条格面的通量按两侧较小的比例f缩放。完全陆地格（f = 1）与标准格式一致。
因此含海面的海岸格与内陆格一起流动，格间不再出现保留冰量造成的方块台阶。
这一短时响应接在共享球面种子之后，全球海洋输出仍由第2.5.6节的共同域计算。
气候储量、细尺度交换和原生延拓分别记账，两种响应时间表示各自的初版计算范围。

`subgrid_ice_surface_level` 按原生基岩高程分布求解`mean(max(s − b, 0)) = H`，
给出相应冰量的水平面几何延拓。露出该面的峰顶保留为裸岩。
`subgrid_ice_relaxation_fraction` 从浅冰方程的单一正弦模式估计未解析起伏的衰减，
使用冰厚、初始地表方差、求解格距和模型时间。薄冰保留来源覆盖与起伏，厚冰接近求解冰面。
两种延拓以该响应比例连接，再按每个连通冰体校正最终体积。该比例是局部浅冰闭合，
高阶应力、短波模式间的相互作用与滑动采用相应动力学。推导见
[亚格子冰面响应](../../knowledge/geology/ice_sheets.md#18-亚格子冰面与固定气候响应)。

原生`chunks`保存相应冰面，独立冰厚保存于`surface/ice_chunks`，23 km文件保存格内均值。
画布根的`surface_ice_source.npz`保存200k种子，其参考地质高程与冻结大气保持原版本。
冰厚、基岩与冰面按各自来源解释，海陆变化和跨画布接缝在最终产品上核对。
共享球面种子提供全球冰量边界；当前细尺度响应按画布分别计算，重叠区的冰面仍可能不同。
跨所有权的覆冰接缝以同一地理点检查，后续共同域计算统一细尺度状态，水文采用对应版本的地表。

### 2.5.8 冰盖的海洋边界

海陆划分由与外海的连通性和静水接地共同决定，不按TD高程的正负号判断。
来源TD高程不高于0 m的像素为水域候选；位于23 km条件场海面格内的候选像素作为外海种子，
`canvas_marine.connect_sea`在存储分块上做四连通的外存连通性判定，与种子连通的像素是海洋。
四连通保证水不会穿过对角相接的陆地角点。不连通外海的海面以下像素是内陆低地，
在种子阶段与细尺度阶段都按陆地处理：冰下属于接地冰床，冰外保持来源高程。
物理依据与公式见[冰盖的海洋边界](../../knowledge/geology/ice_sheets.md#19-冰盖的海洋边界连通外海与静水接地)。

`water_width_px`以覆盖像素的最大内切圆直径测量海洋水域的局地宽度，上限取5750 m求解格距。
宽度达到求解格距的海洋水域是已解析的开阔海面，更窄的是未解析水道。
承载冰的面积由陆地与冰体内部的未解析水道组成，按第2.5.7节的部分格参加细尺度浅冰流动。
距开阔海面不足一个求解格距的水道属于已解析海岸，保持开阔水面，峡湾口与海湾因此留在海岸上；
更深入冰体的水道与陆地一起构成格内的基岩高程分布，参与共享冰面的求解。
原生延拓时，陆地像素沿用第2.5.7节的闭合；水道像素没有来源薄冰分布，
`channel_fill_fraction`以水道宽度为半波长，从求解格冰厚和共享冰面下的亏缺量给出填充比例。
填入的冰按`grounded_ice`检查接地，冰厚不足水深约1.12倍的部分作为入海输出记账，
连通冰体的体积核对计入这一输出。未覆冰的海洋像素保持来源高程。

各画布的连通性与水道宽度在生产批次中按画布逐块保存，供种子与细尺度阶段共同读取。
产品清单分别记录覆冰的内陆低地、无冰的内陆低地、接地水道与漂浮输出的像素数。
冰架、接地线迁移和前缘应力不在这一闭合内，漂浮冰按入海输出处理。

### 2.6 生成、续算与校验

TD 在一张画布上是无缝的：上游的 InfiniteDiffusion 把画布当作只由种子和坐标索引的数组，按需计算互相重叠的去噪窗口，
所以逐块取出的分块之间没有接缝，生成顺序与进程划分也不影响结果；原理与实测见
[terrain_diffusion.md](../../knowledge/cartography/terrain_diffusion.md) 的「大画布上的无缝分块生成」。

`export canvas generate` 为每张 GPU 启动一个 `td_canvas_worker.py` 进程，用 TD 虚拟环境的解释器运行，
工作目录是 TD 克隆；这个进程不导入本库。worker k 取分块清单（行优先）的第 k 段连续切片，使相邻分块
共享缓存的隐变量（`worker_slice`）。每个分块先写临时文件再改名，然后把 sha256 加锁追加到
`chunks.sha256`；重启时文件存在且校验和匹配的分块直接跳过。`export canvas plan` 先在独立临时目录生成
所选画布的布局与输入，再检查已有分块的几何、条件场、生成参数、结构及 `coarse_source` 共享场描述。
输入生成或复用检查失败时，原布局、输入、高清块和校验清单保持原值。全部检查通过后，
`td_canvas_build.install_planned_inputs` 按文件替换输入，并保留已有分块与其他资产。
单个输入文件的符号链接由新文件替换，其原指向文件保持原值；输出目录内部的目录链接在安装前检查。
`--force` 允许改写会使旧分块失效的输入，后续生成前应移开旧 `chunks` 与 `chunks.sha256`。
安装中的磁盘错误可能留下已写入的部分文件，恢复时核对输入与元数据再续算。

生成参数记录在 `layout.json` 与每张 `canvas.json`：模型 `xandergos/terrain-diffusion-90m` 的快照号、
TD 代码提交号、种子 42、条件信噪比（0.2, 0.2, 1.0, 0.2, 1.0）、fp32、条件场 64 个粗格的边缘值延拓。
任何一项变化都会生成一张不同的世界。同一画布在不同进程上生成，只有约 0.3–3% 的像素因 GPU 浮点运算
顺序不同而相差 1 m，其余逐位一致；所以 `chunks.sha256` 只校验传输与存储是否完整，不能比较两台机器各自
的结果。

├── layout.json                       # 画布列表、编号、布局参数、生成参数、数据来源

### 2.8 总览图

`export canvas mosaic` 把一张画布的原始分块拼成一张图（`render_mosaic`），裁到实际生成的范围。画法、陆地颜色与
海洋颜色是三个独立的选项：

- `--style` 选画法，缺省 `relief`。`carto` 与 `export render` 的地形图相同，是只乘在陆地上的双尺度晕渲加饱和度提升；`relief`
  是印刷用的立体晕渲，把高程放大（缺省倍数为像素边长除以 90 m，让平均后的像素与原生像素明暗相当）后用四个方向
  的光照合成，海岸外加一圈柔和的阴影。
- `--palette` 选陆地颜色：`adaptive` 是 `export render` 的自适应地形色表（锚定在固定的 ±9000 m，`carto` 的缺省），
  其余取自 `map/hypsometric_palettes.json`：`pastel`（本项目的浅色分层，`relief` 的缺省）、`gmt-etopo1`、
  `gmt-globe`、`gmt-relief`（GMT 的原始色表）、`wikipedia`（维基百科地形图规范）与 `cross-blended`。每套色表
  记录来源与许可，断点是绝对高程，各大陆的图可以直接并排比较。
- `--intertidal` 选潮间带：高程落在给定区间（缺省 −2 到 +2 m）的像素画成潮间带色，取 IHO S-52 电子海图标准的
  潮间带色 `DEPIT`（日间表，RGB 131、178、149），沿用海图把干出滩单独着色的惯例；这只是成图分类，海陆判定仍以
  高于 0 m 为陆。`off` 关闭。
- `--sea` 选海洋：`carto`（自适应色表的水深蓝，缺省）、`palette`（色表自带的水深色）、
  `flat`（统一蓝色，便于单独查看海岸几何）或 `grey`（统一的灰色，
  清单外也填灰色）。

`cross-blended` 是 Patterson 与 Jenny（2011）的交叉混合分层设色：低地颜色随自然环境变化。逐像素的混合权重取自
画布的粗格气候通道（`cross_blend_weights`）：干旱指数（年降水除以 Hamon 潜在蒸散）从 0.65 降到 0.2 时过渡到
干旱色，年均温从 8 °C 升到 18 °C 时由湿冷色过渡到湿热色，最暖月低于 10 °C 或有冰处用极地色。这些界线取自
干湿分级与柯本 E 类的惯例，是渲染选择。

图按一行分块为一条带、带上下留出晕渲所需的重叠区，并行
着色后拼接，内存随单条带而非整张画布增长。结构晕渲的平滑尺度固定在约 34.5 km 的地面距离，所以大图的
局部与小总览读起来一致；细晕渲是输出像素尺度上的真实坡度。清单外的分块（邻居画布的地盘、远海）留成
纸色。输出 `.jpg`（每边不超过 65535 像素，JPEG 的格式上限）、`.png` 或分块压缩的 BigTIFF（`.tif`），
旁边附一份 `<图>.json` 记录画布、步长、像素尺寸与几何；默认路径在 `exports/mosaic/<画布根目录名>/`，不同配方的画布根目录各占一个子目录。

最终图像产品同时提供 `--step 2` 和 `--step 4` 两档图，实际格距为 179.6875 m 和 359.375 m。
每对图从同一批原生块取样，范围、配色和高程放大倍数保持一致。
批次清单记录画布元数据、原图哈希、尺寸及来源版本，预览与原图分别保存。

## 3. S2：外存水文

### 3.1 边界

画布内每个像素按归属分三类：本画布所有的像素参与计算；其他画布所有的像素，以及分块清单
之外或缺失的像素，一律按开放边界处理（水到达即离开本画布流域，不再抬升）。海岸线与流域
按归属规则完整落在单张画布内，世界岛的两处陆上分界是例外，由联合前沿处理。

### 3.2 填平

填平按 Barnes 2016 的三段式分块方案实现（`fill_canvas_tiled`）：

1. 每块独立跑带分水岭标签的 Priority-Flood，记录局部填平面、分水岭标签与溢出图；
2. 协调端合并标签、拼接溢出图，在分水岭溢出图上再跑一次 Priority-Flood；
3. 重新读取每块，把像元抬升到所属分水岭的全局水位。

填平不 breach。画布外存版本由 `run_canvas_fill` 驱动：阶段一逐块写 `fill/`、`labels/`、
`summary/`，阶段二只读摘要构建全局图，阶段三逐块写 `final/`；内存占用与分块大小同阶，
与画布总像素数无关。`canvas_hydrology.py` 另有一套全局前沿 Dijkstra 实现
（`flood_canvas`），作为正确性参照（oracle）：两者在合成 DEM 上逐位一致，包括带海与
多分块的情形。

### 3.3 ε 坡道

填平面上的平地没有确定流向，因此路由前对每个等高连通区做一次多源 Dijkstra
（`_grade_flats`）：种子是出口格与紧邻更低值的格，区内每步加 ε，得到朝出口单调下降的
坡道。这是 Priority-Flood + ε（Barnes、Lehman 与 Mulla 2014）的形态，与 oracle 在
ε = 1e-3 下逐位一致。坡道只用于计算流向，不写回填平面。

### 3.4 汇流

分块汇流按 Barnes 2017 的三段式方案实现（`accumulate_canvas_tiled`）：块内串行累积，
把跨块流量登记为转移事件，协调端按填平降序沿接收链求解事件图，最后把偏移量折回各块。
该实现只支持 D8 这类不分叉流向，与区域链语义一致。

当前 `run_canvas_rivers` 的河段提取仍会把整张画布的填平面装入内存后计算 D8 与累积
（`canvas_flow_fields`），因此适用于试点画布尺寸；把河段提取也接到分块波次上是后续工作。

### 3.5 湖

湖的检测以填平面与原始地形之差为判据：差值大于 5 m 的封闭盆地成为**湖种子**
（`lake_mask`），再按连通面积、MMU 与最小宽度三个门槛筛选。种子成立后，湖体扩展到与
种子连通、填深大于 0.5 m 的整个填平足迹（`lake_footprint`）：填平面就是水面，浅水
边缘属于湖体。只按深核绘制与断链会让河道沿深核边缘绕行，图上读作河流贴着湖边走。

湖的收支用洼地层级与 Fill–Spill–Merge 级联（`canvas_lakes.py`）：升序扫描与并查集建立
父子关系，叶是坑、父是溢出，容量为溢出高程乘格数减去地形和；来水先蓄满叶，再经鞍部
流入兄弟，双方都满则合并到母洼，余量继续上行，水位由
`Σ max(0, 水位 − 地形) × 面积 = 水量` 求解。该模块目前作为算法实现与测试基准，湖表
（`lakes.json`、`lakes.sparse`）尚未接入磁盘管线；S3 在稀疏湖文件缺失时从填平面推导
湖掩膜。

### 3.6 矢量河段与情相

河道提取复用区域链的 `river_segments`：D8 最陡下降、Chaikin 平滑、湖岸停步与溢出口
续走、短链保留。河段以画布 SW 原点 km 输出，与区域链 `refined-out` 的坐标约定一致。
常流与非常流按 12 个月的累积流量判定：任一月低于 1 L/s 的活动门槛即记为非常流，连续
同类格合成一个情相段。

河道起始门槛采用“物理起始流量不变”原则：区域链的基数是 3000 个 2048/550 km 包格，
细化时按像素数平方换算到 4096²（12000 格），对应约 2.1 m³/s 的平均流量起点。画布
90 m 像素的同一起点约 27000 格，因此 `--threshold-cells` 默认 27000；需要更密的小溪网
时下调。

### 3.7 最终产品目录约定

最终产品使用第 2.7 节的画布根目录。共享几何文件位于根目录，各画布的资产状态与水文产品位于其子目录。

## 4. S3：区域裁窗

裁窗把方位等距平面上的一个正方形窗口逐像素换算成经纬度，再换算到画布像素坐标：

1. 高程对画布分块做双线性采样，块只按窗口包围盒读取，内存随窗口而非画布增长；
2. 海掩膜由高程小于等于 0 判定，并写出按高程跨度归一的 `sea-depth.png`，供制图腿
   做海深分层；
3. 湖掩膜优先读 `hydro/lakes.sparse/`；缺失时从画布填平面与原始地形之差推导完整
   填平足迹，补内部量化空洞，再套用与河链相同的 MMU 与宽度门槛；
4. 河流矢量先由画布 SW 原点坐标减去画布半宽，换算到经纬度，再换算到窗口平面，写成
   窗口 SW 原点 km；同一批段栅格化成一像素宽的 `rivers.png`；
5. 气候通道从粗格采样到窗口：标量双线性，类别最近邻；图例从 `canvas.json` 继承；
6. 窗口 meta 记录包版本、投影、精确窗口边长与像素边长、高程范围（含画布全域锚定范围）、
   海平面、气候图例与来源画布。

输出目录是 `input/`（区域数据包通道与 meta）与 `refined-out/`（高程、水体掩膜、河段矢量
与 meta），与 `export region` 加 `export build` 的产物同构，所以 colorize、carto、relief、
biome、Blender 各腿无需改动。

**渲染侧的河湖衔接**：河链会刻意把最后一段画进湖内一格，作为河与湖的可见连接。渲染载入
时只删除两端都在水中的河段（`_river_lake_keep`），岸线穿越段保留；按岸边缓冲距离裁剪会
把这段桥接删掉，重新打开入湖断口。

## 5. 验证

- S1 的布局与输入：库实现与生成曙光试点画布的脚本输出逐位一致（布局、归属表、五个条件场与十一个气候
  通道）；单元测试覆盖布局配置、玩具网格上的输入、续算记账与总览图裁剪。
- S1 的生成：曙光试点画布 1036 块齐全、校验和匹配；分块接缝处相邻像素差与块内相同（比值 1.02）；
  已知地标探针的最佳偏移为 (0, 0)；跨进程重生成的分块只有 0.3–3% 的像素差 1 m，最大差 1 m（新命令的 worker 重算 8 块实测）。
- 填平与汇流的分块实现与全局前沿 oracle 在合成地形上逐位一致：单块、2×2、2×3、3×2，
  含海与地峡拼合；ε = 1e-3 下的坡道同样逐位一致。
- 洼地层级与 Fill–Spill–Merge 级联有解析水位、两级坑、独立/溢出/合并三态与溢流截平的
  单元测试。
- 真实地形验收：从 nacrea 的 TD 细化地形采样出 368 km 画布（90 m 像素），填平 154 秒、
  11290 个分水岭；阈值 27000 下 38199 条河段，河网呈树枝状汇入海岸，湖面与诊断图一致。
- 裁窗验收：合成画布裁出 550 km 窗口，核对中心高程、海占比、湖与河掩膜、矢量 SW 坐标、
  气候图例；真实画布裁 150 km 后直接出测绘风图，海深、湖岸与河湖衔接正常。
- 可复现：同一画布重跑输出逐字节相同；`.npy` 分块与工作区校验和保证断点续算。

## 6. 已知限制与后续

- 河段提取与湖表仍未接上分块波次：填平是外存的，河段提取当前按整张画布装内存；湖表
  （终局湖、干盐滩、萎缩湖与稀疏湖像素）尚待接入。
- 世界岛两处陆上分界的生产版联合前沿尚未接入磁盘管线；oracle 已有接缝配对实现并通过逐位测试。
- 递归分块并行与 numba 热路径是性能后续项；当前试点画布尺寸可用，全球最大画布的运行
  时间与峰值内存仍需实测。
- S4（重叠窗口一致性验收）未实现；S5 目前只有单张画布的总览图（2.8 节），跨画布拼合的大陆与全球
  概览尚未实现。
- 当前 nacrea 海峡与陆桥接受 TD 地形，不做生成后钉扎；开合大势与叙事口径见设计笔记 0016。
  自动门槛审核仍未产品化，新配方需要重新目视核对关键位置，不能把旧配方的审核结果视为永久通过。
