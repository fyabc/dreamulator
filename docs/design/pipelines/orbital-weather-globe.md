# 太空俯瞰星球链：L2 云纹理、L3 气旋与 L5 大气

> 本文描述已实现的「太空俯瞰旋转星球」媒体链：从引擎网格生成全球云不透明度贴图，
> 叠加参数化气旋，再用物理大气壳合成正交圆盘预览。气象图层 L1（GCM 每 6 小时
> 瞬时快照与气旋轨迹表）已交付：云量条件场、太阳方向、两层壳的平流风与气旋
> 轨迹与云顶分类都已按帧接入；夜面灯光待接，见第 2、6、8 节。
>
> 源码：`src/dreamulator/media/cloud_render.py`（L2 纹理与球面合成）、
> `weather_conditioning.py`（L1 逐帧条件场适配器）、
> `cyclone_render.py`（L3 模板）、`atmosphere_render.py`（L5 大气）、
> `cloud_config.py`（YAML 配置）。命令行入口是
> `src/dreamulator/cli_export.py` 的 `export globe` 子命令。

## 1. 数据流与命令

一条命令完成纹理、气旋与预览：

```bash
dreamulator export globe nacrea --branch gcm-t42-712 --grid 8192x4096 \
    --cyclones --atmosphere
# 或用气象图层包的一帧驱动条件场（云量、云层分层与太阳方向都来自模式天气）：
dreamulator export globe nacrea --branch gcm-t42-712 \
    --weather-pack exports/weather/nacrea-gcm-t42-712 --frame 400
```

数据流是单向的：

1. 从地图网格栅格化云量、海平面气压距平、风场与海陆掩膜；
2. 冻结 GCM 气候的世界直接使用模式的总云量 `cloud_total_frac`，并用低/中云与高云的
   比例在两层云壳之间分配不透明度；没有云量字段的引擎世界退回 `large_scale_cover`，
   用降水与 SLP 距平构造占位的大尺度云量场；
3. 带 `--weather-pack` 时，`media/weather_conditioning.py` 从图层包取一帧替换上述
   年均云量与分层比例，并把太阳方向设为包内该帧的日下点（见第 2 节）；
4. `cloud_texture_equirect` 在球面逐点采样 3D 噪声，生成等距圆柱云不透明度；
5. `warp_cyclone_texture` 与 `cyclone_alpha` 按轨迹表叠加气旋模板；
6. `render_globe_atmosphere` 把地表、云壳与大气壳合成为正交圆盘。

输出目录包含 `clouds.png`（合并 RGBA 直通 alpha）、`clouds_low.png`（低/中云+霾）、
`clouds_cirrus.png`（高壳卷云）、`cloud_cover.png`、`surface.png`、`cyclone_template.png`、
`cyclone_envelope.png`、`globe.png` 与 `meta.json`。
同一份输入与种子逐位可复现；`meta.json` 记录种子、机位、气旋数量与大气参数。

把整条链按数据流平实走一遍。输入有两份：一份是地图网格上的年均气候字段（高程、
海陆、降水、气压距平、地表风，以及总云量与低/中/高三层的比例），描述气候平均态；
另一份是气象图层包——GCM 每 6 小时一帧的瞬时场，覆盖一个模式年，含分层云量、三层
风场与逐帧日下点，描述天气本身。

带 `--weather-pack` 时，适配器（`media/weather_conditioning.py`，见第 2 节）先把选定的
一帧变成渲染条件。瞬时云量接近非 0 即 1，直接驱动纹理会得到椒盐噪声，因此先取以该帧
为中心的 3 帧平均（18 小时窗口），再做约 310 km 的高斯平滑；总云量作大尺度云量场，
低/中云与高云的比例决定两层云壳之间的不透明度分配，日下点给太阳方向，中层与高层风
给两层壳的平流速度。帧号可以取小数：两个整帧各自完整处理后线性混合，时间步长因此
能任意细于 6 小时。

静帧渲染分五步（细节见第 3–5 节）：地表底图从网格高程与群系栅格化；条件场按年均档
或逐帧档取一档（风的丝缕定向在静帧路径仍用年均场）；云纹理在球面三维坐标逐点采样
噪声合成——云量场经全局秩映射决定哪里有云、多厚，采样位置沿风向扭曲使云顺流弯曲，
卷云沿风向拉丝，信风/锋面/对流/层云/急流五类天气状态权重按格点调制纹理风格；
`--cyclones` 时叠加参数化气旋模板（带图层包时为真实移动温带轨迹加正典参数化
热带，见第 4 节）；最后由物理大气壳把地表、两层云壳与瑞利/米氏/臭氧散射
合成全圆盘图。

视频有两条线（见第 6、7 节）。刚性旋转利用「相机与恒星固定时，球对称大气的散射不随
自转变化」的几何事实：大气只算一次，每帧按经度偏移重采样纹理，云系随行星整体转动。
云流演化把两层云的不透明度当作被平流的场，每步沿风倒推来源点做半拉格朗日插值，
配合前后误差补偿与三次采样压低数值扩散；风源取图层包的逐帧风（低/中云壳随中层风、
卷云壳随高层风），在步长中点取插值值。平流只搬运现有纹理，不模拟凝结/蒸发，大尺度
云量场保持导出时那一帧，更长时段的演化需要接入云量再生（见第 8 节待办）。

## 2. L1 接口（图层包已交付；云量、太阳方向与平流风已接，轨迹待接）

L1 是 GCM 气象图层包（结构见 [gcm-weather-pack.md](gcm-weather-pack.md)：每 6 小时
一帧的 T42 瞬时场、ISCCP 分层云量、云顶高度、三层的云层风场、涡度、海冰、海表
温度，以及 TempestExtremes 式检测出的气旋轨迹表）。渲染链当前消费其中五块：

- **年均云量**（冻结 GCM 气候的网格字段）：总云量 `cloud_total_frac` 作大尺度云量场，
  低/中云与高云（ISCCP 680/440 hPa 分界）的比例在低云壳与卷云壳之间分配不透明度。
  三层云量是云所在高度的诊断口径，三者合起来不严格等于总云量，因此只用于分配，
  不用于总量。
- **逐帧云量**：`media/weather_conditioning.py` 的 `load_weather_frame` 把包里一帧
  （`--weather-pack` + `--frame`）变成条件场。瞬时云量接近非 0 即 1（第 400 帧有
  68% 格点落在 0.05 以下或 0.95 以上），先取以当前帧为中心的 3 帧等权平均（18 小时
  窗口；6 小时滞后相关 0.66、隔两帧 0.46，3 帧不会抹掉天气尺度而 5 帧开始明显平均
  掉），再做标准差 1 个 T42 格距（赤道约 310 km）的高斯平滑（经度环绕、纬度边缘
  延拓）——两步之后两端格点降到 16%，与原始场相关仍有 0.82。序列两端窗口收缩为
  2 帧。参数写入 `meta.json` 的 `weather_pack` 块。
- **两层分配（云顶分类）**：可见云顶高度（`cloud_top_height`，随机重叠加权的
  「太空看到的最高云」，NaN = 晴空）决定每个格子画进哪层壳——smoothstep 过渡带
  4.75–8.25 km（中点 6.5 km），带下全归低/中云壳、带上全归卷云壳。依据是全年
  诊断（2026-10-24）：云顶高度呈双峰（海洋层积云约 1 km、卷云砧约 10–12 km），
  过渡带正好落在谷值，且 6.5 km 中点两侧的全球卷云份额（0.52）与按三层云量比例
  分配的口径（0.548）一致，换证据源不改变总量。云顶场过与云量相同的时间平均与
  高斯平滑，但两步都是云频加权（晴空格不拖低邻居的云顶；深晴空区高度趋于 0、
  归低壳，那里本来无云可画）。份额经 `shell_weights_from_shares`（余纬加权、
  全球均值归一、截断 [0.25, 3]、近晴空淡出）变成两壳乘数。份额近双峰使截断
  下限吃掉欠壳侧、主壳侧不触上限，无权重均值乘数落在 1.17（f273 实测），两层
  纹理不透明度合计偏多约 5%——面积加权口径近守恒且方向无害，接受并在代码中
  注明。两层壳的几何高度保持 4 km 与 9 km：逐像素壳高要重构大气渲染的壳层求交
  与散射表，收益只有视差与阴影精度，v1 不做。
- **太阳方向**：带图层包且未显式指定 `--sun-lon/--sun-lat` 时，太阳取包内该帧的
  日下点（`subsolar_lat_deg/lon_deg`，经度换算到 −180…180 口径），视图中心经度也
  默认取日下点经度，让向阳面对着镜头；晨昏线因此与云场同一时刻。
- **逐帧风场**：同一适配器随帧读出 `u_mid/v_mid`（σ≈0.57，低/中云壳的平流风，兼作
  风暴中心引导气流）与 `u_high/v_high`（σ≈0.32，卷云壳的平流风），过与云量相同的
  3 帧平均 + 1 格距高斯平滑。小数帧把两个整帧的完整处理结果（含两层分配与日下点）
  线性混合，日下点经度沿短弧插值，因此步长可以任意细于 6 小时；L4 视频由此驱动
  （见第 6 节）。静帧纹理自身的丝缕定向仍用年均风，是 L2 的后续项。
- **气旋轨迹**：移动温带轨迹逐帧驱动 L3 模板（选择规则与热带参数化见第 4 节）；
  准静止低压默认不画，包内热带轨迹弃用。

引擎世界没有云量字段，仍用年降水与 SLP 距平构造占位云量场；年均路径的两层分配
也仍按三层云量份额（网格上没有云顶高度可用）。

气旋轨迹表的字段已经确定为 `Cyclone` 的构造参数：纬度、经度、类型、中心气压、
环境气压、最大风速半径、外围半径、移动矢量与形态种子。`cyclones.tracks` 非空时
直接使用显式轨迹，是显式配置的接入口。

## 3. L2 程序化云纹理

云不透明度在等距圆柱网格上生成，但所有噪声都在像素的球面三维坐标处采样，因此
反日界线无缝、极点没有收缩。形状层用长波 fBm 决定「哪里有云」，细节层用高频
fBm 侵蚀云缘；两套尺度按低频场交叉淡化，避免固定尺度带来的重复感。风场做域
扭曲（flow noise），卷云沿风向拉丝。不透明度的全局秩映射到截断指数分布，空间谱
按 −5/3 标定；统计依据见
[cloud_field_statistics.md](../../knowledge/climatology/cloud_field_statistics.md)。

统计定标不等于形态复现，这是 L2 当前的主形态学限制。功率谱与不透明度分布都已
对标观测，但小尺度组织仍是空间平稳、各向同性的 fBm 侵蚀——成品里小云呈准均匀
尺寸的「椒盐」碎点，各纬度带同质，与流场零相关。真实卫星全盘影像的第一眼真实
感恰恰来自高阶组织：风排线（5–30 km）、开/闭细胞状层积云（50–300 km）、信风
积云带、锋区弧状锐边、卷云风切丝缕。这些组织全部小于 T42 格距（约 310 km），
模式在源头就不提供「天气体制决定小云怎么排」的信息——这是数据分辨率边界而非
渲染缺陷；渲染侧能做的是用包内的体制诊断把组织形态造回来。候选方向按预期收益
排序：其一，侵蚀与形状噪声沿低层风向拉伸、风切变控制拉丝比（`u_mid/v_mid`
逐帧已在包内，与静帧丝缕改逐帧风定向是同一件事）；其二，体制依赖的侵蚀参数——
云顶低且云量中的层积云带给细胞状（Worley）组织，低层涡度高的锋区给弧状锐边，
云顶高的深对流区给砧状硬边（`cloud_top_height` 与低层涡度已在包内）；其三，
碎块聚集与尺寸重尾（把均匀阈值换成聚集性播种）；其四，多层云各自的组织参数。
前两条数据全在包内，不需要新的 GCM 字段。

## 4. L3 气旋模板

热带气旋按 Holland 1980 风廓线由中心气压与环境气压定强度，形态由眼、眼墙、主
次对数螺旋雨带与卷云层组成；主/次雨带用较窄的高斯和软阈值取边，相位叠加细噪声，
避免整圈均匀的白色晕。温带气旋用 Shapiro–Keyser 概念模型：`_comma_twist` 把局地
坐标按 `1.10·ln r` 做差分旋转，并在旋转角与采样点上叠加低频噪声，然后在扭转后的
坐标系里取一个填充云头与一条冷锋尾——云头因此沿低压卷成逗号，而不是一个椭圆盘；
干槽在未扭转的角坐标里切成锐利楔形，云街沿扭转后的锋面展开，边缘再做一次轻度
unsharp。云头的破洞不另造一套噪声：`cloud_erosion_field` 从 L2 低云场取局部高通，
作为形状/侵蚀分离（Frostbite 思路）中的侵蚀项，让 L3 继承周围云系的 detail/grain/
MCC/Worley 质感；温带气旋在包络内用 lerp 替换底云，而不是 screen 叠加，避免云头
被推到纯白，同时保留侵蚀孔洞。气旋不是外加的白盘：`warp_cyclone_texture` 先把
L2 纹理按风暴轴做螺旋扭曲，眼区主动清除底云。尺度由环境决定（作者裁决 2026-10-25：
风场数据优先于尺寸常数）：热带云盾取「风暴自身 Holland 风仍压过环境风跨盾差值」的
最大半径（`coherent_shield_km`，截断 250–1500 km）——内热带弱风区允许 1500 km 级
宽涡旋，副热带西风坡把云盾剪成 500–1000 km 紧凑核；温带逗号尺度沿用轨迹检出，
但 |lat| > 70° 或 rmax > 800 km 的检出是绕极涡/行星波槽而非风暴，闸门剔除
（实测 nacrea 包：−85° 检出 rmax ≈ 1700 km、反算 Vmax 200+ m/s）。

轨迹来源两档（`media/cyclone_tracks.py`，2026-10-24 接入）：带 `--weather-pack` 时
`--cyclones` 的集合来自包内真实轨迹——移动温带气旋按渲染帧在轨迹点间插值（位置、
中心/环境气压、rmax、外围半径与移动矢量，经度走短弧），准静止低压默认不画
（`--stationary-lows` 仅 QA 用），包内 32 条热带轨迹弃用（T42 下是季风低压，不是
分辨出的热带气旋）。热带气旋按正典参数化生成（作者裁决，设计笔记 0020）：每当地年
约 8 个，生成时刻与位置按 `tc_genesis_potential` 加权（剔除 |lat| < 8° 的格点，潜势
场自带的季节性由此进入抽样），峰值强度取 `tc_potential_intensity` 的一部分并封顶，
云盾在生成时对峰值强度与局地风廓线求解相干半径（见上），移动沿包内中层引导气流自
生成点积分——路径曲率随环境流自然出现，中心气压经 Holland (1980) 反解，行星自转
率取自包内恒星日（`Cyclone.omega_rad_s`，默认地球值）。风暴还携带环境推得的卷云
幡：高层外流顺环境风拉出丝缕状云带（`Cyclone.plume_km` = 局地高层风速 × 云砧寿命
36 h，封顶 4000 km，`plume_bearing_deg` 为其方位；高层风低于 3 m/s 时不画）。幡不随
图案自转、方向与长度都是环境的量，它在视觉上把风暴接进背景风场——被强风切变压小
的紧凑核拖着顺风长幡，正是「涡旋嵌在急流里」的形态；宽盾弱风的内热带则按季风
涡旋形态绘制（`_shape_of` 的 gyre 档：更浅的眼、更松的螺旋）。暖核涡旋在行星涡度
消失处无法维持：被引导流
推进 |lat| < 8° 的赤道死区后，寿命预算按涡度亏损（1 − sin|lat|/sin 8°）加速消耗，
风暴在死区内一两天内消亡，不会漂过赤道。同时在世的风暴数由数据自然给出：一个
模式年平均同时在世约 1–3 条温带气旋。潜势与强度场在不宜环境里有微小负值（实测
GPI 至 −0.002、PI 至 −1 m/s），按「无潜势」截断到零。生成只落在洋面：GPI 场本身
不知道地表类型（大陆内部照样出现高潜势），`export globe` 会把行星地图的陆海判定
重采样到包网格写成静帧目录的 `ocean_fraction.npy`（`pack_ocean_fraction`），
视频链把它乘进生成权重（`--storm-seed` 换的是「哪片海出风暴」，不改变物理）。
采样源取风场时小数帧在相邻两个 6 h 快照间线性插值，轨迹积分每条腿用腿中点的风、
返回的移动矢量取请求帧与终点位置处的风——引导流、幡长/方位与移动矢量都随时间
连续，否则每跨一个包帧阶跃一次，逐帧合成的视频里幡与包络轴（运动不对称相位、
包络椭圆朝向都跟着移动矢量）会跳变（用户 QA 2026-10-25）。
温带轨迹在生命期首尾 6 h 内对气压亏损做淡入淡出，逗号云随检出窗口生长与消散，
不整帧弹出；热带风暴在生成/消亡帧仍有下限振幅的整帧出现（样片窗口未触及，
登记为后续项）。不带包时仍是合成占位集
（`synthetic_cyclones`）。已知 v1 简化：热带风暴的路径只受引导流约束，无 beta 漂移
（慢自转下按 β 缩放后量级可忽略），也不因登陆衰减（登陆由静帧的陆上丢弃近似）；
温带逗号的卷入手性以移动矢量为基准恒逆时针，北半球正确，南半球应镜像为顺时针
而未做（主展示镜头在北半球，南半球逗号多在盘缘，影响小）。

## 5. L5 大气渲染

`atmosphere_render.py` 实现瑞利、米氏与臭氧大气。单次散射为基线，另加 Hillaire
多次散射近似。所有系数按世界自己的恒星光谱与行星物理定标：瑞利散射系数按波长的
−4 次幂变化，米氏气溶胶为灰体前向散射，
臭氧只吸收并取 25 km 帐篷剖面。标高由流体静力学平衡推出，光学厚度按柱质量缩放；
透射率用高度×太阳天顶角二维表预计算。视线在两个云壳高度分成三段：9 km 的卷云壳、
4 km 的低/中云壳与地表；半透明云能正确透出其后的大气，云影由低云壳沿太阳方向
与地表求交得到。卷云层按 9 km 处的太阳透射率单独照明，并向低云/地表投一层薄衰减
（见下）。`cloud_texture_equirect` 把低/中云、卷云与薄霾分开输出，另给一层更易读
的高壳卷云（`alpha_cirrus_high`）；它不进入已标定的合并 `alpha`，只作用于 9 km
壳。高壳卷云再按全局 p60–p98 拉伸、幂 1.4、增益 0.55 的对比曲线处理，保留亮丝缕、
去掉均匀薄纱（2026-10-22 作者选定的 A/B）。高壳卷云还向低云与地表投影：从低壳/
地表沿太阳方向与 9 km 壳求交，按交点处的卷云不透明度乘 `1 − strength·α`（默认
0.6）；这是直接日光的衰减，卷云自身不做自阴影。全圆盘下 5 km 的高度差只有约
1 px 视差，双层的主要收益是卷云与低云各自的照明/遮挡，而不是明显的立体错位。
全圆盘地表底图另用一套更深的海洋色（`SURFACE_SEA_*`，仅限 L2/L5 预览）；区域
制图/carto 链沿用原来的海色，不受影响。

卫星食使用 `EclipseShadow` 接口：中心经纬度、本影/半影角半径与最大暗化深度
（圆形近似）。角半径以度计；影半径大于行星半径且居中时取 90° 饱和。渲染器在表面与云壳的直接日光上乘一个平滑的圆形剖面；
大气入射散射按地表次点做同样的局部衰减。天文层负责从轨道数据算出这些量，
渲染器不依赖具体的食源。Aegis 掩食 Nacrea 的实算本影半径约 66,653 km（9.78
个行星半径）、半影 77,948 km（11.43 个行星半径）。本影半径大于行星半径，中心食
时食界在行星表面之外，整个可见半球都在本影内（接口取 90° 饱和），画面是全球
均匀变暗。偏食时阴影不是以次食点为中心的圆斑，而是沿掩食轴的带：设轴偏离行星
中心 $b$，表面上法线为 $\mathbf{n}$ 的点到轴的距离为
$\rho^2 = R_p^2 + b^2 - 2bR_p(\mathbf{n}\cdot\mathbf{u}) - R_p^2(\mathbf{n}\cdot\mathbf{s})^2$，
其中 $\mathbf{s}$ 是次食点方向、$\mathbf{u}$ 是轴的偏移方向；局部遮蔽率是恒星盘
（角半径 0.447°）与 Aegis 盘（5.66°）在角距 $\delta=\arctan(\rho/d)$ 下的重叠
面积。最靠近轴的点落在晨昏线上（与次食点相差 90°），所以影子从晨昏线一侧进入
昼半球。当前 `EclipseShadow` 的圆形剖面只是中心食与局部近似的接口；真实偏食的
带形遮蔽场需要按上式逐点计算。4°/6° 的小阴影只是通用接口演示；小卫星
（Cadence/Vigil）小于恒星角直径，用 `umbra_radius_deg = 0` 的环形/偏食剖面。

多次散射用 Hillaire (2020) 的局部查找表近似：每个格点对一组均匀方向积分单次
散射的角平均并乘以 1/(1−f_ms) 的几何级数，主光线步进在每个采样点叠加这一源项。
它把白天散射大气的亮度提高约一倍，但不能把日侧的光输运到深夜侧。

颜色按线性光计算：地表与云色先做 sRGB 解码，辐射传输在线性空间完成，最后编码
回 sRGB。默认的 `white_balance` 曝光按画面内直射日光逐通道平衡，保持地表调色板
的中性观感；`physical` 保留恒星白点，K 型星的暖色会进入整幅画面。海洋像元另有
GGX 微表面太阳高光（水菲涅耳、波面粗糙度可配），高光受云影与云层遮挡。恒星温度、
气压与组成在运行时从 `stellar.yaml` 和 `planets.yaml` 读取，缺失时回退地球值。
物理模型、系数来源与已知限制见
[atmospheric_scattering.md](../../knowledge/climatology/atmospheric_scattering.md)。

## 6. L4 云系平流原型

`media/cloud_advection.py` 实现等距圆柱网格上的半拉格朗日平流：风场（东向/北向，
m/s）先换成角位移，经度项除以 `cos(latitude)`，经度周期采样、纬度在极点夹取；
每步之后用前后误差补偿（BFECC）扣掉一半往返误差，压低半拉格朗日插值的数值扩散。
采样默认是双线性；`interp="cubic"` 改用 Catmull–Rom 四点插值，进一步保边，代价约
为双线性的 3 倍。`cloud_flow_video.py` 默认使用三次插值，可用 `--interp linear`
换回快速版。`advection_substeps` 按每步位移不超过约 8 个格子给出子步数上限。

`scripts/media/cloud_flow_video.py` 从 `export globe` 输出目录读取云纹理与网格，
把云不透明度重采样到平流网格后逐帧推进，再用 `SpinRenderer.set_cloud` 更新云场、
渲染固定机位的全圆盘；相机与恒星不动，晨昏线固定。风源两档：`--weather-pack`
给定时代用图层包的逐帧风——低/中云壳随 `u_mid/v_mid`（σ≈0.57，兼作风暴中心的
引导气流）、卷云壳随 `u_high/v_high`（σ≈0.32），每个输出帧在步长中点取插值风
（小数帧 = 两个整帧完整处理结果的线性混合，见第 2 节），起始帧默认取静帧自己的
`weather_pack.frame`，模拟时长越出包范围时报错退出；不给包时回退年均风占位。

风暴处理三档（`--storm-mode`，默认 `rigid`）。`rigid`：环境云只用环境风平流，
风暴模板每帧从原始模板重新合成——位置取该帧时刻的真实轨迹（含正典热带，强度
随生命史由 `TropicalCycloneSource` 给出，云盾与卷云幡按该帧局地风场求解，
见第 4 节），热带旋臂按图案自转角速度
（`pattern_spin_rate_rad_s`：Holland 切向风的角速度以模板自身径向云量廓线加权，
正典风暴约 0.3–1 圈/天，落在观测的成熟台风云系转速带内）绕中心刚性旋转
（`Cyclone.spin_deg` 平移螺旋相位，不重采样）。这样处理的原因：螺旋雨带是对流
维持的风暴坐标系准定常特征，不是被动示踪物——把印好的模板放进「环境风 +
Holland 涡旋」里平流，眼壁风每 ~5 圈/天的差速旋转会在一天内把旋臂差速卷绕上千
度并叠加累积插值扩散，24 h 首末帧形变过大（用户 QA 2026-10-25）。温带逗号在
此档不旋转（锋面驱动，v1 简化），位置与强度逐帧更新。输入用无风暴静帧
（`export globe` 不带 `--cyclones`）。`vortex` 为旧路径：`cyclone_wind_field`
的切向涡旋风（热带全额、温带压零，0.9–1.25 倍外围半径间平滑收敛）叠加进平流
风，输入为已印风暴的静帧，模板随差速切变被动变形。`none` 不画风暴
（`--no-vortex` 是其废弃别名）。模板噪声场只依赖网格与种子
（`template_fbm_stack`），逐帧合成时计算一次复用。模拟时长与
片长解耦（例如 12 小时演化压进 8 秒），便于先看运动方向与纹理稳定性：

```bash
uv run --with imageio-ffmpeg python scripts/media/cloud_flow_video.py \
    <clouds_dir> -o exports/video/cloudflow/nacrea_cloudflow_720p.mp4 \
    --res 720 --seconds 8 --sim-hours 24 --texture-width 2048 \
    --weather-pack exports/weather/nacrea-gcm-t42-712
```

这是原型：只输运现有纹理，不做凝结/蒸发与云量再生，大尺度云量场也保持静帧导出
时的那一帧——长时段演化需要按包内逐帧云量更新或接入再生。热带气旋按图案自转
刚体合成；温带逗号随轨迹平移。极区经度位移被 `cos(latitude)`
下限保护。12 小时版本保留了热带风暴眼，24 小时版本运动更明显但累积插值的扩散
也更明显；BFECC + Catmull–Rom 三次采样明显减缓但未完全消除长时间积分后的细节
损失，更长时段仍需要更强的保守/低扩散格式。数值边界（24 h 实测）：低/中云壳面积
加权均值守恒，纬向位移与各带平均风的预测吻合（南中纬 +31.6°/预期 +35.2°、北中纬
+19.2°/+21.5°、热带 −1.6°/−2.1°，探针 `scripts/media/flow_drift_probe.py`）；卷云这类
近零薄壳有约 +0.02 的均值正漂（三次插值过冲在 0 裁剪处不对称的单向偏置），量级不
影响观感。凝结/蒸发与云量再生尚未接入。

## 7. 旋转视频

`media/globe_spin.py` 的 `SpinRenderer` 利用一个几何事实：相机与恒星固定时，球对称
大气的视线散射、透射率和云壳光照都不随行星自转变化，只有地表与云纹理在转。因此
大气只算一次，每一帧只按经度偏移重采样纹理并重新合成；`frame(0)` 与静态
`render_globe_atmosphere` 逐位一致。

`scripts/media/spin_video.py` 读取一次 `export globe` 的输出目录（`surface.png`、
`clouds_low.png`、`clouds_cirrus.png`、`meta.json`），从 `meta.json` 还原大气模型与海洋掩膜，渲染一整圈旋转
加一段定格，按 16:9 画布居中并编码 H.264：

```bash
uv run --with imageio-ffmpeg python scripts/media/spin_video.py \
    <clouds_dir> -o exports/video/spin/nacrea_spin_720p.mp4 --res 720 --seconds 8
```

经度偏移从 0 递减到 −360°，行星按自转方向（向东）转动；相机与太阳不动，所以
晨昏线在画面中保持固定。云系随行星刚性旋转，不做时间演化（L4 才引入风场平流）。
720p、30 fps、8 秒（7 秒转一圈 + 1 秒定格）的样片准备约 12 秒、240 帧约 160 秒，
输出约 6 MB。

## 8. 状态与后续

已实现：L2 纹理、L3 气旋模板（真实轨迹 + 正典热带）、L4 云系平流、L5 单次与多次
散射大气、双层云壳与高壳卷云投影、海面太阳高光、卫星食通用接口与演示，以及
全圆盘旋转与云流视频。条件场、风场、云顶分类与轨迹两档都已接入：年均档用网格
字段的总云量、分层比例、地表风与合成占位轨迹；逐帧档用图层包的一帧（3 帧时间
平均 + 1 格距高斯平滑）驱动云量、云顶高度的两层分类、包内日下点、两层壳的平流风
（`u_mid/v_mid` 与 `u_high/v_high`，小数帧线性插值）与移动温带气旋轨迹（准静止
默认不画，热带按正典参数化）。待办按依赖顺序排列：

1. L5 夜面城市灯光（文明层）；卫星食的真实椭圆/移动几何由天文层逐帧提供；
2. 次网格云组织：丝缕与侵蚀随逐帧风和天气体制定向（诊断与候选方向见第 3 节
   形态学限制段，现在丝缕仍用年均风）；
3. 多层云与次网格云尺寸分布。

全圆盘 4K 的定版贴图是 16K×8K；这一分辨率的纹理合成内存开销较大，当前预览以
8K×4K 为主，需要 4K 全圆盘时再按镜头加细分辨率。L2 纹理与大气渲染都是确定性
计算，不受预览分辨率影响。
