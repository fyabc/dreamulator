# 程序化视频制作工具库（media-video-toolkit）

> **状态**：部分实现。立项日期：2026-11-17；2026-11-19 抽取 starfield 核心几何。
>
> 来源：2026-11-17 工具库设计讨论（星场/宇宙渲染模块与镜头语言分层）。

---

## 1. 概述

世界推演的视频化需要一条可复现的「数据 → 渲染 → 成片」产线。目前的视频
能力是逐镜头的一次性脚本：能用，但每个镜头各写各的，调优成果（星等可见度、
辉光层序、相机样条纪律）无法沉淀复用。本提案把它们组织成一个**分层的
程序化视频工具库**：每层是一个带稳定接口与调优旋钮的模块，上层镜头按
声明式规格组合各层，全链命令行复现、种子确定。

定位是 [blender-render-pipeline](blender-render-pipeline.md)（地形区域
渲染链）的上层编排：区域数据包、全球贴图、气象场等由既有链产出，本库
负责天体、星空、大气与相机叙事，并把多尺度素材编排成镜头。

## 2. 已定的设计选择

- **分层单库，不按题材拆库。** 跨尺度的连续相机是本库最有价值的产出，
  它必须能同时编排星场、行星体与地表各层——拆库会把这条能力切断。
- **星空三源**：真实星表（公共领域巡天目录，如 HYG 亮星星表）；世界
  正典天空（天文层的天空背景数据：亮星、深空天体、种子化暗星场）；
  预设亮星 + 种子随机背景（手工构图 + 随机垫底的混合源）。三源共用
  同一条「方向 + 星等 + 色指数 → 渲染」管线，只换数据入口。
- **声明式相机轨迹**：镜头以 waypoints（时刻、位置、瞄准）+ 缓动描述；
  插值一律用切线钳制的 Hermite——Catmull-Rom 在公里级与百万公里级
  混合的路径点上会产生巨量级越界鼓包（已证伪方向）。
- **三档渲染纪律**：关键帧先行 → 片段预览 → 完整预览，每档分辨率/
  采样/步长预设固定，长片先在预览档目检再进终渲。
- **确定性**：所有随机源走种子；同一输入与种子给出逐帧相同的结果，
  跨机器渲染可核对。
- **FUI 与渲染同源数据**：仪器层数字一律来自引擎导出（锁定框取
  targeting 投影坐标、停靠卡取星表），叠层页不手敲数值；浏览器捕获用
  虚拟时间逐帧推进，保证与 Blender 帧序列可对齐、可重生成。

## 3. 模块分层

| 层 | 职责 | 现有基础 |
|----|------|---------|
| core | 相机 rig（waypoints/瞄准弧/切线钳制）、档位预设、观感旋钮、编码 | 区域链 bpy 胶水经验 |
| starfield | 三源星空（见 §2），壳层无穷远语义、星等→角径/亮度标定、亮星十字芒，银河弥散带（星表计数→银道系平滑→赤道等距柱状纹理） | 核心几何已抽取：`scripts/media/starfield.py`（目录→方向/半径/强度/色板，含测试）；银河纹理与 Blender 壳层适配待抽 |
| bodies | 类地行星（贴图/凹凸/云壳/大气缘光）与巨行星（条带/环） | 全球贴图渲染链、行星构建脚本 |
| atmosphere | 云系流动、气旋生消、季节演变（消费气象场数据） | `scripts/media/` 云流脚本 |
| phenomena | 掩食、凌星、朔望等天象的几何驱动渲染 | 掩食动画脚本 |
| camera-continuity | 跨尺度无缝镜头（全盘 → 区域 → 地表）：贴图细节按相机高度接力 | 未实现；见 §6 路线 |
| fui | 仪器层叠加：声明卡、锁定框、勘测钢印、停靠卡、隧道字幕、参数数据框；数据驱动（目标坐标/星表数字不手敲）、确定性捕获（CDP 虚拟时间）与帧序列直出双路径；风格模板化（四角括号/闪入/如风消散/字体档位） | 现有 FUI 叠层页、捕获与直出脚本 |

## 4. 典型镜头型（驱动模块优先级，不预先抽象）

科学纪录片风格的世界视频会反复使用这些镜头型，每个模块优先服务它们：

| 镜头型 | 内容 |
|--------|------|
| 轨道见证 | 行星自转、云系运动、季节变化——世界「活着」的断言 |
| 天象事件 | 掩食、凌星、行星连珠——历法与叙事锚点 |
| 延时族 | 星轨、日弧、云延时、板块与河道演变的深时压缩 |
| 尺度穿越 | 恒星系 → 行星 → 卫星 → 地表的连续下降镜头 |
| 仪器层 | 参数卡、轨道图、时间戳等叙述性叠加（浏览器捕获产线） |
| 图表化镜头 | 轨道数据解构为对齐阵列等信息图一拍 |
| 地表见证 | 潮滩、高原、夜空下的地面真值镜头 |

## 5. 验收指标

- 每个模块一条命令出片（帧目录 + 编码），无手工步骤；
- 同输入同种子逐帧可复现，Windows 与 Linux 渲染结果可对照；
- 提供一个 smoke 规格：从世界数据到一个 10 秒短片（星空 + 行星 +
  相机移动）全链自动；
- 星空模块可从任一指定天球方向出图，正典天空与世界数据一致。

## 6. 路线（登记不排期）

1. starfield 抽取为首个模块：核心几何已完成（`scripts/media/starfield.py`），银河纹理与 Blender 适配待后续收编；
2. bodies / atmosphere 以「下一部片用到哪个就抽哪个」的节奏收编；
3. camera-continuity 分两阶段：v1 跨尺度匹配剪辑（同向运动衔接），
   v2 真连续（全球贴图 → 区域分块的细节接力）。

## 7. 已否证方向

- Catmull-Rom 样条用于混合尺度路径点（切线爆炸，见 §2）；
- 亮本体前方的辉光面片（不透明核心会整块替换被遮挡亮面，产生暗心
  伪影）——辉光层永远置于本体之后；
- 逐镜头独立星场——同场景多镜共用一个按方向取向的星场，否则剪辑处
  天空不连续；
- 低帧率采样预览判运动（快摇混叠成瞬移）——运动判定用全帧率稠密渲
  加相邻帧差。

## 8. 与相邻链路的关系

- 下游数据：[blender-render-pipeline](blender-render-pipeline.md) 的
  区域数据包与整球贴图；气象场与云流脚本（`scripts/media/`）；
- 前端录屏仅服务 UI 与仪器层镜头，不作天体素材源；
- 生成物一律进 `exports/`（已 gitignore），脚本与规格文件随版本管理。
