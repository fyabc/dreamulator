## 1 目标与边界

本轮同时降低气候阶段的计算成本，并检查温度、降水和气候分类的误差。
诊断与回归都需要重跑气候阶段，数值等价的提速能够增加归因实验的可行性；
物理改动则必须先通过守恒和自洽检查，再检查大尺度过程、区域误差与下游用途。

作者将首图速度作为改进方向，不设硬性的秒数门槛。并行、缓存和向量化要求存储输出逐位不变；
改变数值的方案按[气候验证指南第 8 节](../pipelines/climate-validation.md#8-引擎改动的验收标准)验收。
地球验证使用独立观测，柯本气候分类同时报告 Beck 2018 与 Beck 2023 两种参照。
Nacrea 使用 GCM（大气环流模型）分支作模型参照，并排除其已知不可信区域。

本文保留本轮的设计结论。已实现机制的接口和参数由[气候管线](../pipelines/climate-pipeline.md)维护，
性能测量由[性能剖析文档](../profiling.md)和 `CHANGELOG.md` 保留；
当前偏差清单见[气候层改进方案](climate-layer-improvement.md#0-定位与当前基线)。

## 3 诊断结论与后续方案

### 3.1 季节热容量

地球中纬陆地的季节振幅与相位能够同时匹配观测，不能据 Nacrea 的短年响应直接改写地球标定。
把整根大气柱的热容量并入地表季节热容量，会限制短年世界的响应；
调整陆面热容量的量级不足以解除这项结构约束。
GCM 的高纬读数还受平板海洋海冰处理影响，不能直接作为独立判决依据。

海冰热容量候选已否证，极地季节热量输送与低纬振幅偏强仍属已知限制。
现行闭合、证据边界和重新评估条件由[季节热容量闭合提案](seasonal-heat-capacity-closure.md)维护。

### 3.2 地面风与洋面水循环

地面风的经向幅度和经度结构是沿岸上升流、冷舌与热带洋面降水的共同前提。
规定观测风的干预能够改善洋面降水减蒸发的空间型态与雨带位置，说明修风应先于增加降水闭合。
这一干预只用于归因，不进入产品；风改善后，水汽停留时间与降雨率必须重新检验。

风场改动以热带洋面降水减蒸发的型相关、雨带位置和沿岸风为目标指标，
陆地柯本分类按容差把关，冬季降水结构也必须保住。
专项方案与干预证据见[由气压场推地面风](surface-wind-from-pressure.md)。
副热带高压的上游缺口及接受边界登记于[路线图技术债 51](../roadmap.md#七已知技术债务)，
柱长波与云顶结构的候选由[柱辐射场提案](column-radiation-field.md)维护。

洋面蒸发的块体公式已实现，当前仍使用现行蒸发方案。模型风尚不足以支持启用块体公式，
其物理依据与接口见[能量平衡第 8 节](../../knowledge/climatology/energy_balance.md#8-降水与水循环)
和[降水执行步骤](../pipelines/climate-pipeline.md#7-降水)；启用前先检验风场、海气温差与输入高度口径。

### 3.3 湿槽迭代

湿槽回路的增益大于一，限幅能够压住气压增量，却不能使降水迭代获得定点。
产品的三轮迭代是按地球观测拟合的停止点，不能称为收敛，也不能通过减少轮数完成数值等价提速。
增加轮数会改变降水与分类结果，这项限制仍然存在。

现行回路与停止点的技术定义见[湿槽回路](../pipelines/climate-pipeline.md#57-gw6-湿槽回路w-供给路线默认开)。
局地湿静力能闭合作为替换方案已经否证；海温梯度驱动的 Lindzen–Nigam 边界层模型
仅适合作补充，方案去留由[湿静力能辐合闭合提案](moist-static-energy-convergence.md)维护。

### 3.4 洋流结构

洋流的米制算子与预条件保持自洽；亚格子急流增速会破坏流函数速度场的无辐散性质，因此未采用。
西边界急流未解析、连通大洋的洋盆划分、拉普拉斯权重、绕极通道与赤道流系仍有结构限制。
改进洋流速度与改进沿岸上升流需要分别归因和验收，不能以同一个增速系数处理。

当前实现见[气候管线的洋流部分](../pipelines/climate-pipeline.md#6-洋流)，
后续候选和限制由[气候层改进方案第 4 节](climate-layer-improvement.md#4-洋流)维护。

### 3.5 两套网格与季节谐波

大尺度水汽输送的长度尺度大于地形网格的格距，因此在粗网格上求解大尺度收支、
在细网格上处理地形订正，具有物理上的尺度分工依据。
World Orogen 提供了同类模型的方法参照，季节谐波也可能减少求解次数；
这些方案尚未在本轮完成结构对照，不能登记为已实现或已否证。

后续是否采用由准确度与运行成本共同决定，分辨率稳定性的验收口径见
[气候验证指南](../pipelines/climate-validation.md#8-引擎改动的验收标准)。
竞品参照只采用公开方法与测量，不引入其代码，定位见[竞品分析](../competitor-analysis.md#43-气候层)。

## 4 未采用的方向

稀疏 LU 是将线性方程的矩阵分解为上下三角因子的直接解法，下表保留本轮和同类模型的路线判决。

| 方向 | 本轮判决 |
|---|---|
| 简单预条件的 Krylov 迭代替换稀疏 LU | 在本轮平流占优的预算矩阵上，迭代成本与收敛表现不如直接分解。 |
| 跨月复用 LU 因子作预条件 | 各月矩阵差异使该预条件失效。 |
| 同时缓存十二个月的分解因子 | 内存成本超出浏览器目标可接受的范围。 |
| 以减少湿槽轮数获得数值等价提速 | 湿槽没有定点，轮数变化会显著改变降水和分类。 |
| 多线程替代月度进程并行 | 稀疏分解未充分释放 Python 全局锁，线程未达到进程路径的收益。 |
| 直接细化气候网格以补大尺度偏差 | 细化地形格距不能补足地面风和大尺度输送结构。 |
| 仅用两个季节计算气候分类 | 同类模型的测量表明这种简化会破坏柯本季节判据。 |
| 按水汽最多的位置放置热带雨带 | 同类模型的测量未支持这条规则，不能作为本库的物理闭合。 |
| 调低陆面热容量以解释全部短年振幅差距 | 大气柱热容量的结构约束仍然存在，专项判决见季节热容量提案。 |
| 给西边界流增加亚格子速度倍数 | 该操作破坏无辐散性质，专项限制见洋流技术参考。 |
| 在当前模型风下启用块体蒸发 | 风速与空间结构的误差会叠加到蒸发，启用条件尚未满足。 |

## 5 验收与维护边界

验收标准由[气候验证指南第 8 节](../pipelines/climate-validation.md#8-引擎改动的验收标准)统一维护。
守恒和自洽检查先于目标指标，规定观测输入仅用于诊断；
存在湿槽迭代限制时必须明确记录，不能以局部账本闭合宣称整个气候回路已收敛。

Nacrea 的公开气候采用 GCM 分支，来源与不确定度见
[气候正典笔记 0013](../../../data/worlds/nacrea/design-notes/0013-climate-canon-source.md)。
根世界的参数化气候作为快速工具与回归对照，不作为该世界的独立真值。
后续工作在对应专项提案中定义，优先级由路线图维护；本轮不再保留逐日实施清单。
