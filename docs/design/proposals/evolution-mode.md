# 演化模式：从规划的历史正向生成现状地形

> **定位**：新建世界的地质生成方案。`geography.yaml` 从「现状的偏置场」改为「演化的目标」：
> 先规划一段与目标相容的板块历史，再用板块运动学正向模拟到现在，现状地形是模拟的终态，地质
> 时间轴是模拟的副产品。本文件是设计提案，只写物理依据、当前方案与已否证方向；优先级在
> [roadmap.md](../roadmap.md)（§六 P2「基于地质时间的板块运动演化」），实验记录进 git 与 CHANGELOG。
>
> **状态**：提案，未实现（2026-10-16 立项）。排在 [geological-timeline.md](geological-timeline.md)
> 的 M2 之后，复用其地壳质点运动学。
>
> **适用范围**：新建世界，或作者同意整体重建现状地形的世界。已有现状正典的世界（nacrea）继续
> 使用现行管线加事后倒推（geological-timeline），本模式不改变它们。

---

## 0 问题

现行地质管线把海陆格局交给 `geography.yaml` 的偏置场，再叠加一段随机板块演化，最后按最终的
板块边界放置造山带、裂谷与洋底深度（geological-timeline §1.1）。这样做能精确实现作者要的海陆
格局，但有四个缺陷：

1. **地形缺少因果来源**：造山带、裂谷、被动陆缘与洋底年龄都不来自一段历史，演化只留下累计汇聚量
   与累计张裂量两个字段。
2. **板块与地壳彼此独立**：板块边界可以穿过大陆（nacrea 为边界总长的 62%），事后倒推必须另建
   重建用板块模型（geological-timeline §4.0）。
3. **没有共轭边缘**：海岸线由作者绘制，不是裂解的产物，倒推时两岸只能近似拼合。
4. **构造模拟器本身的限制**：不搬运地壳、实际位移约为名义时长的十分之一（roadmap 技术债 33、34）。

对新建世界，现状并不需要逐格固定，只需要实现作者的意图。本模式用这一自由度换取一段自洽的历史。

## 1 方案总览

```
geography.yaml（目标）
  └─ 1. 读出意图：目标大陆块 + 地物约束
       └─ 2. 逆向规划：把大陆块拼成超大陆，求每块到目标位置的有限旋转
            └─ 3. 定裂谷：块间接缝即裂谷，缝隙补成被拉伸的陆壳
                 └─ 4. 正向运动学模拟：洋壳生成与消亡、碰撞造山、裂谷演化，逐步存快照
                      └─ 5. 收尾：偏置场做细节修正，得到现状地形
```

第 2 步是一个只有几十个参数的小反问题，第 4 步是确定性的正向计算。整段历史由规划结果、种子与
物理参数决定，可复现。

## 2 读出意图

- **目标大陆块**：`geography.yaml` 偏置场为正的连通区域，按面积阈值合并碎小岛屿。每块记录目标
  轮廓与目标位置。
- **地物约束**：
  - 山脉类地物：要求其两侧的大陆块在该处相撞，或该处是活动大陆边缘；
  - 裂谷海、陆间海类地物：要求该处正在张开或刚张开；
  - 地峡、海峡类地物：要求两块在该处相接或刚分开；
  - 没有约束的海岸：允许成为被动陆缘或活动陆缘。
- **物理参数**：板块速度上限由潮汐加热或内热推出（`docs/knowledge/geology/tidal_plate_speed.md`），
  超大陆时刻取超大陆旋回先验（地球约 3–7 亿年，Nance 等 2014）或由作者给出。

## 3 逆向规划超大陆

把目标大陆块当作拼图块，求每块从超大陆位置到目标位置的有限旋转，等价于求每块在超大陆中的
位置与朝向。每块 3 个自由度，十块左右的世界共约 30 个参数。目标函数由以下几项组成：

- **拼合**：相邻块边缘的 Bullard 式最小二乘失配（Bullard 等 1965），以陆壳边界而不是海岸线计；
- **紧凑**：超大陆的周长与面积之比，以及块间空隙的面积；
- **运动合理**：每块从超大陆到目标的平均速度不超过速度上限，转动量合理；
- **地物约束**：§2 的约束作为惩罚项，例如要求相撞的两块在运动中确实相向而行，并在目标山脉处
  接触；
- **构造规则**：岩石圈净旋转小、板块大小保持双峰分布（Müller 等 2022；Morra 等 2013）。

用多个种子做全局搜索，保留若干个得分最高的方案供作者选择。拼不出合理超大陆时（例如目标大陆
形状彼此完全不互补），报告失配最大的接缝，并给出允许形状小幅变形后的最接近方案。

两次关键帧之间的运动用阶段欧拉极插值。一条直接从超大陆到现在的旋转路径太简单，规划器可以插入
中间关键帧（板块重组），让大陆走出曲折的路径，并在中途产生碰撞与再裂解。插入多少次重组由
种子与旋回先验决定。

## 4 定裂谷

超大陆中相邻块之间的接缝就是最初的裂谷线。拼合不可能严丝合缝，接缝处的空隙按拉伸因子（约
1.5–3）补成被拉伸的陆壳，重叠处按同样比例缩回。这样每条裂谷两岸的陆缘天然共轭，倒推回去时
可以精确合拢。

## 5 正向运动学模拟

从超大陆时刻开始按阶段欧拉极推进，每步约 1 Myr，复用 geological-timeline 的地壳质点机制
（`map/paleo_kinematics.py` 的旋转与重采样，以及 M2 的示踪点洋壳与碰撞处理）：

- **洋中脊**：裂谷张开后在两块之间生成洋壳，记录生成时间，得到真实的海底年龄与等时线；洋深由
  年龄-深度关系给出。
- **俯冲**：板块相向运动时，较老、较密的洋壳在海沟处消亡；海沟后方生成岛弧与陆缘弧。
- **碰撞**：两块陆壳相遇时累积缩短，按累计缩短量与时间生成造山带，并记录造山带年龄。停止汇聚
  的造山带随时间侵蚀变低，成为古老造山带。作者已确认叙事接受这类古老造山带（阿巴拉契亚式），
  不要求所有山脉都在活动。
- **裂解**：规划中的重组关键帧可以让一块大陆再次裂开，生成新的共轭陆缘与新大洋。
- **快照**：每个时间步存一份与现状同几何的字段，构成地质时间轴；典型时刻按 geological-timeline
  §8 的分支机制接入气候与生态。

板块剖分在每一步由运动学决定，不再使用加权 Voronoi 重剖分，所以不存在现行模拟器的位移偏小
问题，地壳也真正随板块移动。

## 6 收尾：现状地形

- **大格局**：旋转按「终点等于目标位置」构造，所以大陆块在 t = 0 必然落在 `geography.yaml`
  要求的位置，海陆大格局与目标一致。
- **细节**：海岸形状、内海、群岛等细节，与目标轮廓之间的差异用偏置场做一次小幅修正，做法与
  现行 overlays 后处理相同；修正量作为诊断量报告，过大时说明规划不足。
- **地形**：高山、裂谷、洋底深度、陆架与岛弧都来自历史，不再由 `_apply_interior_landforms`
  等步骤手工放置；高程合成沿用现行地形合成的边界效应公式，但输入换成历史中真实累积的汇聚量、
  张裂量与年龄。
- **未来**：从现状沿当前阶段欧拉极继续推进，即得到未来时刻。

## 7 与现行管线的关系

| 方面 | 现行管线（指定模式） | 演化模式 |
|---|---|---|
| `geography.yaml` 的语义 | 现状偏置场 | 演化目标与地物约束 |
| 海陆格局 | 逐格精确 | 大格局精确，细节经小幅修正 |
| 造山带与裂谷 | 按最终边界放置 | 由碰撞与裂解产生 |
| 洋底 | 由距离比估年龄 | 真实生成年龄 |
| 共轭边缘 | 没有 | 自带 |
| 地质时间轴 | 事后倒推（geological-timeline） | 生成过程的副产品 |
| 适用世界 | 已有现状正典的世界 | 新建世界 |

两种模式并存，由世界的地质层输入选择；同一套物理引擎，只差输入，符合「同物理」原则。演化模式
复用的模块：`paleo_kinematics.py`（旋转、重采样、海底年龄、空缺与重叠）、geological-timeline M2
的示踪点洋壳与 Bullard 拟合、`geography.py` 的地物解析、地形合成的边界效应公式。

## 8 验证

- **科学验收**：用地球做闭环检验。以真实重建（如 Müller 等 2019）给出的 2 亿年前大陆块与旋转
  作为输入，正向模拟到现在，比较海底年龄（Seton 等 2020 年龄网格）、造山带位置与年龄、被动
  陆缘分布；再以现今地球大陆作为目标，检验规划器能否找回一个与盘古大陆相近的超大陆。
- **自洽验收**：面积守恒残差；构造规则得分；海底面积随年龄的分布接近三角形（Coltice 等 2012）。
- **创作验收**：现状是否实现了作者在 `geography.yaml` 中的意图；细节修正量是否足够小。

## 9 闭合的认识论分类

| 闭合 | 类别 | 标定域与不确定度 |
|---|---|---|
| 有限旋转、质点运动学、面积守恒 | 守恒定律与运动学 | 精确 |
| 年龄-深度关系、造山带侵蚀衰减 | 观测拟合 | 地球 |
| 速度上限 | 近似推导 | 由热流标度律推出，经验律约 ±50% |
| 拼合、紧凑与构造规则打分 | 观测拟合 | 地球重建经验 |
| 超大陆格局、重组时刻、消失大洋 | 创作设定 | 规划器在约束内的一个解，非唯一 |

## 10 分期

| 期 | 内容 |
|---|---|
| E1 | 意图解析与超大陆规划器（拼合、紧凑、速度与地物约束），输出候选方案与诊断图 |
| E2 | 正向运动学模拟：洋壳生成与消亡、碰撞缩短、造山带年龄与侵蚀，逐步快照 |
| E3 | 收尾与地形合成接入（边界效应改用历史量）、偏置场细节修正；地球闭环检验 |
| E4 | 作为世界的地质层输入选项上线，模板世界示例，前端时间轴复用 geological-timeline M4 |

## 11 不采用的方向

- **随机初态自由正演**（Cortial 2019、Tectonics.js 的做法）：历史自洽，但终态不受作者控制，
  无法实现 `geography.yaml` 的意图。
- **随机初态正演再用松弛项拉向目标**：松弛项强到能命中目标时，演化只剩装饰，且终点仍需硬性
  替换（geological-timeline §12）。
- **地幔对流驱动的板块演化**：能自组织出板块与超大陆旋回（Coltice 等 2019），但代价与交互性
  约束不符，且同样无法锚定目标；可作为远期的速度场来源。
- **对已有正典世界整体改用本模式**：会改变现状地形与已写好的叙事，违反这些世界的硬要求。
