# 湿静力能辐合闭合：替换湿槽迭代

> 立项 2026-11-02，由[气候引擎本轮迭代 5.7](climate-engine-round.md#57-降水预算的分解成本与湿槽迭代2026-11-02)
> 的实测分出。核心主张：热带的降水辐合不该由一个增益大于 1、靠截断停止的 Picard 环产生，而应由
> 柱积分湿静力能收支直接给出。这条闭合的增益由大气层结决定、严格小于 1，所以定点按构造存在；
> 它还能把每次构建的降水求解从四轮减到一轮。本文记录物理依据、可行性判据、分阶段方案与验收，
> 不记录每日进度。

## 1 要解决的问题

现行的湿槽回路（`wet_trough_enabled`，技术参考见
[气候层管线 §5.7](../pipelines/climate-pipeline.md#57-gw6-湿槽回路w-供给路线默认开)）把
「降水 → 柱潜热 → 两层定常波 → 湿槽气压距平 → 边界层辐合 → 重解水汽收支」做三轮 Picard 迭代，
欠松弛 0.5，气压增量限幅 ±8 hPa。实测（2026-11-02）表明它没有定点：

- 推到十轮，逐格月降水的平均改变量停在约 7.5 毫米（nacrea）或在第三轮后回升（地球），
  触顶格月比例单调增长，地球从第三轮的 0.39% 涨到第十轮的 4.18%。
- 地球评分卡随轮数全线变差：各大洲等权的柯本分类吻合从 26.0% 降到 18.3%，雨季相位吻合从
  48.7% 降到 37.6%。两轮同样更差（κ 低 4.3 个百分点）。三轮恰在附近最好，所以迭代次数是一个
  按地球观测拟合的停止点，不是收敛。
- 失控有两条通道：温带的气压增量有上限，热带波导内的求解器风没有上限，苏拉威西海岸一格的
  年降水从第三轮到第十轮涨了 340 倍。

按引擎纪律第 5 条，这是「状态不一致」——产品取决于迭代次数——应当先于任何新机制修。
按纪律第 7 条，修法是换掉这条闭合，而不是给它再加一道门。

## 2 物理依据

### 2.1 为什么现行回路的增益大于 1

现行回路把潜热直接换算成气压距平，再由气压距平经边界层平衡换算成辐合。这条链里没有能量约束：
上升运动在真实大气里要付出干静力能的代价，而回路不记这笔账。所以它的增益取决于阻尼时标、
限幅与欠松弛这些数值参数，而不取决于大气层结；实测在两个世界上都大于 1。

### 2.2 湿静力能收支给出的增益

湿静力能 h = c_p T + g z + L q 在绝热可逆过程中守恒，凝结只在 c_p T 与 L q 之间转换，所以它的
柱积分收支里没有潜热这一项（Neelin 与 Held 1987）：

    ∂⟨h⟩/∂t + ∇·⟨h v⟩ = F_net

其中 F_net 是柱的净能量收入：大气顶的净辐射收入减去进入地表（海洋或土壤）的净能量。按两层的
第一斜压模态近似，低层辐合 D 把边界层的湿静力能 h_b 带进柱内，高层以干静力能 s_u 输出（水汽已
在上升中凝结），于是平均辐散环流的输出为

    ∇·⟨h v⟩ ≈ M · D，   M = (Δp/g) · (s_u − h_b)

M 称为总湿稳定度（gross moist stability）。同一上升运动对干静力能与水汽的作用分别是
M_s = (Δp/g)(s_u − s_b) 与 M_q = (Δp/g) L q_b，并有 M = M_s − M_q。

由此得到闭合的两个关系。稳态下辐合由柱能量收入决定：

    D = F_net / M

降水超过蒸发的部分则是

    L (P − E) = M_q · D = (M_q / M) · F_net

**它为什么不会失控**：若只有潜热驱动，L P 由上升运动的干静力能输出平衡，L P ≈ M_s · D；
上升运动输入的水汽为 M_q · D。所以降水驱动辐合、辐合再供给降水这个环的增益是

    g = M_q / M_s = 1 − M / M_s

只要 M > 0，增益就严格小于 1，定点必然存在；放大倍数 M_s / M 大而有限。这正是季风辐合
「强而不失控」的物理来源，也正是现行回路缺的那一道闸。

### 2.3 适用范围

这条闭合依赖弱温度梯度近似：热带自由对流层的水平温度梯度很小，加热主要由垂直运动平衡
（Sobel 与 Bretherton 2000）。它在科里奥利参数小、罗斯贝变形半径大的热带成立，在温带不成立，
那里的加热由水平温度平流与瞬变涡旋平衡。所以闭合只在热带生效，按引擎已有的赤道波导权重
（`_w_eq`，由罗斯贝变形半径推出）与温带的气压通道衔接，不引入新的纬度参数。

### 2.4 沙漠的预期行为

撒哈拉一类的副热带沙漠年均是柱能量汇（F_net < 0），地表反照率高、长波冷却强（Charney 1975
的沙漠反馈）。闭合在这里给出辐散与下沉，降水被压低。现行湿槽在同一位置由模型自身过量的西非
降水自引用出一个伪湿槽（「西非雨带走廊族」，登记为单层框架局限，见
[气候层改进方案 §5](climate-layer-improvement.md)）。这一条只是预期，必须实测验证。

## 3 输入量从哪里来

### 3.1 柱净能量收入 F_net

逐格逐月由引擎已有的量组成，不引入新参数：

    F_net = (1 − α) · Q_sw − OLR(T) − C · ∂T/∂t

吸收短波由季节能量平衡模型的入射与反照率给出，OLR 用同一模型的线性化 A + B·T，地表储热用同一
模型的热容 C 与月温度的时间导数。年平均时储热项归零，F_net 等于该格大气与海洋共同承担的能量
输出。全球面积平均的 F_net 在稳态下为零，这是泊松问题可解的相容条件；残差按全球均值扣除并记录。

**能量自洽的一个附带收益**：季节能量平衡模型的稳态里，F_net 正好等于它自己的经向热输送散度。
所以闭合产生的辐散环流搬运的正是能量平衡模型认为需要搬运的那份能量，温度与环流两条链在能量
账本上第一次闭合（纪律第 6 条）。

### 3.2 总湿稳定度 M

这是本提案最难、风险最高的一步。M 是两个大数之差：在严格的对流准平衡下，自由对流层温度沿
边界层空气的湿绝热线走，s_u 趋近 h_b，两层近似给出的 M 趋于零。真实的正值来自边界层的欠饱和
与自由对流层的湿度廓线，观测估计离散度大，典型为正的零点几（以 M / M_s 计），部分体制下可以
为负（Raymond 等 2009）。

计算方式按 QTCM 的做法（Neelin 与 Zeng 2000）：温度取由地表温度出发的湿绝热参考廓线，湿度取
参考相对湿度廓线，M_s 与 M_q 都对第一斜压模态的垂直结构做加权积分，而不是只取两层端点。输入
是引擎已有的地表温度、递减率与柱水汽，所以 M 是近似推导量，认识论类别为「近似推导加观测约束」：
它不拿观测拟合，观测只用来检验它的符号与量级。

**M ≤ 0 的处理**：若某处算出 M ≤ 0，物理上意味着那里的辐合没有稳定的稳态。不允许为此加一个
裸下限；先在阶段 0 测出这类格子的面积与位置，再决定是推导上的缺陷还是真实的体制。

### 3.3 辐散风

由柱能量收支直接解出辐散环流的速度势 χ：

    ∇·(M ∇χ) = F_net

辐散风 v_div = ∇χ 按赤道波导权重加到边界层风上，然后**只解一次**水汽收支。系数矩阵只依赖网格
与 M，每月一次稀疏分解；它是对称正定的变系数拉普拉斯算子，比现在的水汽收支矩阵好解。水汽收支
仍是同一个守恒有限体积格式，辐散风只是又一项风，所以守恒账本不受影响。

## 4 竞品与参照

| 参照 | 做法 | 本提案用它做什么 |
|---|---|---|
| Neelin 与 Held（1987） | 柱积分湿静力能方程，辐合由 F_net / M 给出 | 理论根源，闭式、无迭代 |
| QTCM1（Neelin 与 Zeng 2000；UCLA，Fortran 2.3 版） | 对流准平衡加单一斜压模态的热带环流模式 | M_s、M_q 的推导方式与模式的验证基准 |
| `qtcm`（Lin 2009，Python 包装） | 用 Python 管理 QTCM1 的 Fortran 子程序 | 不直接使用，理由见下 |
| 弱温度梯度近似（Sobel 与 Bretherton 2000） | 热带加热由垂直运动平衡 | 适用范围的依据 |
| World Orogen | 没有对应机制，自记局限之一是「季风偏弱」 | 反证：没有这类闭合，季风会偏弱 |
| ExoPlaSim | 完整 GCM，Kuo 对流方案 | nacrea 的对照真值，不作后端 |

**`qtcm` 不能直接使用**（2026-11-02 核查）：它不在 PyPI，最后一版 0.1.2 发布于 2009 年，属于
Python 2 时代、以 f2py 包装 Fortran；作者网站说明这批例程自 2000 年代后未再维护，不建议原样
使用。核心 QTCM1 的 Fortran 代码下载需要注册，许可不明，不能随库分发，浏览器端也无法运行
Fortran。更根本的是架构不匹配：QTCM1 是需要时间积分与起转的原始方程模式，跑在 5.625°×3.75°
的经纬网格上并由给定海温驱动，而本引擎需要的是一条能嵌进 20 万格稳态诊断管线的闭合。所以借用
的是它的公式，不是它的代码。

## 5 分阶段方案

每阶段单独验收，前一阶段不达标不进入下一阶段。

| 阶段 | 内容 | 验收 |
|---|---|---|
| 0 | 离线诊断，不改产品：在地球上由引擎月场算出 F_net 与 M；用 GPCP 观测降水与模型蒸发反推「观测所需的 M」 | 去留判据见 5.1。⛔ 未通过（5.1.1）：引擎辐射给出的 F_net 在热带近乎均匀为正，不携带 P − E 的符号；下一步改用观测的柱能量收入重测 |
| 1 | 实现闭合：纯函数模块计算 F_net、M 与辐散风，以开关 `convergence_closure` 在湿槽与新闭合之间切换，新闭合只解一轮 | 守恒账本残差为零；单元测试覆盖相容条件、对称正定与 M 的单调性 |
| 2 | 两个世界的验收 | 按 5.2 |
| 3 | 退役湿槽：通过后删除湿槽回路与其开关，更新管线文档 | 删除后两个世界的结果与阶段 2 逐位相同 |

### 5.1 阶段 0 的去留判据

阶段 0 回答一个问题：这条闭合在地球上能否产生观测到的热带降水型态。两项测量：

1. **M 的符号与平滑度**：由引擎月场推出的 M 在热带（30°S–30°N）应以正值为主、空间平滑。
   报出 M ≤ 0 的面积与位置。
2. **反推的 M**：由 L (P_obs − E) = (M_q / M) · F_net 反解 M，与第 1 项的推导值比较。

若推导值在热带大面积为负，或与反推值的型相关很低，说明推导上缺了关键项（最可能是自由对流层
湿度），先补推导，不进入阶段 1。若两者在符号与量级上一致，进入阶段 1。阶段 0 不加任何参数，
也不改产品。

### 5.1.1 阶段 0 的结果：不通过，原因在输入（2026-11-02）

在地球 climate-dev 分支上，用引擎自己的函数逐格逐月重建 F_net（与温度链同一本能量账），以 GPCP
观测降水与模型蒸发（陆地取土壤水桶的逐月蒸散，海洋取引擎的蒸发率）构成观测的 P − E。为避免
推导 M 时引入的假设掩盖结论，先加了一项不含任何参数的前置检验：若 γ = M/M_q 处处为正，F_net
与观测的 P − E 在热带应当同号且正相关。

| 热带（30°S–30°N） | 全部 | 陆地 | 海洋 |
|---|---:|---:|---:|
| F_net 为正的面积 | 99.96% | 99.8% | 100% |
| 观测 P − E 为正的面积 | 43.6% | 62.1% | 37.1% |
| 两者同号的面积 | 43.5% | 62.0% | 37.1% |
| 两者的型相关 | 0.32 | 0.18 | 0.29 |

引擎的 F_net 在热带几乎处处为正且几乎均匀（10 与 90 分位为 22 与 39 W/m²），同号面积恰好等于
P − E 为正的面积，说明它不携带符号信息。另两项：在辐合区反推的 γ 中位数为 0.475（10 与 90 分位
0.27 与 0.95），折算 M/M_s 约 0.32，量级合理，但它为正是由选择条件保证的；按弱温度梯度近似、
边界层相对湿度 0.8 推出的 γ 与反推值的型相关只有 0.03，中位数小四倍。

**原因在输入，不在闭合。** 引擎的辐射是全球常数的行星反照率（地球 0.306，结冰处换为冰反照率）
加线性化的 OLR（B = 2 W/m²/K，行星平均反馈）。真实 F_net 的空间结构主要来自这两者缺少的项：
沙漠的高反照率、深对流区高云对长波辐射的削减、层积云的反照。所以被否证的是「用引擎现有的辐射
驱动这条闭合」，闭合本身的物理没有被检验到。

**还暴露了一个形式问题。** 两层关系 D = F_net / M 只对平均辐散环流承担的能量输送成立。副热带
洋面 F_net 为正却在下沉，是因为那里的能量主要由涡旋向极输送；闭合需要的是 F_net 减去涡旋输送
散度，而季节能量平衡模型把全部经向输送写成一个扩散项。3.1 所说的「能量自洽附带收益」因此要
改写：闭合只能接管其中属于平均环流的那一份，这一份怎样从扩散项里分出来，是进入阶段 1 之前必须
回答的问题。

**下一个可测点**：用观测的柱能量收入（大气顶净辐射与地表能量通量的气候态）作为规定输入，只做
诊断、不进入产品，重做同样三项检验。它把「闭合物理错」与「引擎输入粗」分开：若观测 F_net 也
给不出观测降水的型态，这条闭合就不值得为它重建辐射；若给得出，前置工作是给引擎一套有空间结构
的柱辐射。脚本与结果在 `private/experiments/mse-stage0-20261102`。

### 5.2 阶段 2 的验收

按[气候验证 §8.2](../pipelines/climate-validation.md#82-物理或结构类改动) 的物理或结构类改动走：

- **对照基线**是湿槽三轮的现行产品，地球评分卡各大洲等权，任何大洲不得明显变差；
- **目标指标**是热带季风盒（恒河、华南、西非、澳北）的降水幅度与雨季相位、撒哈拉与阿拉伯的
  过湿偏差，以及雨季相位吻合率；
- **与迭代次数无关**：闭合只解一轮，按构造满足，作为回归测试固定下来；
- **守恒账本**残差为零，**nacrea** 只在 GCM 可信区比较，作为同物理回归而不是真值。

按纪律第 3 条，新闭合一开始很可能比三轮湿槽差，因为后者的停止点是在地球上挑出来的。指标变差时
先判断是物理错了还是标定没跟上：若 F_net 或 M 的推导有误，修推导；不退回湿槽。

## 6 预期与风险

**预期收益**：

- 定点按构造存在，增益由层结决定，产品不再取决于迭代次数；
- 降水求解从四轮减到一轮，每次构建的稀疏分解从 100 次降到约 25 次，降水阶段约减少四分之三；
- 温度链与环流链在能量账本上闭合；
- 撒哈拉一类能量汇的下沉可能改善西非走廊的过湿，需实测。

**风险**：

- **M 的推导**是最大的风险，见 3.2；阶段 0 专为它设置。
- **温带季风**（东亚）的潜热驱动部分由现行湿槽的温带通道承担，新闭合不覆盖温带。这部分是否
  需要补，用阶段 2 的华南季风盒判断，不预先加机制。
- **标定的连锁**：现行的对流抬升门与湿槽联锁（`convective_pickup_gate_enabled` 要求湿槽开启）。
  替换后联锁需要重新审视，阶段 1 先保持门关闭。
- **风向吻合**：辐散风会改变地面风，可能影响[由气压场推地面风](surface-wind-from-pressure.md)
  的阶段 3 前置检验。两者在热带是同一个物理，不应各自标定。

## 7 不采用的方向

- 继续调湿槽的轮数、欠松弛或限幅：迭代没有定点，任何轮数都是标定出来的停止点（2026-11-02，
  见[气候引擎本轮迭代 5.7](climate-engine-round.md#57-降水预算的分解成本与湿槽迭代2026-11-02)）。
- 给热带求解器风再加一个上限：那是第三道门修第二道门，违反纪律第 7 条，而且上限不改变增益。
- 直接接入 `qtcm` 或 QTCM1：不维护、不可分发、架构不匹配，见第 4 节。
- 给 M 加裸下限以避免 M ≤ 0：会把推导缺陷藏进一个参数里，见 3.2。
