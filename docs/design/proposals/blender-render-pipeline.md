# Blender 高清渲染链（blender-render-pipeline）

> **状态**：部分实现，立项日期 2026-10-02。区域数据包与 Blender 区域静帧已实现，技术参考见
> [pipelines/region-pack.md](../pipelines/region-pack.md)，操作见[地形视频链](../../usage/terrain-chain.md)。
> 相机动画与整球 Blender 渲染未实现。

## 1. 定位

前端 200k 网格的实时展示约 51 km 一格，作为视频素材信息密度不够。视频计划的硬约束是：全球与区域尺度的镜头走 Blender，
前端录屏只用于 UI 与 FUI 镜头。本链把引擎产出的世界数据交给外部渲染器，流程是区域数据包、由 bpy 脚本重建场景、
再用 Cycles 渲染静帧或动画；全链由命令行复现，不入库任何二进制工程。

## 2. 已定的设计选择

- **脚本重建工程。** `.blend` 是可随时由数据包重建的一次性产物，渲染参数与种子固定，同一数据包给出确定结果。
- **纯数据直出（作者 2026-10-02 裁决）。** MVP 只渲染引擎真实产出的高度场与配色，不叠加程序化细节；细节由独立阶段提供，
  并且必须与纯数据渲染可以区分。
- **细化层独立成包。** terrain-diffusion 条件化细化已作为主方法接入（作者 2026-10-05 裁决：先采用，不够再改进），
  它以独立子进程运行、不导入其代码，结果写入 `refined-out/`，不覆盖 `input/` 的原始通道。
- **每个场一个文件。** 不合并为 `.npz`，因为 zip 头带时间戳会破坏逐字节复现，合并容器也牺牲逐层懒加载；
  与外部工具的互通格式是 16 位 PNG、GeoTIFF 或 EXR。
- **资产位置。** 正式命令行入口在包内（`dreamulator export region`，与 `export layers` 同族），Blender 胶水在
  `scripts/media/blender/`，数据包与渲染输出在渲染工作目录，不入 git。

## 3. 与相邻链路的关系

- **Gaea 精化链**（[gaea-refinement.md](gaea-refinement.md)）共享区域选择与 16 位导出的接口词汇；本链只读盘上地图数据，不回写。
- **全球画布链**（[canvas-chain.md](../pipelines/canvas-chain.md)）与数据包共用方位等距窗口换算；画布窗口包可直接交给同一套出图与渲染脚本。
- **太空俯瞰星球链**（[orbital-weather-globe.md](../pipelines/orbital-weather-globe.md)）已提供整球云层、气旋与大气的圆盘合成，
  不经过 Blender。

## 4. 路线（登记不排期）

| 项目 | 内容与前提 |
|---|---|
| 相机动画 | 高空俯冲与火山口仰视母行星等运动镜头，需要沿相机路径的视距细节与稳定的种子策略。 |
| 整球 Blender 渲染 | 8192×4096 贴图加整球网格，受显存预算约束；与太空俯瞰链的圆盘合成分别评估用途。 |
| 夜灯贴图与红矮星大气查找表 | 夜面灯光在太空俯瞰链中待接；Blender 侧如需同类效果，读取同一导出，不另写一份。 |
| 程序细节增强 | fBm 位移、法线或 Gaea 侵蚀等，只在细化层不足的镜头上评估，并与纯数据渲染分开出图。 |
