# 柱辐射场：空间结构与云顶输入的限制

> 状态：草案，未实现。当前单层框架缺少可用的云顶结构输入，复用 GCM 云顶结构仍待作者裁决。
> 立项日期：2026-11-03。
>
> 本提案由[地面风提案的辐射下沉候选](surface-wind-from-pressure.md#32-洋面副高的上游缺口)分出。
> 目标是诊断有空间结构的柱辐射收支，为副热带下沉与地面气压提供物理输入。
> 本文保留依据、输入限制、候选与验收；逐日诊断和参数扫描由 git 与另存档案保留。

## 1 问题与物理依据

现行季节能量平衡模型使用全球反照率、温度驱动的冰反照率反馈与线性化出射长波，
缺少高云、层积云及地表类型的独立辐射贡献。其热带柱净能量收入近乎均匀，不能表达
降水减蒸发的正负结构，限制见[湿静力能终止说明](moist-static-energy-convergence.md#21-引擎输入的限制)。

对流区之外，自由对流层的辐射冷却可由下沉增温平衡，下沉与边界层质量连续性共同约束
辐散和地面气压。规定柱辐射冷却的离线检验支持这一机制，能够给出符号正确的五个洋面副高；
该结果只支持物理候选，尚未证明引擎自身输入可用，也未接入背景风。

柱辐射冷却需要区分大气顶与地表的辐射通量，单独知道大气顶出射长波不能确定大气柱的净冷却。
云的垂直位置决定其长波效应：深对流高云的云顶温度低，会显著削弱出射长波；
洋面层积云靠近海面，云量相近时也可产生不同的长波效应。地表反照率主要改变地表短波收支，
无法独自补上热带柱长波的结构。

## 2 输入限制与已有判决

地球 NCEP 辐射气候态的离线诊断中，柱长波损失与热带柱冷却的相关为 +0.95，
表明其空间结构主要来自柱长波损失。
这些辐射与云量属于再分析诊断量，证据用于检验候选在目标区域的可用性。
全球相关会混入赤道暖、极地冷的纬度趋势，不能替代热带洋面及各洋盆的型态检验。

| 方向 | 当前判决 |
|---|---|
| 只用地表温度、灰体温度四次方或柱水汽预测长波。 | 全球纬度趋势可以被复现，热带长波结构仍不足。 |
| 用降水代理高云。 | 再分析诊断中，降水与热带柱长波损失的相关为 −0.05；引擎自身降水结构也不足，不能作为现成的云顶输入。 |
| 用总云量与固定云顶温差修正长波。 | 总云量与热带柱长波损失的相关为 −0.083；已检验的固定云顶档位均未通过洋面副高检验。 |
| 只补地表反照率。 | 可以改变温度的地表能量收支，不能代替柱长波这一关键输入。 |

云量本身不提供云顶温度或垂直分层。当前网格已有 `cloud_high_frac`、`cloud_mid_frac` 与
`cloud_low_frac` 字段，GCM 气候投影可提供相应分层云量，快速气候引擎尚不能自产这些量。
GCM 气象包也能诊断云顶，但已有字段与诊断不等于快速模式的消费接口已经实现。
因此本提案仍停在输入与方案阶段，接受边界见[路线图技术债 51](../roadmap.md#七已知技术债务)。

## 3 保留的候选方案

目标是逐格逐月的诊断式柱辐射收支，包含大气顶吸收短波、大气顶出射长波与地表净辐射。
令大气顶净辐射 `R_TOA = SW_abs − OLR`，地表净辐射 `R_sfc` 向下为正，则
柱净辐射加热为 `R_TOA − R_sfc`，柱辐射冷却为 `R_sfc − R_TOA`，通量统一使用 W/m²。

实施前须先解决云顶或分层云量的来源，再检验灰体与云修正是否能在热带复现柱长波结构。
长波保留 `OLR = σT_e⁴` 的灰体与云修正候选，云量、云顶与柱水汽共同约束有效发射温度；
当前检验不支持只按降水诊断高云，
也不支持把固定云顶温差作为已通过的方案。

地表反照率仍可按海陆与雪冰状态构成，但它属于地表收支的补充。
气候层不能直接读取下游生态层的群系，否则会形成循环依赖；地表类型或干旱度代理
必须限定为气候层内可得的量，并单独检验其标定域。

让快速模式复用慢速 GCM 的云顶结构，是尚未裁决的设计选项。它会使交互迭代依赖一次
慢速运行，须明确产物来源、适用世界与复用边界，并检验改变世界输入后该结构是否仍适用。
直接用 GCM 辐射场作为独立真值的路线不采用；候选的云顶复用也仍须受地球辐射参考约束。

云、下沉、风和降水相互依赖。若候选采用前一遍的垂直速度构造云场，须先证明迭代收敛且
结果不依赖停止轮数；[现行湿槽的停止点](climate-engine-round.md#33-湿槽迭代)不能提供这一保证。
新增云诊断参数必须注明物理依据或观测锚定类别与标定域，跨世界只改变输入参数。

## 4 验收与顺序

先验收辐射量自身，再验收温度，最后评估副高与下游风场。

| 判据 | 验收方式 |
|---|---|
| 大气顶出射长波的空间型态。 | 对 NCEP 或 CERES 报告各大洲与各洋盆等权的型相关，并单独报告热带洋面。 |
| 柱辐射冷却的空间型态。 | 用同一来源、同一符号约定的辐射通量构成参考量，检验热带洋面及各洋盆结构。 |
| 全球平均大气顶净辐射。 | 绝对值须小于现行能量平衡模型的闭合容差，避免温度链漂移。 |
| 地表净辐射的纬向剖面。 | 与地球辐射参考在相同时间与面积口径下比较。 |
| 温度与季节响应。 | 全球及分纬带偏差、季节振幅须按容差保住，再检验下游副高。 |

整轮按[气候验证第 8 节](../pipelines/climate-validation.md#8-引擎改动的验收标准)执行。
再分析规定云场或柱冷却的干预只作诊断，不能替代引擎自身输入的验收；
辐射输入质量未通过时，不接入地面风替换。

## 5 不采用的方向

- 直接接入完整辐射传输模式：当前候选只需柱积分通量，代价需符合交互式气候引擎的范围。
- 用总云量或固定云顶温差独自预测热带柱长波：已有规定输入检验未通过。
- 用降水作现成的高云代理：代理自身与目标长波结构不符，上游降水质量也不足。
- 把全球长波相关当作热带副高的验收：纬度趋势会掩盖目标区域的结构误差。
- 继续以地表温度距平映射洋面副高：路线判决由[地面风提案](surface-wind-from-pressure.md#5-不采用的方向)维护。
