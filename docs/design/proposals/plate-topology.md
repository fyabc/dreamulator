# 板块拓扑层：显式维护边界图的逐步倒推

> **定位**：地质时间轴（[geological-timeline.md](geological-timeline.md)）逐步倒推的拓扑层设计。本文件
> 是设计提案，只写物理依据、当前方案与已否证方向；实验记录进 git 与 CHANGELOG，优先级在
> [roadmap.md](../roadmap.md)。
>
> **状态**：提案，未实现（2026-10-17 立项，作者选定方案：连续几何表示，阈值随板块数放宽）。替代 M2 中由质点归属决定板块的做法；
> 质点运动学、海底年龄合成与古地形字段保留。

---

## 0 为什么需要拓扑层

M2 的逐步倒推让每个地壳质点随板块转动，板块就是「归属该板块的质点占据的格子」，边界随之而来。
合并、缝合带切开、洋区新生都是对质点标签的局部操作。这种做法没有任何机制保证全局拓扑合理，
开发中依次出现：

- 边界随噪声累积成蜿蜒和窄凹口；
- 合并冻结未合拢的洋盆，为此加铰接，铰接又被重组冲掉；
- 接触即合并使板块数塌缩，为此加洋区新生，新生又造出被母板块包住的板块；
- 补上包裹吸收后，板块数进一步塌缩到两三块，洋中脊消失，洋壳年龄失去意义。

每修一处就冒出下一处，属于项目纪律所说的「加第三个门修第二个门」。根源是拓扑从质点归属中
涌现，而不是被维护。

专业重建的做法相反。GPlates 的连续闭合板块（Gurnis 等 2012）把板块表示为边界段的闭合序列，
每个边界段按自己的运动规则移动，每个时刻由边界段重新闭合出板块多边形；全板块模型（Domeier &
Torsvik 2014；Merdith 等 2021）在消失的大洋里以显式编辑的方式画出合成洋中脊与海沟。本提案把这一
做法引入倒推：**板块拓扑由一张显式的边界图维护，质点只携带地壳属性，不决定板块归属**。

## 1 物理约束

拓扑层必须满足的约束，按来源列出：

| 约束 | 依据 |
|---|---|
| 洋中脊位于两翼正中，随两侧板块转动的平均（半阶段旋转）移动 | 对称扩张；GPlates 的半阶段旋转（Müller 等 2018） |
| 洋中脊呈扩张段与转换断层的正交阶梯，扩张段近似垂直于相对运动 | Macdonald 等 1988；Gerya 2010 |
| 海沟随仰冲板块移动（可加后撤项），形态为平滑弧 | Frank 1968；Schellart 等 2007 |
| 转换断层沿相对欧拉极的小圆 | 刚体运动学 |
| 边界在三联点交汇，三联点的运动由三条边界的运动共同决定 | McKenzie & Morgan 1969 |
| 两块刚性板块之间的闭合边界，张开量与闭合量相等，所以不存在被单一邻居包住、四周都在扩张的板块 | 刚体运动的面积守恒 |
| 大陆岩石圈不俯冲，大陆壳面积在刚性倒推中守恒 | 浮力；刚性旋转保面积 |

## 2 数据结构

拓扑层在球面上用连续几何表示，不依赖网格分辨率：

- **节点**：三联点，球面上的点，恰好连接三条边界段。少数情况下允许四联点，但每步把它分解为两个三联点。
- **边界段**：两个节点之间的一条折线，点距约一个网格格距。属性包括：
  - 左右两侧板块；
  - 类型：洋中脊、海沟、转换断层、缝合带（已停止的旧边界，位于同一板块内部，不参与闭合）、大陆弥散边界；
  - 海沟的极性，即哪一侧仰冲。
- **板块**：边界段的有向循环列表，外加欧拉极。板块多边形由列表首尾相接闭合而成，因为相邻边界段共享节点，所以闭合不需要求交。
- **质点**：沿用 M2 的地壳质点，携带地壳类型、年龄、高程、来源格子等属性。质点的板块归属在每步由多边形重新判定。

格子层面的字段（快照、下游气候与生态的输入）由多边形栅格化到 CVT 网格得到：先在多边形边界上标出格子，再从内部种子做洪泛填充，复杂度与格子数成正比。

## 3 逐步倒推

每一步（默认 1 Myr）依次进行：

1. **移动边界段**：
   - 洋中脊按两侧板块旋转的平均移动；
   - 海沟随仰冲板块移动；
   - 转换断层随两侧的平均移动，再投影回相对欧拉极的小圆；
   - 大陆弥散边界随两侧的平均移动。
2. **移动节点**：每个节点取三条边界段在该端的移动结果的最小二乘交点，再把三条段的端点对齐到节点。
3. **闭合板块**：由循环列表得到多边形，检查多边形是否自交，自交处做局部修复（截去短于一个格距的环）。
4. **更新质点**：
   - 所有质点按所属板块的阶段旋转转回去；
   - 质点落在别的板块多边形内时，按边界类型处理：在洋中脊处，删去比 t 年轻的一侧（等时线相接）；在海沟处，被消耗一侧的质点在倒推中从海沟后方重新出现；大陆壳质点从不删除；
   - 多边形内没有质点覆盖的格子补上合成洋壳，归属和年龄由所在多边形和最近的洋中脊决定，不再按邻居猜。
5. **重新分类边界段**：按当前相对速度判定张开、汇聚或走滑。类型只在超过阈值时改变，海沟极性保持不变，除非一侧变成大陆。
6. **检查拓扑规则**（§5），不满足时拒绝本步的候选事件或重组方案。

## 4 拓扑事件

合并、切开与新生都是对边界图的显式编辑，每个事件都要通过 §5 的检查才生效：

| 事件 | 倒推中的触发 | 正向时间的含义 | 图编辑 |
|---|---|---|---|
| 裂谷合拢 | 一条洋中脊长度缩到零，或两侧大陆在洋中脊处相接 | 裂谷张开 | 删除该洋中脊段，两块板块的循环列表合并为一块 |
| 缝合带切开 | 到达缝合带的碰撞年龄 | 两块板块碰撞拼合 | 缝合带段变为活动边界（新的海沟），板块分成两块 |
| 洋区板块新生 | 某块板块的洋区过大，或板块大小分布偏离双峰形态 | 洋中脊熄灭、两块洋区板块拼合 | 在该板块边界上取两点作为新三联点，在两点间插入一条洋中脊段（扩张段与转换断层的阶梯），板块一分为二 |
| 微板块吸收 | 一块小板块被单一邻居环绕超过 240° | 微板块被捕获 | 删除它与包围板块之间的段，并入包围板块（地形引擎同一规则） |
| 洋中脊俯冲 | 洋中脊段到达海沟 | 洋中脊被俯冲消耗 | 洋中脊段与海沟段交换，生成转换断层或新的三联点（后续阶段） |
| 边界碰撞 | 两条非相邻边界段相交（某板块局部宽度缩到零） | 洋中脊俯冲、板块从洋中脊诞生、两海沟间板块被吃尽 | 在固定分辨率的内部采样球面上栅格化、按引擎飞地规则清理、重新提取边界图，段类型与海沟极性按两侧板块对继承（已实现） |

新生事件选两点的规则：两点都在该板块的外边界上，连线不穿过该板块的大陆，把洋区分成面积相近的两部分，并使新板块的邻居数最多。

## 5 拓扑规则与验收标尺

每步都检查以下规则，作为硬约束而不是事后诊断：

- 每个板块多边形是简单多边形，即不自交、只有一个连通块；
- 没有板块只有一个邻居；
- 节点都是三联点；
- 面积超过 1% 的板块，邻居数不少于 n_min(N)，与最大邻居的边界占比不超过 s_max(N)，N 为当时的板块总数（见下）；
- 大陆质点不被删除，快照上的大陆重叠损失不超过 2%；
- 板块数与大小分布保持双峰形态（少数大板块加若干小板块），最大板块的洋区不超过全球的 20%。

标尺取自 PB2002 在同一网格上的统计：面积超过 1% 的板块至少有 5 个邻居，与最大邻居的边界占比最多 0.62，
按面积加权的凸度约 0.77。倒推时板块总数通常少于现今，邻居自然更少，所以邻居数与边界占比的阈值随
板块总数 N 放宽。依据是欧拉公式：边界在三联点交汇的球面剖分里，平均邻居数为 6 − 12/N（N = 52 时
5.77，N = 10 时 4.8，N = 4 时 3）。阈值取

- n_min(N) = max(3, ⌊6 − 12/N⌋)，N = 52 时为 5；
- s_max(N) = min(0.9, 0.62 × 5.77 / (6 − 12/N))，N = 52 时为 0.62，N = 10 时约 0.75，N = 4 时为 0.9。

## 6 从现状初始化

1. 由重建用板块模型的格子标签提取边界：标出相邻格子属于不同板块的边，串成折线，找出三个板块交汇处作为节点。
2. 按类型平滑：洋中脊拟合为扩张段与转换断层的阶梯，海沟拟合为小圆弧，大陆弥散边界做弱平滑。沿海岸线走的被动陆缘边界不应存在，初始化时改走到海上。
3. 被重建模型粘起来的现状引擎板块边界，记为缝合带段，携带由 `find_sutures` 估出的碰撞年龄。

t = 0 的格子快照由初始边界图栅格化得到，与重建模型的格子标签会有边界附近的小差异，这是平滑造成的，不影响现状地形（古地理推演只读现状）。

## 7 与现有代码的关系

| 模块 | 处理 |
|---|---|
| `paleo_kinematics.py`（旋转、海底年龄合成、重建用板块模型） | 保留 |
| `paleo_history.py` 的质点状态、阶段欧拉极与构造规则打分、造山带回退、合成洋壳重新定龄、缝合带识别 | 保留，接到拓扑层 |
| `paleo_history.py` 中由质点归属决定板块的部分：按板块对补空缺、飞地合并、洋区边界松弛、铰接、接触合并 | 由拓扑层取代，保留为旧模式以便对照 |
| 新模块 `paleo_topology.py` | 边界图的数据结构、段与节点的移动、多边形闭合与栅格化、拓扑事件、规则检查（纯函数，无 IO） |

**不采用 pyGPlates 作为核心依赖**：pyGPlates 1.0.0 已可 pip 安装，自带成熟的拓扑闭合，但许可证为
GPLv2，本项目为 MIT。它只作为可选依赖用在地球对照验证上（M2b 的地球旋转模型对照）。

## 8 验证

- **自洽**：每步的拓扑规则通过率；面积守恒残差；正向回放到 t = 0 复现初始边界图。
- **地球**：用 EarthByte 的旋转模型与拓扑板块文件（通过可选的 pyGPlates 读取）驱动本拓扑层的移动与闭合，与 pyGPlates 自己闭合出的多边形逐时刻比较面积差与边界距离。
- **形状**：凸度、粗糙度、邻居数、与最大邻居的边界占比，按 §5 的标尺验收；作者目视验收各时刻的板块图。

## 10 闭合的认识论分类

| 闭合 | 类别 | 说明 |
|---|---|---|
| 边界段移动规则（半阶段旋转、海沟随仰冲板块） | 运动学 | 精确，后撤项为可选参数 |
| 三联点移动 | 运动学 | McKenzie & Morgan 1969 |
| 扩张段与转换断层的阶梯、海沟小圆弧 | 观测拟合 | 段长与曲率半径取地球观测范围 |
| 拓扑规则的阈值（邻居数、边界占比、最大洋区） | 观测拟合 | PB2002 在同一网格上的统计，倒推时按板块总数放宽 |
| 事件的具体位置与时刻（新生洋中脊的走向等） | 创作设定 | 受规则约束，不唯一 |

## 11 不采用的方向

- **继续在质点标签上叠加规则**：已在 M2 开发中证明会互相牵制（§0）。
- **以 pyGPlates 为核心引擎**：许可证与项目不兼容；保留为验证用的可选依赖。
- **在网格边上维护离散边界图**：实现较简单，但边界形状随网格分辨率变化，不同格子数下行为不一致（作者
  裁决 2026-10-17 明确要避免），也仍受网格锯齿与重采样噪声影响，平滑规则难以按类型施加。
